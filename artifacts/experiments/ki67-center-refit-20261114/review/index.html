변경한 학습 범위와 epoch0 대조

기존16epoch 가중치에서 시작해24epoch를 추가 학습했습니다. 이전 optimizer 상태가 없어 새 Adam을 사용했으며, 처음부터 연속40epoch 학습한 재현 결과가 아닙니다. 구조·손실·자료는 유지했습니다. 임계값 탐색 범위는 기존보다 넓어졌으므로 추가 학습만의 효과라고 단정하지 않습니다. epoch0은 새 탐색 범위에서 원래 가중치를 평가한 대조이며 채택 후보에서 제외했습니다.

표시와 사례 선택 기준

같은224×224 원영상·좌표의 A(원래 검출기)와 B(추가 학습 결과)를 비교합니다. B는 전체 조건을 통과한 설정이며, 통과 설정이 없으면 최고 검증 F1의 진단용 설정입니다. 후보 원은 핵 윤곽이 아닙니다. 두 모델이 독립적으로 중심을 예측하므로 이전 위치 보정 화면처럼 후보 간 이동 화살표를 그리지 않습니다.

각 seed에서 이미지별 (FP+FN) B−A 변화가 최소·최대인 두 사례를 고릅니다. 사후 설명용으로 전체 성능을 대표하지 않습니다. 주석과6px 이내 일대일 대응하며 세포 유형의 분류 정확도와 구분합니다.

해석 범위

기존에 여러 번 사용한 검증 자료의 탐색 실험입니다. 세 seed는 기존 검출기와 추가 학습 seed를 짝지었습니다. 주석되지 않은 모든 위치가 전문가가 확인한 비세포 정답인 것은 아닙니다. 점수는 보정된 임상 확률이 아닙니다. 임상·전체 WSI·새 미노출 외부 일반화를 입증하지 않습니다.
