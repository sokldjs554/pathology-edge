작은 모델 비교군과 실험 범위

주 비교 모델은 결과를 보기 전에 width16으로 정했습니다. width4는 별도 비교군이며 결과가 좋더라도 주 모델 대신 선택하지 않습니다. 두 새 모델 모두 처음부터24epoch를 학습했습니다. A는 기존16epoch 모델이므로 구조·정규화만의 인과 효과를 분리한 실험은 아닙니다.

자동 Ki-67와 외부 평가의 연결

검출 조건을 통과한 주 모델만 실제 예측 위치에서 세포를 분류합니다. 세포 분류 F1 상승과 같은 케이스의 양성률 오차 감소를 별도로 확인하며, 양성률만 좋아졌다는 이유로 전체 분석 성공이라 판단하지 않습니다. 기존 Patherea 테스트·BCData는 재평가입니다. 새 DeepLIIF는 폐·방광의 전체 세포 양성·음성 비교로, 종양세포 전용 Ki-67 지수·임상·전체 WSI 검증과 다릅니다. 이 화면은 위 검증 자료의 검출 사례를 보여줍니다.

사례 선택·표시 기준과 한계

각 seed에서 이미지별 (FP+FN)의 B−A 변화가 최소·최대인 실제 사례를 선택했습니다. 사후 설명용이며 평균을 대표하지 않습니다. 같은224×224px 좌표에서 정답과6px 이내 일대일 대응합니다. 후보 원은 핵의 윤곽이 아닙니다. 전체 조건을 통과한 설정이 없으면 최고 검증 F1의 진단용 미채택 모델을 표시합니다.

검증 자료는 반복 사용됐고, 점수는 보정된 임상 확률이 아닙니다. 표시를 끄면 원영상만 보이며 계산된 수치는 바뀌지 않습니다. 새로 학습된 모델은 기본 배포 모델로 교체되지 않았습니다.
