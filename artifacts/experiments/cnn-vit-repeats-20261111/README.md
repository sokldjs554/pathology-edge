# 3개 seed CNN–ViT 반복 실험 원본

개발 참고 실행입니다. 사용자 Codespaces 실행과 합치지 않았습니다. 기존 seed20261113의 원본을 재사용하고, 동일한 Python 소스·환경에서20261114·20261115를 추가했습니다. 전체180개 이미지·영역 지표를 저장 확률에서 재감사했습니다.

각 ZIP에는 `pairs/<seed>/` 아래 전체 로그·확률맵·체크포인트·소스·설정·보존 기록이 있습니다. 원본 위치 문자열은 변경하지 않았습니다. 데이터 이미지는 TNBC 원본에서 별도로 준비합니다.

이 폴더에서 `sha256sum -c SHA256SUMS`로 파일을 확인한 뒤, **이 폴더의 새 복사본에서만** ZIP 세 개를 풀면 재감사 가능한 구조가 됩니다. 원래 학습을 재실행하지 않습니다. 저장소 루트에서 다음처럼 재감사합니다.

```bash
python scripts/run_model_repeats.py --summarize /절대경로/해제한실험폴더 --data-override /절대경로/TNBC데이터폴더
```

학습 소스는 기존 실행의 동결본을 그대로 사용했고, 반복 실행기의 소스는589b04d입니다. 오래된 `source_commit`과 현재 반복 실행기의 커밋이 다른 것은 기록 오류가 아닙니다. 실효 소스 SHA는 `protocol.json`에 있습니다. 원본 코드와 실행 파일을 임의로 실행하지 않고 신뢰하는 저장소의 감사 명령을 사용합니다.

3개 seed는 데이터 독립성을 늘리지 않습니다. 기존 validation10장·2그룹에서 epoch/threshold를 선택했습니다. test·외부·임상 평가는 하지 않았습니다. 시간은 다른 시점의 기존 실행을 포함한 기술적 기록이며 통제된 속도 벤치마크가 아닙니다.
