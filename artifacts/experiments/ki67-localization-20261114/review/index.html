비교 방법과 용어

A: 기존 학습 검출기. U: 느슨한 학습 후보 + LoG 후보, 같은 좌표만 통합. S: 새 CNN 점수로 원래 위치에서 선택. R: 같은 CNN 점수·임계값·거리 기준을 사용하되 위치를 보정한 뒤 선택. S와 R은 같은 체크포인트이며, 이전 C0(임계값 0)와 다릅니다. 화살표는 R에서 남은 후보의 원래 위치→보정 위치입니다. U는 후보 공급 확인용입니다.

FP는 정답과 대응하지 않은 후보, FN은 놓친 정답입니다. 6px 이내에서 클래스와 무관하게 일대일 대응합니다. 재현율은 TP/(TP+FN), F1은 2TP/(2TP+FP+FN)입니다. 표의 F1·재현율은 케이스별 평균, FP·FN은 227장 합계입니다. 양성/음성 종양 재현율은 실제 종양 클래스별 위치 검출 비율이며 분류 정확도가 아닙니다.

사례는 seed별 R−A의 FP+FN 변화가 가장 작고 큰 검증 이미지를 고릅니다. 후보 원은 핵 경계가 아닙니다. 네 화면의 영상과 좌표는 같습니다.

해석 범위

세 seed는 기존 검출기 seed와 새 CNN seed를 짝지은 비교입니다. 검출기·4분류기는 고정했습니다. 새 CNN은 후보 유지 점수와 연속 좌표 이동량을 함께 학습했습니다. 연속 이동은 최대 12px이며 정수 반올림 후 최대 약 12.71px까지 가능합니다. S/R 비교는 추론 때 좌표 보정을 켰을 때의 차이이며 학습 변경 전체의 원인을 분리하지 않습니다. 주석에서 멀리 떨어진 후보를 음성 대용으로 사용했으므로 실제 세포가 음성 학습 자료에 포함됐을 가능성이 있습니다. 점수는 보정된 임상 확률이 아닙니다.

기존에 사용한 검증 데이터의 탐색적 실험입니다. 조건을 통과하지 못한 모델의 화면은 실패 분석용입니다. 새로운 외부 일반화, 임상 검증, WSI 전체 검증을 의미하지 않습니다.
