# STEP92 — 정규화 검출기 첫 예제 표시 확인 (응답 확인)

2026-11-14(Asia/Seoul), 첫 예제에서 FP14→6·FN10→4가 보이는지 요청한 뒤 사용자가 “응 잘 보이는거 확인했어”라고 답했다. 해당 화면·수치의 표시 확인을 U106에 기록했다. 예제 이름이나 숫자를 별도로 전사하거나 독립 검산한 것은 아니다. [응답 기록](../artifacts/learning/step92-review.json).

이번에는 첫 예제 한 개만 확인한다. 새 학습이나 코드 작성은 필요하지 않다.

1. [검토 ZIP](../artifacts/handoff/PathologyEdge-Normalized-Review-20261114.zip)을 내려받아 압축을 풀고 `index.html`을 연다.
2. A와 B의 같은 원영상에서 FP·FN 숫자와 후보·정답 표시를 확인한다. B가 미채택 진단 모델이면 그 표시도 확인한다.
3. 사용자 응답으로 첫 예제의 표시 확인은 완료했다. 같은 원영상 여부의 별도 확인, 표시 전환, 다른 예제·화면 크기와 독립 수치·좌표 검산은 미확인이다.

이전 U105는 이전 추가학습 화면의 표시 전환 확인이며 이번 화면의 확인을 대신하지 않는다. 화면이 보인다는 사실은 성능 안정성이나 외부 개선의 증거와 다르다.

Mac에서 파일 직접 열기가 제한될 때는 **압축을 푼 폴더**에서 다음 명령을 실행하고 `http://127.0.0.1:8000/`을 연다. 내장 이미지를 보여주는 로컬 서버이며 새 모델 추론이나 데이터 다운로드를 하지 않는다.

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Codespaces에서 실행한다면 같은 폴더에서 위 명령을 실행하고 Ports 패널의8000번 포트에서 브라우저 열기를 사용한다. 검사에 사용한 관리형 Chromium은 file://을 차단하여 로컬 HTTP 방식으로만 확인했다.
