# STEP89 — 후보를 모으고 제거한 실제 화면 확인

이번 단계에서는 코드를 작성하거나 학습을 다시 실행하지 않아도 된다. 새 화면의 사용자 확인은 아직 **대기** 상태다.

1. 후보 통합 검토 ZIP을 내려받아 압축을 풀고 `index.html`을 브라우저로 연다.
2. 첫 예제에서 A(기존), B(통합), C0(거리 억제), C(CNN 임계값 적용)의 네 화면이 같은 영상인지 확인한다.
3. **후보·정답 표시**를 껐다가 켜서 원영상과 후보 표시가 전환되는지 확인한다.

여기까지 확인한 뒤 네 화면과 표시 전환이 정상인지 알려 주면 된다. 모바일에서는 네 화면이 세로로 나열된다. 표는 가로로 스크롤할 수 있다.

파란 점은 주석과 대응한 후보, 분홍 점은 주석과 대응하지 않은 후보(FP), 노란 원은 정답 중심이며 ×가 붙으면 놓친 정답(FN)이다. 원은 핵 윤곽이 아니다. C가 '진단용·선택 조건 미충족'이면 채택된 개선 모델로 해석하지 않는다.

실패하면 사용 브라우저, 선택 예제 이름, 화면 캡처와 어느 조작이 안 되는지를 보내 준다. 이번 확인을 학습·독립 수치 검산·전체 사례 검토로 기록하지 않는다.
