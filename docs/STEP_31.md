# 31단계: 종양 여부 오류와 양성률의 분자·분모

상태: **2026-11-10 (Asia/Seoul) 사용자 해석 확인**. 다른 세포의 결과를 고정하면 이 한 건의 오류로 분자와 분모가 각각 1씩 줄어든다는 설명을 받았습니다. 다음은 [32단계 양성률 결과의 검증 범위](STEP_32.md)입니다. 새 코드·설치·화면 조작·터미널 실행은 없습니다.

## 계산 정의와 질문 하나

현재 실험의 주석 세포 기반 종양 양성률은 다음과 같습니다.

**Ki67 양성 종양 세포 수 ÷ (Ki67 양성 종양 세포 수 + Ki67 음성 종양 세포 수)**

정답 비율은 정답 클래스로, 예측 비율은 예측 클래스로 각각 셉니다. 분모는 제공된 모든 세포 수가 아니라 해당 집계에서 종양으로 분류된 세포 수입니다. 분모가 0이면 비율은 정의하지 않습니다.

`incorrect-01`의 정답은 **Ki67 양성 종양 세포**, 예측은 **Ki67 양성 비종양 세포**입니다.

**다른 세포의 결과는 같다고 할 때, 이 세포를 올바르게 분류했을 때와 비교해 이 한 건의 오분류는 예측 양성률의 분자와 분모를 각각 어떻게 바꾸나요? 한 문장으로 설명해 주세요.**

이 한 세포 오류의 영향을 구분하는 질문입니다. 실제 case 전체에는 다른 세포의 오류도 있으므로 전체 비율 차이를 이 한 건만으로 설명하는 과제가 아닙니다. 대상은 정답 중심이 주어진 주석 세포이며 전체 WSI의 임상 Ki67 지수가 아닙니다.

## 사용자 답변과 확인 범위

> 양성 종양 세포 1개를 양성 비종양 세포로 잘못 분류하면, 올바르게 분류했을 때보다 분자(양성 종양 세포 수)와 분모(전체 종양 세포 수)가 각각 1개씩 감소합니다.

양성 종양 수와 전체 종양 수에서 모두 제외된다는 올바른 설명입니다. Codex가 계산식과 다른 세포를 고정한 조건을 제공했고 사용자가 수 변화의 의미를 설명했습니다. 이 한 세포의 기여에 대한 해석이며, 실제 case 전체 오차나 일정한 퍼센트포인트 변화량을 검증한 것으로 기록하지 않습니다. [답변 원문과 범위](../artifacts/learning/step31-review.json).

## Codex 확인 범위

`src/pathology_edge/ihc_baseline.py::tumor_ratios`의 클래스별 집계와 분모 0 처리를 읽었습니다. `case_0004`의 저장 테스트 행 566개에서 정답·예측의 분자와 분모를 각각 다시 세어 저장된 비율·분모와 일치함을 확인했습니다. 공개 결과 파일의 해당 case와 원본 case도 같습니다. 화면의 부속 비율 결과와 범위 안내 연결을 읽었습니다.
