# 69단계 — MoNuSeg 외부 H&E 핵 분할 결과 검토

BCData에서 사용자는 공식 원자료 수신과109/367 두 장의 추론·비교 그림 표시·해석을 완료했다(U75–U82).
402장 전체 평가는 개발 환경에서 수행한 결과이며, 사용자 전체 재실행으로 기록하지 않는다.
다음은 별도 H&E 핵 분할 과제의 외부 평가다. IHC 분류·종양 양성률과 지표를 섞지 않는다.

| 사용자 seed20261116의 고정 모델 쌍 | 기준 ViT 전체 Dice | 보정 추가 전체 Dice |
|---|---:|---:|
| TNBC validation10장, epoch/threshold 선택에 사용 | 0.570565 | 0.590386 |
| MoNuSeg 공식test14개 주석 ROI, 고정 모델·threshold | 0.551974 | 0.534943 |

MoNuSeg는14장 중13장에서 전체 Dice가 낮아졌고 패치 경계 Dice는14장 모두 낮아졌다.
두 평가의 평균을 합치지 않는다. 이 외부 실행은 사용자가 새로 실행한 것이 아니다.

[실제 최대 하락 그림](../artifacts/experiments/external-monuseg-20261111/largest-decrease.png):
`TCGA-GL-6846-01A-01-BS1`, Dice0.546064→0.514521.
빨강FP327258→382171, 파랑FN9752→6497. 일부 누락 감소와 전체 점수 하락이 함께 관측됐다.
[전체 보고·출처·원본](EXTERNAL_MONUSEG_VALIDATION.md)을 참조한다.

사용자에게 그림과 표를 보고, TNBC에서의 보정 효과가 외부 데이터에서도 입증됐다고 말할 수 있는지
두 데이터 결과를 근거로 설명하도록 요청한다. 답변 전에는 해석 완료로 기록하지 않는다.
답변이 표의 수치만 해석한 범위라면 실제 그림의 개별 위치까지 검토했다고 확대하지 않는다.

14개1000² 주석 ROI이며 전체 WSI·임상 검증이 아니다. 한 고정 모델 쌍의 결과로 모든 기관·환자에서의
일반적 우열이나 성능 하락 원인을 확정하지 않는다. 공개 그림은 MoNuSeg/Kumar 등·TCGA 출처,
CC BY-NC-SA4.0의 연구 파생 그림이다.
