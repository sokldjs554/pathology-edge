# 추가 공개 WSI·Ki67 조사 자료 대조

2026-11-12. 사용자 제출 `WSI_Nuclei_Ki67_Public_Data_Research_20261112.zip`을 열고 주요 공식 출처를 대조했다. **후보 조사와 일부 실물 자료 연결을 보완했지만, 임상 검증 또는 전체 WSI 핵 정답 기반 평가를 완료할 자료는 확보되지 않았다.** 기존 실험 수치·모델·배포 화면은 변경하지 않았다.

## 실제 수행한 범위

- 업로드 ZIP 28,544bytes의 CRC와 13개 구성 파일을 확인했다. 후보 14개에 대한 Markdown 5개·CSV 4개·JSON 1개·Python 3개이며 원영상·핵 마스크·임상 판독 원자료는 없다. 첨부된 실행 절차는 조사 제안으로 읽었고, 첨부 Python 도구를 실행하거나 기관에 요청문을 전송하지 않았다.
- Zenodo 3개 기록의 API에서 파일 목록·크기·라이선스를 다시 읽었다. 문서에 적힌 공개 MD5 **10/10개가 현재 카탈로그와 일치**했다. 이는 원본 파일 전체를 다운로드해 MD5를 검증했다는 뜻이 아니다.
- 새 IHC 후보의 배포 ZIP을 HTTP206 범위 읽기로 조사해146개 항목(디렉터리 25개, JSON 11개, JPEG 55개, PNG 55개)을 확인했다. JSON 11개를 실제 추출해 구성 파일 CRC를 검사했다.
- 사전식 첫 사례 0001의 Ki67 JPEG와 대응 PNG를 실제로 읽고 CRC·SHA256·디코딩·크기 일치를 확인했다. 두 파일은 4096×3286px다. 같은 좌표에 마스크를 표시해 기본 연결을 살펴봤으며, 전문가 주석의 정확성·완전성을 검증했다고 주장하지 않는다.

이 작업은 제공된 개발 환경에서 수행했다. 사용자의 직접 실행·직접 판독 기록을 추가하지 않았다. 업로드 문서의 작성자를 제출자와 동일하다고 추정하지 않는다. [파일 해시·구조 대조 근거](../artifacts/research/public-data-review-20261112/audit.json).

## 새 IHC 자료에서 직접 확인한 문제

[공식 배포](https://zenodo.org/records/21487212)의11개 JSON 모두 Ki67 `positive_cell_percentage`를 포함한다. 그러나 같은 시야의 양성 종양세포 수·전체 종양세포 수·세포별 정답 중심 좌표는 제공하지 않는다. [논문 §3.5](https://www.mdpi.com/2306-5729/11/9/214)는 수치가 검체 전체의 판독값이며 각 FOV의 국소 비율로 자동 해석해서는 안 된다고 명시한다.

실제 Ki67 마스크 유형은 다음처럼 섞여 있다.

| JSON의 마스크 의미 | 사례 수 | 현재 모델 평가에 필요한 구분 |
|---|---:|---|
| `only_positive_tumor_cells` | 5 | 양성 종양세포 영역만 표시. 음성 종양세포를 포함한 분모를 이 마스크만으로 얻을 수 없음 |
| `tumor_cells` | 6 | 전체 종양세포 영역. 마스크 하나에서 양성·음성 정답을 구분할 수 없음 |

논문은 마스크가 세포 무리·조직 영역을 포함해 항상 개별 핵 윤곽과 같지는 않다고 설명한다. 따라서 연결 성분을 곧바로 정답 세포로 세거나, 기존 H&E 모델의 **모든 핵** 예측과 **양성 종양세포만**의 마스크를 비교해 같은 과업의 Dice로 발표할 수 없다. 정답 중심이 필요한 기존 IHC 분류기도 이 자료에 그대로 적용할 수 없다.

**실제 경로 불일치도 있다.** JSON의 55개 이미지 경로는 ZIP 멤버와 정확히 일치하지만, 마스크 55개는 JSON에 `_mask.png`, 실제 파일에는 `_MASK.png`로 저장돼 있다. 대소문자를 구분하는 Linux에서 그대로 열면 실패한다. 대소문자를 무시한 후보가 각각 하나임을 확인해 명시적으로 연결했고 원 JSON·파일명은 수정하지 않았다. 이 연결 성공은 정답의 임상적 적합성을 뜻하지 않는다.

0001 마스크는 이진값만 가진 PNG이며 전경 171,932px다. 이 수치는 **표시된 영역의 픽셀 수**이고 핵 개수·Ki67 분자·임상 정확도가 아니다. 사례 JSON의 20%를 이 FOV의 정답 양성률로 사용하지 않았다. 새 추론·학습·성능 수치 계산은 하지 않았다.

## 다음에 필요한 자료

공개자료로 추가할 수 있는 것은 **수작업 핵 주석 ROI의 연구 평가**다. 현재 누락된 목표를 완료하려면 다음 조건을 별도로 충족해야 한다.

- **전체 WSI 핵 평가:** 같은 원본 파일과 level0 좌표계, 사전에 정한 전체 평가 조직의 빠짐없는 핵 정답, 주석/제외 영역과 완전성 근거. 일부 ROI라면 평가명과 분모도 ROI로 제한한다.
- **Ki67 임상 검증:** 독립 Ki67 검체 원영상, 같은 평가 범위의 전문가 기준과 양성/전체 종양세포 수 또는 검증된 산정 규칙, 평가자·합의 과정, 사용 조건 및 연구 계획. 현재 정답 중심 조건 분류기를 자동 전체 WSI 정량기로 바꾸는 구현도 별도 과제다.

우선 실제 원본 1장과 대응 주석·범위·메타데이터로 연결을 시험할 수 있다. 한 묶음의 연결 성공만으로 임상 표본이 충분하거나 검증이 완료된 것은 아니다. 자세한 현재 상태는 [검증 범위 문서](CLINICAL_WSI_VALIDATION_STATUS.md)를 따른다.

## 검사 범위와 보관

업로드 ZIP CRC, 카탈로그 10개, 추출 JSON 11개, 선택 영상/마스크 2개의 CRC·SHA, JSON 참조 110개의 대응을 검사했다. 첫 HTTP 범위 요청의 503은 후속 요청으로 해결했으며 원 ZIP 손상으로 판정하지 않았다. 전체 518,528,624bytes의 MD5는 미검증이다. 원영상·마스크·케이스 원 JSON·검토 화면은 비공개 work 폴더에 두고 집계·해시만 공개한다.

이전 최종 전달 ZIP은 발행 시점의 기록으로 유지한다. 본 검토는 그 이후 추가 자료이며 본인 직접 수행 U01–U83을 변경하지 않는다. 기존 앱 회귀 테스트·모델 평가·배포를 이번 문서 작업에서 새로 실행한 것으로 기록하지 않는다.
