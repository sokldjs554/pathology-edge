# 32단계: IHC 양성률 결과의 검증 범위

상태: **2026-11-10 (Asia/Seoul) 사용자 해석 확인**. 정답 중심이 주어진 주석 세포의 case별 양성률 오차이며 전체 WSI 자동 검출이나 임상 Ki67 정확도 검증이 아니라는 설명을 받았습니다. 다음은 [33단계 예측 점수 해석](STEP_33.md)입니다. 새 코드·설치·화면 조작·터미널 실행은 없습니다.

## 저장 결과와 질문 하나

현재 저장된 부속 결과는 **10개 테스트 case의 주석 세포 기반 종양 양성률 평균 절대오차 7.686퍼센트포인트(%p)**입니다. 원본은 `7.686353396880657`이며 소수 셋째 자리로 표시합니다. 전체 테스트 자료는 407개 패치·6,419개 세포이고, 비율은 case별로 계산한 뒤 오차를 평균합니다. 상대 오차 7.686%라는 뜻은 아닙니다.

**이 결과를 “WSI 전체에서 세포를 자동 검출해 계산한 임상 Ki67 지수의 오차를 검증했다”고 설명해도 될까요? 실제 입력 조건과 평가 대상을 근거로 한두 문장으로 설명해 주세요.**

참고할 자료는 [IHC 실험 설명](IHC_EXPERIMENT.md)의 주석 세포 비율 항목과 데모의 **결과·출처 → 주석 세포 비율의 부속 결과** 아래 범위 안내입니다. 지금은 기존 설명을 바탕으로 답하면 되며, 추가 화면 조작을 수행했다고 기록하지 않습니다.

## 사용자 답변과 확인 범위

> 아니요. 7.686%p는 10개 테스트 케이스에서 제공된 정답 중심 좌표의 주석 세포를 분류해 계산한 양성률의 평균 절대오차이며, 세포를 자동 검출한 결과가 아닙니다. 따라서 WSI 전체의 자동 세포 검출 성능이나 임상 Ki67 지수의 정확도를 검증했다고 설명할 수 없습니다.

저장된 입력 조건·case별 집계·검증 범위에 맞는 설명입니다. 수치와 참고자료·질문은 Codex가 제공했고 사용자가 평가 범위를 해석했습니다. 새로운 화면 조작·모델 실행·임상 검증을 수행한 기여로 기록하지 않습니다. [답변 원문과 범위](../artifacts/learning/step32-review.json).

## Codex 확인 범위

저장된 `artifacts/ihc/test-predictions.json`의 클래스에서 10개 case의 정답·예측 분자와 분모를 다시 집계했습니다. case별 비율, 절대오차, 평균이 원본 보고와 일치하며, 유효 case 10개·분모 0 제외 0개입니다. 공개 결과 파일의 case·요약·scope도 원본과 같습니다.

`dist/ihc.js`의 표시 값 연결과 `dist/ihc.html`의 범위 안내를 읽었습니다. 답변 검토 시 준비 기록의 입력 해시 7개가 그대로이고 공개·원본 scope가 같음을 확인했습니다. 이 검산은 기존 저장 클래스만 사용했으며 새 특징 추출·추론·학습·영상 처리·브라우저 검사·임상 검증은 하지 않았습니다.
