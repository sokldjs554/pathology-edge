# 32단계: IHC 양성률 결과의 검증 범위

상태: **사용자 해석 대기**. [31단계](STEP_31.md)에서 종양→비종양 오류가 양성률의 분자와 분모에 미치는 영향을 설명했습니다. 이번에는 저장된 양성률 결과를 면접에서 어떻게 설명할 수 있는지 확인합니다. 새 코드·설치·화면 조작·터미널 실행은 없습니다.

## 저장 결과와 질문 하나

현재 저장된 부속 결과는 **10개 테스트 case의 주석 세포 기반 종양 양성률 평균 절대오차 7.686퍼센트포인트(%p)**입니다. 원본은 `7.686353396880657`이며 소수 셋째 자리로 표시합니다. 전체 테스트 자료는 407개 패치·6,419개 세포이고, 비율은 case별로 계산한 뒤 오차를 평균합니다. 상대 오차 7.686%라는 뜻은 아닙니다.

**이 결과를 “WSI 전체에서 세포를 자동 검출해 계산한 임상 Ki67 지수의 오차를 검증했다”고 설명해도 될까요? 실제 입력 조건과 평가 대상을 근거로 한두 문장으로 설명해 주세요.**

참고할 자료는 [IHC 실험 설명](IHC_EXPERIMENT.md)의 주석 세포 비율 항목과 데모의 **결과·출처 → 주석 세포 비율의 부속 결과** 아래 범위 안내입니다. 지금은 기존 설명을 바탕으로 답하면 되며, 추가 화면 조작을 수행했다고 기록하지 않습니다.

## Codex 확인 범위

저장된 `artifacts/ihc/test-predictions.json`의 클래스에서 10개 case의 정답·예측 분자와 분모를 다시 집계했습니다. case별 비율, 절대오차, 평균이 원본 보고와 일치하며, 유효 case 10개·분모 0 제외 0개입니다. 공개 결과 파일의 case·요약·scope도 원본과 같습니다.

`dist/ihc.js`의 표시 값 연결과 `dist/ihc.html`의 범위 안내를 읽었습니다. 이 검산은 기존 저장 클래스만 사용했으며 새 특징 추출·추론·학습·영상 처리·브라우저 검사·임상 검증은 하지 않았습니다. 사용자의 검증 범위 해석은 답변을 받은 뒤 기록합니다.
