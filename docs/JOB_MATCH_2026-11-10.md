## 회사 제품과의 연결

[Qanti Breast Ki-67](https://www.aivis.kr/product/qanti-breast-ki-67)는 종양 세포 중 양성 비율을 정량화하고,
[Qanti Discovery](https://www.aivis.kr/product/qanti-discovery)는 연구자·제약사를 위한 재현 가능한 IHC 정량을 다룬다.
[회사 공개 연구 목록](https://www.aivis.kr/technology/publication)에는 ViT 기반 종양 세포 검출과 Ki-67 정량 연구도 있다.
이는 패치 경계, 세포 유형 오류, 분모 변화, 원본 위치 추적을 다루는 프로젝트의 직무 연관성을 뒷받침한다.
제품의 검증 수준이나 공개 연구의 상세 방법을 본 프로젝트에 적용해 주장하지 않는다.

현재 IHC 기준선은 주제 연결에는 유용하지만 중심 위치를 입력으로 받으므로 회사 제품과 같은 자동 정량 파이프라인은 아니다.
제품 관련 확장을 한다면 색상 기준선에 형태 정보를 쓰는 분류기를 비교하거나 점 주석 기반 자동 중심 검출을 평가하는 방향이 의미 있다.
두 방향을 동시에 새로 구현하기보다 하나를 선택해야 실험·검증을 끝까지 수행하기 쉽다.

## 보완 우선순위

아래는 회사가 추가로 요구한 조건이 아니라, 현재 기여·실험 근거를 바탕으로 한 Codex의 권고다. 아직 새 구현이나 사용자 과제로 완료 처리하지 않았다.

| 순위 | 보완 | 사용자 역할 | Codex 역할·완료 근거 |
|---|---|---|---|
| 1 — 지원 전 우선 | 기존 TinyUNet 학습 재현 후 단일 가설 비교 실험 | 학습·검증 루프를 이해하고 실행, 이후 손실/증강 등 한 요소의 변경을 직접 작성·선택·설명 | 설치·데이터·안전한 별도 출력 경로·기록 형식 준비, 변경 검토와 독립 검산. 사용자 커밋·학습 로그·validation 결과·실패 해석이 있어야 완료 |
| 2 — 엔지니어링 보완 | 사용자 좌표 함수를 실제 WSI 배율·리사이즈 경로에 연결 | 입력 좌표 단위·scale 계약과 변환 호출을 직접 구현하고 결과 위치 검토 | OpenSlide 메타데이터·ROI·테스트 fixture 지원. level>0, 비등방 리사이즈, 경계 crop, native 경로 회귀를 실제 경로에서 검증 |
| 3 — 실험 근거 강화 | 선택한 가설의 반복과 비교 모델 하나 | 비교 기준·지표·선택 규칙 결정, seed별 결과와 비용 검토 | 실행 자동화·결과 표·프로토콜 보조. 예를 들어 사전 고정한 3개 seed를 모두 보고하고 좋은 seed만 선택하지 않음. 반복은 2개 테스트 그룹의 한계를 해결하지 않음 |
| 4 — 제출 정리 | 현재 커밋의 Ubuntu/Docker 재현, 간결한 직무별 기여 설명과 실제 PR 하나 | 재현 명령 실행·로그 제출, 본인 변경과 설계 판단 설명 | 재현 안내·오류 해결·문서 정리. Codex가 대신 실행한 로그를 사용자 실행으로 바꾸지 않음 |

ViT 비교는 공고의 명시적 우대에 대응하는 **선택 보완**이다. 구현 시간을 확보할 수 있다면 단순 CNN/현재 기준선과 비교하는 한 모델을 고르고,
실제 가중치 이용 조건·데이터 유출 가능성·CPU/메모리 비용부터 확인한다. 라이브러리 import나 추론 화면만으로 ViT 연구 경험을 주장하지 않는다.
시간이 부족하면 새로운 대형 모델 추가보다 1번의 본인 주도 실험을 먼저 마치는 편이 낫다.

현재 test 결과는 이미 상세히 열람했다. 새 모델·손실·증강 선택은 train/validation에서 하고 기존 공개 결과와 별도 실험 디렉터리에 기록한다.
같은 test에 후속 결과를 보고할 때는 이미 노출된 테스트의 한계를 명시한다. 새 독립 최종 검증을 주장하려면 별도의 미열람 데이터가 필요하다.

## 지금 확대하지 않아도 되는 범위

전체 WSI의 끝까지 가는 자동 Ki-67 분석, 임상 검증, 추가 장식 UI, 모든 공개 모델 재현, Jira 사용 흔적 만들기를
지원 전 필수로 잡지 않는다. 자동 검출을 확장한다면 실제 점 주석을 사용한 일대일 매칭·허용 거리·유형별 precision/recall/F1을 먼저 정의하고,
GT 중심 분류와 분리해 평가해야 한다. 정답 없는 WSI의 예측 차이만으로 검출 성능이나 개선 효과를 만들지 않는다.
