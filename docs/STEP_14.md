# 14단계: 확대된 영상의 클릭 드래그 이동 확인

상태: **사용자 드래그 확인 대기**. 13단계에서 사용자는 국소 경계 Dice0.546→0.433과 양쪽 같은 위치 표시를 확인했습니다. 그 답변으로 드래그·두 손가락 스크롤까지 확인됐다고 기록하지 않았습니다.

## 직접 할 조작 하나

`10_1 → 현재 예제 경계`로 확대한 화면에서 **왼쪽 영상의 조직 무늬 위를 클릭한 채 오른쪽으로 조금 끌었다가 놓습니다.** 마우스는 왼쪽 버튼을 누른 채, 트랙패드는 클릭을 유지한 채 움직입니다.

화면을 닫았다면 [정답 경계 실험 데모](https://pathology-edge-lab.ykh13571.chatgpt.site/)에서 TNBC10_1을 선택하고 **현재 예제 경계**를 누르면 됩니다.

예상 결과는 양쪽 조직 영상과 흰 상자가 같은 방향으로 함께 이동하는 것입니다. 확대 배율과 선택 경계의 Dice0.546→0.433은 유지됩니다. 영상의 시야만 이동하며 새 추론이나 점수 재계산을 실행하지 않습니다.

**양쪽 영상이 함께 이동하는지**를 알려 주세요. 움직이지 않거나 한쪽만 움직이면 브라우저 이름과 마우스/트랙패드 중 사용한 장치를 함께 적어 주세요.

이번에는 클릭 드래그 하나만 확인합니다. 두 손가락 스크롤은 별도 확인 전까지 미확인으로 남깁니다.

## Codex 검증 범위

2026-11-09 로컬 Chromium에서 같은 화면의 왼쪽 영상을 오른쪽80 CSS px만큼 드래그했습니다. 양쪽 영상 중심은 `(112,128)`에서 `(95.636,128)`로 함께 바뀌었고 배율4.88889·선택 사례·국소 점수는 유지됐습니다. 화면을 오른쪽으로 끌면 보이는 시야의 이미지 좌표 중심은 왼쪽으로 바뀝니다.

이는 저장소의 로컬 데모 검증입니다. 사용자 브라우저나 공개 배포 화면의 새 드래그 검증으로 기록하지 않습니다. 이전 공개 HTTP 조회 제한은 [13단계](STEP_13.md)에 남겼으며 이번에는 공개 URL을 다시 조회하지 않았습니다.
