# 자동 Ki-67 후보 통합과 영상 기반 후보 제거 비교

상태: 방향 선택·별도 설계 검토 완료, 사용자 실행 승인 대기. 이 문서는 실행 전 제안이며 새 CNN의 성능 결과가 아니다.

## 목적과 기존 근거

사용자는 남은 성능 보완을 요청했고, 두 방향 중 **후보 통합 + 배경 제거 CNN 우선**을 선택했다(U101). 목표는 자동 패치 분석에서 누락과 오검출을 함께 줄이고 세 seed에서 관찰되는지 확인하는 것이다. 기존 모델·기본값·원자료·실험·ZIP·공개 데모와 사용자 작성7파일은 보존한다.

기존 중심 검출기를 후처리만 완화하면 첫 seed 내부 재현율은0.3943→0.6060으로 오르지만 FP5297→30134, 위치F1 0.3553→0.1924가 된다. 기존 LoG 재현율 조건을 충족한 seed도3개 중1개뿐이다. 양성률 MAE만을 성공 기준으로 삼지 않는다.

이번 설계 준비에서 train/validation923장의 공개 영상·점 주석을 대조했고 테스트 영상을 새로 읽지 않았다. 기존 저장 피크를 검사하면 seed18/19의 양성 종양 근처 피크 존재 상한은251/483,240/483이다. 따라서 그 피크 집합을 거르는 방식만으로 이전 기준270/483을 회복할 수 없다.

검증227장에서 고정 LoG0.1/8px와 학습 후보0.01/4px를 합친 탐색적 대조는 양성 종양386/483,373/483,363/483에 일대일 대응하는 후보가 있음을 확인했다. 반면 전체 후보는41874/71757/78425개다. 이는 후보 공급 범위이며 최종 정밀도·F1·개선 결과가 아니다. 이 관찰을 보고 제안한 후속 연구이므로 같은 검증 자료의 반복 노출을 명시한다.

근거: `artifacts/experiments/ki67-union-design-20261113/preflight.json`, `candidate-feasibility.json`, `docs/KI67_RECALL_DIAGNOSIS.md`.

## 검토한 방법과 선택

1. **선택한 방향:** 고정 학습 검출기와 LoG의 후보를 합치고 영상 기반 CNN으로 제거한다. 현재 피크가 없는 정답의 후보를 보충할 수 있다. 후보 증가·연산 비용과 배경 대리 라벨의 오류를 감수한다.
2. 중심 지도 손실·학습 균형부터 바꾸는 방향은 이번 비교에서 보류한다. 기존 모델 전체를 재학습하면 후보 공급과 학습 변화가 함께 달라진다.
3. 임계값·간격만 다시 바꾸는 방법은 기존 실험에서 검사했다. 같은 피크 집합의 두 seed가 양성 재현율 기준에 못 미쳐 이번 주된 보완으로 선택하지 않는다.

**구현 담당자의 제안:** 새 CNN은 4종 세포 분류까지 다시 학습하지 않고 후보 유지/제거만 담당한다. 기존 LR와 CNN3개는 고정하고 새 위치에서 다시 분류한다. 분류기 변화와 후보 변화가 섞이는 정도를 줄이기 위한 결정이며 사용자가 모델 세부 구조를 직접 설계했다고 기록하지 않는다.

## 데이터와 분리

- Patherea P1 v1.1: train696장/15케이스, validation227장/4케이스, 기존 test407장/10케이스. 기존 manifest·split·파일/픽셀 SHA를 재사용하고 교차 분할 케이스·픽셀 중복을 검사한다.
- 학습 주석은 중심점으로, 전체 핵 윤곽이나 완전한 주석 영역 polygon을 제공하지 않는다. 무대응 후보를 전문가가 확인한 비세포/배경으로 단정하지 않는다.
- BCData validation133장은 이미 결과를 본 종양 주석 자료다. 추후 재평가에만 쓰고 설정·모델 선택에는 쓰지 않는다. 비종양 정답을 만들어4-class 평가하지 않는다.
- 원자료 재다운로드·사용자 코드 변경·추가 외부 전송은 필요하지 않다. 공개 자료의 기존 이용 조건을 유지한다.

## 후보와 추론 흐름

1. 기존 학습 검출기 seed20261117/18/19의 가중치를 동결한다. 각 seed의 기존 선택 설정을 대조군 A로 보존한다.
2. 실험 후보는 동일 가중치의 score0.01/간격4px 출력과 기존 LoG response0.1/간격8px 출력의 합집합이다. LoG sigma는 기존1.5/2.5/3.5px를 유지한다. 좌표가 정확히 같은 후보만 먼저 하나로 합치고 출처를 bitset으로 기록한다. 다른 검출기의 점수를 같은 척도로 취급하지 않는다.
3. 각 후보 주변 native32×32 RGB crop을 별도 이진 CNN에 입력한다. 영상 밖은 기존 crop 도구와 같은 흰색 padding이다. 모델은 유지/제거 logits2개를 출력하고 softmax의 유지 점수를 사용한다. 보정된 정답 확률·임상 신뢰도가 아니다.
4. 유지 점수 기준과 최종 최소 간격을 적용한다. 순서는 점수 내림차순, 동점 y/x 오름차순이다. 설정·후보가 같으면 결과가 결정적이어야 한다. 좌표는 원본 패치 픽셀 기준이다.
5. 남은 좌표에서 기존 LR/CNN20261113/14/15를 다시 추론하고 종양 양성률을 계산한다. 기존 후보의 예측 클래스를 복사하지 않는다. 추론 함수 입력에는 정답·split·reference class가 들어가지 않는다.

CNN 제안 구조: 채널8/16/32의3개 block, 각 block은3×3 Conv 두 개·LeakyReLU0.1·2×2 MaxPool. 마지막4×4 공간 배치를 flatten한 뒤 Linear(512,2). 위치 정보가 사라지는 전역 평균 대신 중심 주변 형태를 구분하도록 한다. 기존 모델은 수정하지 않는다. 외부 사전학습 가중치를 쓰지 않는다.

## 학습 표본과 고정 설정

- train에서만 표본·라벨을 만든다. 양성 표본의 기준은 공개 정답 중심이며, 각 중심에 일대일 대응한 통합 후보가 있으면 매 epoch50% 확률로 그 좌표를 사용한다. 그렇지 않거나 나머지50%에서는 정답 중심에 축별−3~3px 정수 jitter를 적용한다. 영상 밖 jitter는 중심을 유지한다. 추론에는 정답 중심을 넣지 않는다.
- 음성은 **미대응 후보 대리 라벨**이다. 통합 후보 중 모든 정답 중심에서12px 초과이고 이미지 가장자리24px를 제외한 후보만 사용한다. 애매한 근접 후보는 음성으로 쓰지 않는다. 주석이 없는 이미지에서는 음성을 만들지 않는다. 이 라벨도 누락된 실제 세포일 수 있다는 한계를 유지한다.
- 이미지당 음성 대리 후보 최대256개를 seed 고정 표본으로 선택한다. 서로 다른 검출기 원점수로 순위를 매기지 않는다. 모든 클래스의 양성 정답을 포함하며 새 임상 라벨을 만들지 않는다.
- 이진 cross-entropy, Adam lr0.001,12epoch, batch64, CPU thread2. 각 batch에서 양성/음성1:1. 각 label에서 가능한 train 케이스를 균등하게 뽑고 케이스 안에서 표본을 균등하게 선택한다. 한 epoch는 train 정답 수×2개의 표본을 뽑는다. 음성 표본이 있는 케이스 수를 보고한다.
- crop 회전90도/반전과 RGB배율0.9~1.1을 train에만 적용한다. validation/test에는 증강하지 않는다.
- detector17/18/19 각각에 gate seed17/18/19를 짝지어3회 학습한다. 검출기 자체를 새로 학습한3회가 아니며, 후보 차이와 gate 초기화·샘플 순서·증강 변동을 함께 포함한3개 파이프라인 비교다. seed 중 유리한 것만 고르지 않는다.
- 후보 생성기는 train 영상을 본 기존 모델이다. train 후보 난도와 미주석 음성의 편향 가능성을 적고, validation 케이스는 gate 학습에서 제외한다. 독립적 학습 후보를 확보한 것으로 주장하지 않는다.

## 실행 전에 고정할 선택·성공 기준

매 epoch의 validation 점수에서 gate 유지 threshold `[0,.05,.1,.2,.3,.4,.5,.6,.7,.8,.9,.95,.99,1]`와 최종 간격 `[4,6,8]`만 비교한다. 각 seed의 기존 A와 동일한6px 일대일 위치 대응으로 평가한다.

선택 가능한 설정은 다음을 모두 충족해야 한다.

1. validation pooled FP와 FN이 각각 같은 seed의 A 이하이고, 둘 중 하나 이상은 엄격히 감소한다.
2. 기존 LoG 검증 재현율 기준을 그대로 유지한다: 케이스 평균 재현율≥0.4797951648158369, pooled 양성 종양 위치 재현율≥270/483, pooled 음성 종양 위치 재현율≥439/1292.
3. 각 검증 케이스의 재현율이 A의90% 이상이다. 정답이0인 경우의 정의는 기존 지표 계약을 따르며 이번 고정 검증4케이스는 모두 정답이 있다.

조건을 통과한 설정 중 케이스 평균 위치F1 최대를 선택한다. 동점은 재현율, 더 이른 epoch, 더 높은 threshold, 더 큰 간격 순이다. 임계값1은 부동소수점 score가1인 후보를 남길 수 있으므로 무조건 빈 결과라는 가정을 하지 않는다.

**통과 설정이 없는 seed는 미충족으로 기록한다.** 같은 실행에서 기준을 낮추거나 데이터·threshold 범위를 늘리지 않는다. 진단용 최고F1 체크포인트는 별도 표시할 수 있지만 평가 대상으로 선택된 모델로 바꾸지 않는다. 세 seed 모두 통과해야 이번 검증 조건의3seed 재현으로 기록한다. 단3개라는 한계와 같은4검증케이스 반복 노출을 유지한다.

## 고정 후 기존 자료 재평가

세 seed 학습·선택을 모두 마친 뒤 소스·프로토콜·입력·선택·체크포인트 해시를 잠근다. 조건을 통과한 seed만 기존 test407/BCData133에서 재평가한다. 실패 seed를 숨기지 않고 선택 실패 수를 함께 보고한다. 모두 실패하면 새 test/외부 추론을 진행하지 않고 검증 실패 분석으로 종료한다.

대조군 A(기존 학습 후보), B(정확 좌표 중복만 정리한 통합 후보, gate 없음), C(선택 gate+간격)를 기록한다. B는 후보 공급 범위 진단이며 동일 억제 정책의 대조군이 아니다. 따라서 A→C의 결과는 통합 파이프라인 효과로 설명하고 CNN만의 단독 인과 효과로 단정하지 않는다. 별도로 선택된 C의 같은 gate 점수·간격에서 threshold0을 적용한 C0를 비교해 threshold 제거 효과를 관찰한다. C0/B로 설정을 다시 고르지 않는다.

- 위치 TP/FP/FN·precision/recall/F1, 참조 클래스별 위치 재현율, 내부4-class/외부종양2-class F1.
- 케이스별 양성·음성 종양 수, 양성률 MAE와 분모0 건수, 유효 집계 수. 내부는10케이스, 외부는133이미지의 집계임을 구분한다.
- detector/gate/classifier seed별 표와 각 이미지/케이스의 변화. 양성률만 좋아진 경우 전체 정확도 개선으로 쓰지 않는다.
- 입력 크기·장치·thread·범위를 적은 처리 시간·메모리. 참고 측정이며 통제된 속도 벤치마크로 확대하지 않는다.
- 재평가에서도 A보다 FP/FN이 함께 감소했는지 판정한다. 내부가 좋아도 외부 지표가 악화되면 그대로 보고하고 기본 분석을 교체하지 않는다. 반복 사용한 외부 자료이며 새 미노출 일반화 입증이 아니다.

## 구현·검증·보존

새 전용 모듈/실행기에서 후보 합집합·대리 라벨·이진 CNN·조건 선택을 구현한다. 기존 detector/classifier/learner 함수와 공개 데모 기본 동작은 보존한다. 준비→후보 자료 생성→gate 학습/검증 선택→해시 고정→조건 충족 seed 재평가→독립 감사의 단계가 서로 섞이지 않게 한다.

의미 있는 테스트는 후보 원점수 비호환·정확 좌표 중복/출처·좌표/경계·미대응 대리 라벨/ignore·빈 결과·NaN/Inf fail-closed·validation 전용 선택·미충족 seed·원본 보존·정답 없는 추론 경로를 검증한다. 수치 감사는 별도 저장 후보/예측에서 일대일 대응과 모든 집계를 다시 계산한다. 기존 Dice42/6과 적절한 회귀 검사를 유지한다. 공개 외부 ZIP에는 BCData 원영상·개별 좌표를 넣지 않는다.

검토 화면은 새 실험 결과가 나온 후에만 만들고, 기존값과 비교값·같은 위치·추가/제거/놓친 정답·지표 범위를 표시한다. 최종 통과·실패·악화 사례를 포함한다. 사용자는 결과가 준비되면 한 사례씩 확인하며 코딩·학습·자동 감사는 사용자 수행으로 기록하지 않는다.

현재 로컬 디스크 여유는 약15MiB다. 실행 전에 해시·원격 보존이 확인된 재생성 가능한 작업 복사본을 sparse checkout에서 제외하는 등 가역적 방법으로 공간을 확보한다. 원자료·사용자 파일·미게시 실험·이전 결과/ZIP의 Git 원본을 삭제하지 않는다. 이미지/crop cache는 메모리, 예측·피크는 압축 저장한다. 필요한 여유 공간이 없으면 실행을 시작하지 않고 환경 제약을 명시한다. 낮은 공간을 검사 우회로 해결하지 않는다.

## 완료 범위

성능 향상을 미리 약속하지 않는다. 사전 기준·소스·해시·3seed 선택 결과·가능한 재평가·실패·감사·검토 화면까지 결과에 맞게 기록하는 것이 완료 조건이다. 임상 검증, WSI 전체 핵 정답 검증, 새로운 미노출 외부 검증, main 병합·공개 데모 배포는 이 실험의 완료 조건이 아니다.

사용자에게 확인할 최종 항목은 이 설계의 실행 승인이다. 세부 선택 기준을 바꾸길 원하면 실행 전에 수정해 고정한다. 승인 전에는 새 gate 모델 코드·학습을 시작하지 않는다.

별도 설계 검토 결과: 중요한 미정 질문 없음(`nothing important left`). 이는 실행·성능 검증 결과가 아니며 사용자 승인과 별개다.
