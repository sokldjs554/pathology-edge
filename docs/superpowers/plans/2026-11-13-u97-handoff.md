# U97까지 전달 자료 통합

사용자 승인 범위: 남은 보완을 순서대로 진행. 이 단계는 최신 근거 통합과 한 가지 개인 화면 검토 준비이다.

1. 기존 U86 ZIP의 문서·그림·실험 근거를 유지하고 자동 Ki-67, 후보 제거, 학습 중심, 재현율 조건 실험을 연결한다.
2. 현재 요약·공고 대조에서 자동 검출 미구현이라는 오래된 표현을 고친다. 구현 완료와 성능 개선 성공을 구분한다.
3. U87–U97의 실제 응답만 직접 수행 기록에 포함한다. CNN–ViT 오류 그림 확인은 STEP84/U98 예정으로 둔다.
4. 큰 원본·모델·추론 재현 묶음은 기존 고정 커밋 링크와 SHA로 보존하고, 통합 ZIP에는 결과·검토 화면·현재 문서·사용자 원문을 넣는다.
5. 숫자와 저장 JSON, 모든 ZIP 멤버의 SHA/CRC, 문서·HTML 연결, 사용자 작성 7파일 보존을 검증한다. 문서 통합을 새 학습·추론이나 사용자 테스트로 세지 않는다.
6. draft PR #2에 기록하고 실제 다운로드 바이트를 확인한다. 자동 병합·공개 데모 변경은 하지 않는다.

완료 조건: 최신 전달 ZIP의 다운로드와 내부 화면이 확인되고, 사용자에게 09_1 오류 그림 확인 한 단계만 안내한다. 개선 성공·임상·전체 WSI 정답 검증은 완료로 바꾸지 않는다.

- 사용자 작성7파일 보존. U98은 예정이며 사용자 응답 없음. 자동 병합·공개 데모 변경·새 학습/추론 없음.
