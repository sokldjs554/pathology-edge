# Automatic Ki67 Patch Analysis Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Implement image-only patch detection/classification/quantification, then fairly compare a morphology classifier and assess external evidence.
**Architecture:** Small independent detector/evaluation/CNN modules and a staged frozen research runner. Read-only reuse of existing IHC data/splits/model; separate outputs and explicit zero-denominator handling.
**Tech Stack:** Python3.12, NumPy2.5.4, SciPy1.18.1, PyTorch2.15CPU, Pillow, existing locks.
**Spec:** docs/superpowers/specs/2026-11-13-auto-ki67-design.md

## Global Constraints
- Existing sources/data/learners/results/demo unchanged. Fresh output directories only.
- Fixed15/4/10case split,3seeds,12epochs, detector9settings, native6px matching; see spec for exact choices.
- Never pass GT centers into prediction or tune using known test outcomes. No clinical/generalization success invented.
- Keep raw datasets private; cite/reuse figures under their actual licenses.

## Review Focus
- Empty predictions/tumor denominator: explicitnull ratio, misses counted.
- Crowded nuclei: one-to-one maximum cardinality beats nearest-only greedy; no double matching.
- Border48px crops and channel/coordinate order: consistent white padding, finite real input.
- Invalid model/data and partial run: fail before replacing any existing output.
- Reused tests and absent external non-tumor labels: exact scope, no inflated independence or inappropriate four-class scores.
