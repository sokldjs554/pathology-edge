# STEP84 — 본인 CNN–ViT의 09_1 오류 그림 확인

상태: **요청한 그림의 표시 확인 완료(U98)**. 사용자가 “응 잘 보이는것으로 확인되었어”라고 응답했다. 09_1 동일 영역 확대 그림의 표시 확인 범위이며, 독립 수치 검산·오류 해석·09_6 검토·새 실행으로 확대하지 않는다. 아래는 당시 안내이다.

1. 새 Cowork 전달 ZIP을 전체 압축 해제하고 `START_HERE.html`을 연다.
2. **이번 확인: CNN–ViT 09_1** 링크를 누른다. 연결된 오류 보고서에서 `09_1 · 전체 Dice 최대 하락`을 찾는다. 직접 경로는 `artifacts/experiments/user-cnn-vit-errors-20261112/index.html`이다.
3. 전체 비교 그림 아래의 **노란 상자 동일 영역 확대**가 보이는지만 확인한다. 원영상·정답·CNN 오류·ViT 오류·변화 지도를 같은 위치에서 보여 준다. 청록은 FP, 분홍은 FN이다. 작은 화면에서는 그림 영역을 가로로 이동해 볼 수 있다.

예상 표시는 이미지 전체 Dice **0.402373→0.344220**과 선택 영역 Dice **0.5875→0.3907**이다. 서로 다른 평가 범위의 점수다. 영역 `[160,128,288,256)`은 128×128px이며 교정210px·악화1,068px는 핵 개수가 아니다. 전체10장 중 전체 Dice가 가장 많이 하락한 이미지를 고르고, 그 안에서 악화−교정 픽셀이 큰 영역을 선택했다.

이 그림은 사용자가 실행·제출한 seed20261113의 저장 확률과 정답을 제공된 도구로 다시 대조한 것이다. 여기서 그림을 여는 것은 새 추론이 아니다. 그림 표시를 확인해도 모든 픽셀 독립 검산·오류의 생물학적 원인 판정·09_6 검토까지 완료한 것으로 기록하지 않는다.

이 확대 그림의 표시 확인을 마쳤다. 다음은 [STEP85](STEP_85.md)의 09_6 그림 확인 한 단계이며 아직 응답 대기다. 기존 U97 전달 ZIP은 발행 당시 기록을 그대로 보존한다.
