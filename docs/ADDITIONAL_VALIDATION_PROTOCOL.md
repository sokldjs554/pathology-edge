# 추가 검증 범위와 사전 결정

기준 소스: `ad739fd2456e3a2ba1d2b39d2832ad4e514a989e`. 사용자는 Cowork 전달용 완료 작업 정리와 보정 모듈 추가 seed, 외부 데이터, 임상, WSI 전체 정답 기반 검증을 요청했다. 기존 결과와 사용자 원본 파일은 보존한다.

## 결정

1. 보정 모듈은 기존 20261116에 이어 20261117·20261118을 비교한다. 소스·환경이 동일함을 입증할 수 없으면 같은 개발 환경에서 세 seed 모두 새로 실행한다. 사용자 Codespaces의 20261116 결과와 개발 환경 결과를 합쳐 독립 반복으로 세지 않는다. 각 seed에서 두 방식은 같은 초기 backbone 및 crop/augmentation 순서를 사용한다. arm 순서는 교대한다.
2. 16 epoch × 20 step, batch 8, crop 128, Adam 0.001, BCE+사용자 soft Dice, 검증 임계값 0.35/0.5/0.65 등 기존 조건을 유지한다. 검증 이미지 10장·2그룹에서 선택한 결과이며, 같은 검증셋 반복 사용의 한계가 남는다. 전체·경계·내부 Dice와 paired 차이, sample SD, 상승/동일/하락을 보고한다.
3. 외부 검증은 공개 핵 주석 H&E 자료의 라이선스·출처·범위를 확인한 후 수행한다. 데이터와 평가 대상 모델·임계값·부분집합을 결과 확인 전에 고정한다. 추가 학습이나 외부 정답 기반 threshold 선택을 하지 않는다. 픽셀 Dice를 핵 검출 정확도나 임상 성능으로 설명하지 않는다.
4. 전체 WSI 추론 완료와 전체 WSI 정답 기반 성능 검증을 구분한다. ROI/타일 주석 또는 종양 영역 주석을 슬라이드 전체의 핵 정답으로 간주하지 않는다. 실제 핵 정답의 공간적 범위와 누락 여부를 확인할 수 없는 경우 전체 WSI 정확도를 산출하지 않는다.
5. 임상 검증에는 대상 질환·사용 목적, 승인된 데이터 접근, 독립된 환자 코호트와 전문가 기준, 사전 평가 계획이 필요하다. 사용자에게 자원 보유 여부를 질문했다. 공개 연구 데이터 평가를 임상 검증으로 표시하지 않는다.

## 산출물과 확인

- Cowork 전달 문서: 완료한 기능, 실제 사용자 작성·실행·검토, 수치와 근거 링크, 작성 시 금지할 과장 표현.
- 추가 seed: 새 실행 폴더, protocol/source/model/data hash, 원시 예측, 재계산 감사 및 집계.
- 외부 데이터: 접근·라이선스·중복 점검, 고정 protocol, 이미지별 예측과 원시 지표, 평균과 실패 사례.
- WSI·임상: 수행한 범위, 이용 가능한 정답, 실제 미실시 항목 및 필요한 자원.
- 코드 수정은 관련 단위 테스트로 확인하고, 새 결과는 원시 확률과 정답에서 독립 재계산한다.
