# 18단계: 강조 수치의 단위 해석

상태: **2026-11-09 사용자 해석 확인 완료**. 사용자는268px가 겹침 방식에서 정답과 일치하게 된 픽셀 수이며 추가로 검출한 핵 개수가 아니라고 설명했습니다. [답변·확인 범위](../artifacts/learning/step18-review.json). 아래는 완료한 질문의 참고이며, 다음은 [19단계 처리 시간 확인](STEP_19.md) 하나입니다.

## 볼 곳과 질문 하나

현재 `TNBC 11_1`의 오른쪽 **검토 결과 → 이미지 → 선택 경계**에서 국소 Dice 바로 아래의 설명을 읽습니다. 화면을 닫았다면 [데모](https://pathology-edge-lab.ykh13571.chatgpt.site/)에서 **좋아진 경계 보기**를 누르면 같은 사례가 열립니다.

저장 결과에 따른 표시는 **청록: 정답 일치로 변경 268px**, **분홍: 불일치로 변경 11px**입니다. A는 무겹침 처리, B는 겹침 처리 후 병합입니다. 수치는 선택된 64×64 상자와 고정 경계 띠가 겹치는 영역에 해당합니다.

**‘정답 일치로 변경 268px’를 “핵 268개를 추가로 찾아냈다”고 설명해도 될까요? 268이 무엇을 센 값인지 포함해 한두 문장으로 설명해 주세요.**

답변은 수치 해석 확인으로 기록했습니다. 새 화면 캡처나 픽셀 수 표시를 직접 확인했다는 별도 보고는 받지 않았습니다. 다른 화면 조작이나 추론 실행을 완료한 것으로 기록하지 않습니다.

## 검토 결과

해석은 정확합니다. 코드의 집계 조건은 `A != 정답`이면서 `B == 정답`인 픽셀입니다. 핵 픽셀을 놓쳤다가 맞힌 경우뿐 아니라 배경을 핵으로 잘못 예측했다가 바로잡은 경우도 포함할 수 있습니다. 핵의 개수와 변경된 픽셀의 개수는 구분해야 합니다.

## 제공 자료와 Codex 확인 범위

화면의 색상 설명은 `dist/index.html`, 변경 집계와 표시는 `dist/review-ui.js`의 `evidenceLayer`·`open`에 있습니다. 저장 결과는 `dist/cases.json`의 `11_1-improved`입니다. Codex는 이 정의를 읽고 [이전 PNG 대조](../artifacts/learning/step17-preparation.json)의 입력 파일 해시가 현재 파일과 같은지 확인했습니다. 이번에 새 브라우저 검사·추론을 실행하지 않았습니다.
