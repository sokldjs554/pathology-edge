# STEP82 — 누락 감소와 오검출 증가를 같은 영상에서 확인

상태: 사용자 확인 대기. 이번 구현·추론·자동 검증을 사용자 수행으로 기록하지 않는다.

지금은 아래 한 단계만 확인한다.

1. 전달 ZIP을 풀고 `review.html`을 브라우저에서 연다.
2. 첫 사례 `테스트 · 찾은 정답 증가가 가장 큰 영상`, `CNN seed20261113`을 유지한다.
3. A의 **TP7 / FP9 / FN23**, B의 **TP21 / FP49 / FN9**를 확인한다.
4. `놓친 정답 ×`를 껐다 켜면서 같은 위치의 빨간 표시를 비교한다.

예상: B에서 놓친 정답은23→9개로 줄지만 FP는9→49개로 늘어난다.
이는 선택한 한 영상의 결과이며 전체407장 평균을 대표하지 않는다.

이 화면과 전환이 정상인지 알려 주면 확인한 범위만 기록한다. 테스트 로그 실행이나
독립적인 수치 검산, 다른 사례·전체 결과 검토까지 완료한 것으로 확장하지 않는다.

빈 화면/오류가 나면 브라우저 이름·버전, 파일명, 화면 캡처 또는 콘솔 오류를 보내면 된다.
