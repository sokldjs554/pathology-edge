# 영상만 입력하는 자동 Ki-67 패치 분석

2026-11-13 (Asia/Seoul). **자동 분석의 초기 연구 기준선은 구현했지만, 과다 검출이 커 실용적 정확도를 달성했다고 말할 수 없다.** 양성률 오차만 보고 세포 분석 전체가 개선됐다고 판단해서도 안 된다.

## 무엇을 실제로 구현했는가

RGB 패치 → 광학 밀도의 여러 크기 LoG 극값 → 거리 기반 후보 억제 → 세포 분류 → 예측 종양 세포의 양성률 계산을 연결했다. 추론 함수와 CLI에는 정답 좌표를 받는 인자가 없다. 정답 좌표는 학습과 사후 평가에만 사용한다.

비교 A는 기존 색상 통계 40개와 로지스틱 회귀다. 비교 B는 48×48 RGB 크롭을 실제 입력받는 새 CNN(72,340개 파라미터)이다. 16·32·64채널의 3×3 convolution 두 개와 pooling을 반복하고, 평균 pooling 후 네 클래스를 분류한다. 두 방식은 **동일한 자동 검출 위치**를 사용한다. 검출기는 학습된 신경망이 아니며, 공식 Patherea-P2P 구현/논문 재현도 아니다. CNN 파라미터 수는 기존 분류기와 다르다.

세포 클래스는 양성 종양·음성 종양·양성 비종양·음성 비종양이다. 양성률 = 양성 종양 세포 수 / (양성 종양 + 음성 종양 세포 수). 분모가 0이면 `null`을 반환한다. 예측 점수는 보정된 정답 확률이 아니다.

## 데이터, 선택과 평가의 분리

- [Patherea Breast P1 v1.1](https://huggingface.co/datasets/ds2268/patherea), 고정 revision `eb8a6c38cb1df3381b22385ed7b6175091c87ea5`, CC BY-NC 4.0. 원본 ZIP SHA `1194dbfb145ca3aee1a27fcff9d92799d73d34b5da972118424a7b67047034e7`.
- 원본 이미지 1,330장·29케이스와 주석 19,972점을 사용한다. 기존의 train 696장/15케이스, validation 227장/4케이스, test 407장/10케이스 분리를 유지한다.
- 파일·픽셀 해시, 케이스 중복, 마스크별 해시와 좌표 수를 검사한다. preparation 단계에서는 테스트 파일을 해시만 확인하며 디코딩·추론·평가하지 않는다.
- 기존에 테스트 407장의 조건부 분류 결과를 확인했으므로 **새로운 미노출 테스트가 아니다**.
- 검출 후보 9개 설정을 사전 고정하고 validation 케이스 평균 검출 F1로 선택했다. 선택은 response 0.10, 최소 거리 8px. LoG sigma 1.5·2.5·3.5px는 고정이다.
- CNN은 12epoch, Adam 0.001, batch 64, train 클래스 빈도 역수 가중치, flip/90도 회전/RGB 0.9~1.1배 증강으로 학습했다. validation의 정답 중심 위치 분류 macro-F1로 epoch를 선택했다.
- seed 20261113/14/15를 모두 공개한다. 선택 epoch는 각각 11/12/7, validation macro-F1은 0.598192/0.690429/0.656292다. 테스트를 보고 seed를 선택하지 않았다.
- 검출 설정·소스·가중치 SHA를 고정한 뒤 테스트를 평가했다. 해당 시점은 `selection-lock.json`과 `evaluation-started.json`에 기록한다.

## 내부 테스트 결과 — 기존 407장·10케이스

| 방식 | 검출 F1 | 4-class end-to-end macro-F1 | 이미지 양성률 MAE (%p) | 케이스 양성률 MAE (%p) |
|---|---:|---:|---:|---:|
| 동일 검출기 + 색상 LR | 0.098239 | 0.070438 | 21.018811 | 19.776615 |
| 동일 검출기 + CNN 20261113 | 0.098239 | 0.056976 | 17.583749 | 13.505564 |
| 동일 검출기 + CNN 20261114 | 0.098239 | 0.066858 | 15.595658 | 12.756412 |
| 동일 검출기 + CNN 20261115 | 0.098239 | 0.053924 | 16.563498 | 14.430800 |

정답 6,419점, 자동 후보 69,152점 중 TP 3,712 / FP 65,440 / FN 2,707이다. 검출 precision 0.053679, recall 0.578283이다. 실제 핵보다 훨씬 많은 후보가 생기는 것이 가장 큰 약점이다.

CNN 세 seed 모두 케이스별 양성률 MAE는 줄었지만 end-to-end macro-F1은 낮아졌다. 따라서 “CNN을 붙여 자동 세포 분석 정확도가 개선됐다”고 요약할 수 없다. **양성률 오차 감소와 개별 세포 검출·분류 정확도 개선은 다른 주장**이다. 학습하지 않은 배경 후보도 네 세포 클래스 중 하나로 강제 분류되는 구조가 과다 집계의 한 원인이다. 이후 연구에서는 배경/비세포 거부 또는 학습 기반 검출기를 train/validation에서 검토하고, 이미 노출된 외부 결과를 새 미노출 검증처럼 재사용하지 않아야 한다.

이미지 양성률 MAE는 공통으로 395/407장에서 계산된다. 나머지 12장은 제공 정답 또는 예측의 종양 분모가 0이어서 정의되지 않는다. 케이스 양성률 MAE는 케이스 안 이미지들의 **세포 수를 합쳐 비율을 구한 뒤** 10/10케이스에서 평균한다. 이미지 비율을 단순 평균한 값이 아니다. 유효 분모 범위와 정확한 정답/예측 세포 수는 원본 JSON에 있다.

반경 6 원본 픽셀 안에서 클래스와 무관하게 일대일 최대 대응 수를 먼저 찾고, 그 중 거리 합을 최소화한다. 잘못 분류된 대응은 해당 클래스 FP와 FN에 반영한다. 점 주석 평가이며 윤곽 분할 Dice가 아니다. 두 집합이 모두 비면 검출 F1은 0, 매칭 정확도는 null로 처리하며 자동 성공으로 기록하지 않는다.

## 처리 조건

개발 환경 CPU는 AMD EPYC 9V74, process affinity 5 logical CPU, PyTorch CPU thread 2개다. Codespaces에서 사용자가 이전 실험을 실행했던 AMD EPYC 7763과 다른 환경이다. Python/PyTorch/NumPy 등 실제 버전은 `protocol.json`과 `environment.json`에 기록했다.

학습+검증 실행 시간은 세 seed에서 각각 191.55/190.19/189.68초였다. 이미지당 단일 detector+classifier 실행 중앙값은 LR 약 36.29ms, CNN 약 125.84~128.01ms였다. 영상 파일 읽기·정답 평가·모델 로딩은 제외한다. **예열·반복·CPU 자원 통제를 갖춘 속도 벤치마크가 아닌 참고 측정**이며 이전 프로젝트 시간과 직접 비교하지 않는다.

## 외부 전이 평가

[외부 사전 규약](AUTO_KI67_EXTERNAL_PROTOCOL.md)에 따라 BCData 공식 validation 133장 전체를 평가했다. 원본 399개 파일의 크기·CRC·SHA를 확인하고, 같은 클래스의 중복 좌표 42개를 정규화한 종양 정답 21,762점을 사용했다. Patherea 1,330장 및 기존 BCData test 402장과 전체 픽셀 해시가 같은 영상은 없었다. 환자·슬라이드·부분 크롭 중복은 검증하지 못했다.

| 방식 | 종양 검출 F1 | 양성·음성 종양 end-to-end macro-F1 | 이미지 양성률 MAE (%p) | 유효 이미지 |
|---|---:|---:|---:|---:|
| 색상 LR | 0.095577 | 0.067704 | 21.109443 | 133/133 |
| CNN 20261113 | 0.107922 | 0.060548 | 57.094769 | 133/133 |
| CNN 20261114 | 0.108676 | 0.077071 | 43.913940 | 133/133 |
| CNN 20261115 | 0.114335 | 0.065849 | 55.357723 | 133/133 |

**외부 개선을 입증하지 못했다.** 종양 검출 F1은 세 seed 모두 소폭 증가했지만 절대 성능이 낮고, 양성률 MAE는 세 seed 모두 악화됐다. 두 클래스 macro-F1은 한 seed만 상승했다. 내부에서 양성률 오차가 줄었다는 관찰을 외부 일반화 성공으로 표현하지 않는다. 평가 후 설정을 바꿔 같은 133장을 다시 새 미노출 평가로 주장해서도 안 된다.

외부 자료에는 비종양 정답이 없으므로 예측 종양 클래스만 정답 종양 점과 대조한다. 제공되지 않은 비종양 라벨을 만들어 4-class 평가를 하지 않는다. 이 수치는 BCData의 이미지 단위 종양 주석 벤치마크이며 임상 검증·WSI 전체 정답 평가가 아니다. 외부 133×4 = 532건의 저장 예측도 독립 재집계에 모두 일치했다.

## 검증 및 검토 화면

- 기존·신규 전체 CI: 최종 가중치 검사 수정 코드 `a12a157`에서 **501 passed**, 기존 Dice 42개/평균 6개 재계산 일치, 정적 데모 검사 통과.
- 별도 감사 스크립트가 내부 407장×4방식 = **1,628건**을 다시 집계했다. 최대 대응 수는 별도 이분 그래프 matching 알고리즘으로 대조했다. 원본 예측 SHA `9c38381d5de3afa1e3ce4f372b82b2b8275030f97a54cb28345d7cbf8d6ddc93`.
- 저장된 한 이미지에 RGB-only CLI를 다시 실행하여 자동 위치·클래스가 기존 산출물과 일치하는지 검사했고 일치했다. 사전 계산 JSON을 추론 결과라고 가장하지 않는다.
- `viewer.html`은 저장 결과 검토 화면이다. 3사례×4모델 12개 전환과 점 오버레이를 브라우저에서 검사했다. 1440px 데스크톱 및 390px 작은 화면을 캡처했다. 긴 파일명으로 생긴 모바일 가로 넘침을 재현하고 수정했다.
- 기본 예시는 첫 seed 20261113의 개별 이미지 4-class F1 차이로 고른 최대 하락/중앙/최대 상승이다. 전체 성능을 대표하는 예시라고 표현하지 않는다.
- 관리형 Chromium에서는 `file://` 접근이 정책으로 차단되어, localhost HTTP로 동일 HTML을 열어 검사했다. 외부 라이브러리나 데이터 요청이 없는 독립 HTML이다.
- **사용자 화면 확인은 U87에 기록했다.** 첫 사례에서 색상 통계→CNN 20261113 전환 요청에 “확인했어”라고 응답했다. 후속 U88에서 내부 양성률 오차 감소와 macro-F1 하락을 구분한 해석을 확인했다. 원본 수치의 독립 재계산·전체 사례 검토는 미확인이며 새 구현·학습·추론·테스트를 사용자 수행으로 추가하지 않았다. [검토 범위](AUTO_KI67_REVIEW.md)를 참고한다. 발행 ZIP은 응답 이전의 기록으로 보존한다.

## 범위

자동 패치 기준선의 실행과 실패 분석을 완료하는 것이 이번 목적이다. 임상 Ki-67 assay, 전문가 hotspot 선정, WSI 전체 검출·정답 검증은 아니다. 기존 TNBC/MoNuSeg/NuCLS H&E 실험의 수치와 한계, 기존 데모는 바꾸지 않았다. IHC의 양성률 변화가 기존 H&E 보정 모듈의 외부 일반화 성공을 뜻하지 않는다.

독립 코드 검토에서는 한 가지 중요한 재사용 오류를 추가로 수정했다. CNN 가중치가 NaN이거나 유한 가중치로 계산한 출력이 overflow하면 `argmax`가 클래스 0을 내놓을 수 있었다. 현재 소스는 빈 검출에서도 가중치를 검사하고, 두 분류기의 확률이 유한·정규화된 값인지 확인한 뒤에만 클래스를 고른다. 4개 회귀 테스트가 수정 전 실패하고 수정 후 통과했으며, 관련 50개 테스트가 통과했다. **역사적 실험의 소스 snapshot·모델·수치는 변경하지 않았다.** 세 실제 체크포인트는 모두 유한하고 기록된 결과는 이 오류의 영향을 받지 않았다. 과거 결과 재현은 제공된 정확한 snapshot과 SHA가 일치하는 신뢰된 체크포인트를 사용한다.
