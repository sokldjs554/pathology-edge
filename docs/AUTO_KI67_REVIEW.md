# 자동 Ki-67 후속 검토 — U87–U95 확인 완료

[학습한 세포 중심 첫 화면](STEP_80.md)의 후보 수 표시·위치 지도 전환 요청에 사용자가 “응 잘 작동해”라고 응답해 U94에 기록했다. 새 검출기 구현·학습·평가나 개별 수치의 독립 검산을 사용자가 수행한 것으로 기록하지 않는다. 비교 결과는 [별도 보고서](KI67_LEARNED_CENTERS.md)에 정리한다.

2026-11-13 KST. 아래 아홉 가지 요청에 대한 사용자 응답을 확인했다. 제공된 구현·개발 환경에서 수행한 학습·평가를 사용자 실행으로 바꾸지 않는다.

| 기록 | 확인한 범위 |
|---|---|
| U87 | ZIP의 viewer.html 첫 사례에서 색상 통계→CNN 20261113 화면·모델 전환 요청에 확인 응답 |
| U88 | 내부 케이스 양성률 MAE 19.78→13.51%p 감소와 macro-F1 0.0704→0.0570 하락을 구분하고 전체 정확도 향상으로 단정하지 않음 |
| U89 | 제공된 후보107·정답7·대응3으로 위치 기준 FP104·FN4 계산 |
| U90 | 비세포 거부 기능이 없는 네 클래스 분류기 교체가 검출 후보 제거를 뜻하지 않는다는 구조 해석 |
| U91 | 이미 확인한 BCData133장으로 기준을 조정한 뒤 같은133장을 평가하면 새 미노출 검증이 아닌 재평가라는 원칙 해석 |
| U92 | 후속 후보 제거 ZIP의 첫 사례 전후 수치 표시·회색 제거 표시 전환 요청에 정상 동작 확인 응답 |
| U93 | 검증 자료의 재현율 유지 조건이 외부 자료에도 보장되는 것은 아니며 BCData 재현율 하락을 근거로 일반화할 수 없음을 설명 |
| U94 | 학습한 세포 중심 첫 사례의 후보107→13개 표시·위치 지도 전환 요청에 정상 동작 확인 응답 |
| U95 | 전체407장 검출 F1 상승과 재현율 하락을 근거로 놓친 정답 세포가 늘었다고 해석 |

근거는 `artifacts/learning/step73-review.json`부터 `step81-review.json`까지의 사용자 원문과 질문 범위다. 구체적인 클릭 로그·원본 좌표의 독립 대응·주석 전수 검수·전체 이미지/seed 검토·새 학습/추론/자동 테스트는 확인된 사용자 수행에 포함하지 않는다.

U87의 첫 화면 검토에 제공했던 순서는 첫 **가장 큰 F1 하락** 사례에서 원영상·정답·자동 예측을 구분하고, 색상 통계와 CNN 20261113을 전환하는 것이었다. 두 방식은 동일한 자동 검출 위치를 사용하고 분류기만 바꾼다. 발행 ZIP은 응답 이전의 기록으로 보존한다.

초기 검출기는 과다 후보가 많고 외부 CNN 양성률 오차는 세 seed 모두 악화됐다. 이후 [후보 제거 실험](KI67_CANDIDATE_FILTER.md)은 Patherea 학습·검증에서 기준을 고정해 수행했다. 내부 검출 F1은 상승했으나 BCData133장 재평가에서는 네 방식의 F1이 모두 하락했다. 새 미노출 외부 검증이나 임상·WSI 전체 정답 검증 완료를 뜻하지 않는다. 새 전후 화면의 첫 사례 확인 응답은 U92에 기록했다. U92는 전수 화면 검토·독립 검산·새 실행으로 확대하지 않는다. 별도 후속 답변에서 검증 재현율 유지 조건의 외부 보장 불가를 설명한 범위를 U93에 기록했다.

학습한 세포 중심 ZIP과 그 안의 문서는 U94 응답 이전의 발행 기록으로 보존한다. 이번 응답은 저장소의 별도 후속 기록으로 추가했으며, 새 ZIP 발행이나 사용자 모델 실행을 뜻하지 않는다.

U95는 제공된 F1·재현율 변화의 올바른 해석이다. 이어진 원인 질문을 위해 저장 결과의 TP/FP/FN과 양성·음성 개수를 별도 대조했으며, 그 대조·설명은 사용자 직접 실행이나 원인 규명으로 기록하지 않는다. `artifacts/learning/step81-result-analysis.json`은 새 추론 없이 저장 수치로 만든 설명 근거다.
