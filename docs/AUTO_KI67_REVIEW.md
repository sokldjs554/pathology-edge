# 직접 검토할 다음 한 단계 — 아직 수행 전

기존 직접 작성·실행·검토 기록은 U86까지 유지한다. 이번 자동 Ki-67 구현·학습·외부 평가는 제공된 구현과 개발 환경에서 수행한 작업이다. 이 문서를 읽거나 화면을 열었다는 응답을 받기 전에는 본인 검토 완료로 기록하지 않는다.

전달 ZIP의 `viewer.html`을 압축 해제한 뒤 브라우저로 연다.

1. 첫 번째 **가장 큰 F1 하락** 사례를 그대로 둔다.
2. 세 화면에서 원영상, 제공된 정답 점, 자동 검출 점이 구분되는지 확인한다.
3. ‘예측 모델’을 **색상 통계 + 로지스틱 회귀 → CNN · seed 20261113**으로 바꾼다.
4. 자동 검출 점의 위치·개수는 같고, 분류 색과 양성률의 분자·분모가 바뀌는지 확인한다.

예상되는 동작은 모델 두 개가 **동일한 영상 기반 검출기**를 사용하고 분류기만 바꾸는 것이다. 결과가 나빠진 사례를 의도적으로 함께 제공한다. 보이는지·전환되는지 먼저 알려 주면 그 다음 한 가지 해석 질문으로 이어간다. 지금 사용자에게 새 학습이나 여러 과제를 한꺼번에 요구하지 않는다.
