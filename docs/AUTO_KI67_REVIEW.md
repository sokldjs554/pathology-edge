# 자동 Ki-67 검토 — 화면·지표·검출 오류·구조 해석 U87–U90 확인 완료

2026-11-13 KST, 직전 첫 사례 화면·모델 전환 안내에 사용자가 “확인했어”라고 응답해 U87에 기록했다. 아래는 확인을 요청했던 순서다. 이후 내부 지표의 반대 방향 변화에 대한 해석을 U88에, 제공된 대응 수로 FP104·FN4를 계산한 답변을 U89에 기록했다. U90에서는 클래스 변경과 후보 제거를 구분한 구조 해석을 확인했다. 구체적인 원본 수치 재계산·전체 사례 검토는 확인하지 않았다. 이번 자동 Ki-67 구현·학습·외부 평가는 제공된 구현과 개발 환경에서 수행한 작업이며, 사용자 실행으로 바꾸지 않는다.

전달 ZIP의 `viewer.html`을 압축 해제한 뒤 브라우저로 연다.

1. 첫 번째 **가장 큰 F1 하락** 사례를 그대로 둔다.
2. 세 화면에서 원영상, 제공된 정답 점, 자동 검출 점이 구분되는지 확인한다.
3. ‘예측 모델’을 **색상 통계 + 로지스틱 회귀 → CNN · seed 20261113**으로 바꾼다.
4. 자동 검출 점의 위치·개수는 같고, 분류 색과 양성률의 분자·분모가 바뀌는지 확인한다.

예상되는 동작은 모델 두 개가 **동일한 영상 기반 검출기**를 사용하고 분류기만 바꾸는 것이다. 결과가 나빠진 사례를 의도적으로 함께 제공한다. U88에서 케이스 양성률 MAE 19.78→13.51%p 감소와 macro-F1 0.0704→0.0570 하락을 구분하고 전체 정확도 향상으로 단정할 수 없다고 설명했다. U89에서는 후보107개·정답7개·대응3개로 FP104와 FN4를 계산했다. U90에서는 비세포 거부 기능이 없는 네 클래스 분류기를 교체하는 것만으로 위치 기준 FP가 자동 제거되지 않는다고 설명했다. 검출기 자체 개선이나 후보 거부 기능의 구현·검증은 별도 작업이다. 다음에는 이미 결과를 확인한 외부133장으로 기준을 조정한 뒤 같은 집합을 새 미노출 검증으로 주장할 수 있는지 구분한다. 해당 답변은 아직 대기 상태다. 새 학습이나 여러 과제를 한꺼번에 요구하지 않는다.
