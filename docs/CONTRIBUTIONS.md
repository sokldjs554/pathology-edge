직접 구현·테스트한 범위는 좌표 함수, NMS 합성 반례 테스트 본문, Dice 함수, 그룹 누수 보고 함수, PyTorch soft Dice 계산 본문입니다. 각각12개·1개·20개·18개·8개 테스트 통과를 사용자 보고로 확인했습니다. 반례 fixture·병합 알고리즘·Dice/그룹 계약 테스트·실제 결과 검산 호출·저장 해시 비교 코드는 Codex 제공입니다. 사용자는 본인 Dice로42개 점수·6개 평균, 그룹 함수로 실제50개 레코드의 그룹 분리, 제공 명령으로 저장 이미지 해시50개·분할 간 해시 중복 없음을 확인해 출력을 제출했습니다. 이전 저장 결과 검산 단계에서는 이미지 hash 재계산·새 학습·추론을 실행하지 않았습니다. 이후 34단계에서 사용자가 새 학습을 직접 실행하고 모델 저장·동일 설정·기록된 Git 상태를 확인했습니다. 프로젝트 기반 구현과 원래 공개 모델의 학습·전체 검증은 Codex가 수행했으며, 사용자 재현 학습·개별 화면 조작·수치 해석은 확인 범위를 따로 기록합니다.
