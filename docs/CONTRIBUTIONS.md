## 면접에서 현재 말할 수 있는 범위

“Codex와 프로젝트를 구성하고 데모 화면이 정상적으로 표시되는 것을 확인했습니다. 좌표 변환 함수를 직접 작성해12개 단위 테스트를 실행했고, 축별 리사이즈를 되돌리는 이유를 설명했으며 Codex의 독립 검토도 받았습니다.”
직접 구현·테스트한 범위는 좌표 함수, NMS 합성 반례 테스트 본문, Dice 함수, 그룹 누수 보고 함수입니다. 각각12개·1개·20개·18개 테스트 통과를 사용자 보고로 확인했습니다. 반례 fixture·병합 알고리즘·Dice/그룹 계약 테스트·실제 결과 검산 호출·저장 해시 비교 코드는 Codex 제공입니다. 사용자는 본인 Dice로42개 점수·6개 평균, 그룹 함수로 실제50개 레코드의 그룹 분리, 제공 명령으로 저장 이미지 해시50개·분할 간 해시 중복 없음을 확인해 출력을 제출했습니다. 이미지 hash 재계산·새 학습·추론을 실행한 것은 아닙니다. 전체 프로젝트 구현·모델 학습·전체 검증은 Codex 기여이며, 개별 화면 조작·수치 해석은 확인 범위를 따로 기록합니다.
완료 후에도 Codex가 수행한 모델 학습과 본인이 실행한 재현 실험을 분리합니다.
