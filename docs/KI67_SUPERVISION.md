# 중심 검출 후속 진단: 손실 함수와 피크 정리

**성능 개선 목표는 여전히 미달이다.** 두 손실 대안과 예측 지도 평활화가 사전에 정한 학습 전용 진행 기준을 통과하지 못했다. 기존 모델·디코더·배포 데모를 유지했다. 새 3-seed 본 학습과 검증·테스트·BCData·DeepLIIF 추론은 실행하지 않았다. 이는 이번 세 seed를 다시 평가해 실패했다는 뜻이 아니다. 이전 정규화 실험의 채택 0/3 결과를 대체하지 않는다.

## 이번에 실제로 실행한 작업

- 기존 정규화 모델 3개의 저장된 validation227장 좌표에서 FP 거리와 클래스별 FN 원인을 다시 집계했다. 새 추론 없이 저장 결과를 분석한 것이다.
- 학습 자료 15케이스에서 각 첫 8장, 총120장·2130개 주석 중심을 고정했다. 같은 seed20261117·초기 가중치·미니배치 순서·증강으로 기존 focal과 두 soft 목표를 각각300step 학습했다. 합계900step이며 세 seed 반복이 아니다.
- 새로 학습한 세 체크포인트의120장 출력과108개 설정을 독립 NMS로 다시 계산했다. **360건의 체크포인트·영상 재실행과108개 지표 대조가 일치**했다.
- 별도로 기존 정규화 seed17 진단 모델에서 Gaussian 평활화 sigma0/1/2/3/4px를 같은120장에 비교했다. **120건의 원모델 재실행,600개 지도와180개 설정**을 명시적 Gaussian 커널·별도 NMS로 대조했다.
- 공용 손실·선택 함수와 진단 감사 코드를 추가했다. 새35개 검사와 기존 중심 검출 회귀 검사를 실행했다. 전체 CI 결과는 게시 기록에 남긴다. 사용자 직접 실행으로 기록하지 않는다.

## 원인 조사에서 확인한 범위

기존 정규화 최고 F1 진단 모델에서, FP 중 정답 중심에서6~12px 떨어진 후보는 seed17/18/19에 각각865/855/874개(전체 FP1807/1850/1835개 중 약46~48%)였다. 누락된 양성 종양세포 중 정답6px 내에 저장된 피크가 없는 것은184/167/182개, 거리 억제로 사라진 것은11/8/2개였다.

저장 피크는 점수0.01이상만 포함하므로 ‘피크 없음’은 수학적 극댓값이 전혀 없다는 뜻이 아니다. 위치 오차·표현 학습을 살펴볼 근거이며, 세포의 생물학적 원인이나 주석의 완전성을 확정하지 않는다. 전체 분포·클래스별 원인은 `saved-error-diagnosis.json`에 보존했다.

## A. 손실 함수 비교 — 새120장 학습, 단일 seed

모델은 동일한 GroupNorm width16(118913파라미터), 원영상224×224px, maxGaussian sigma2/radius6 표적이다. Adam0.001, batch8,300step, 작업당1thread, 회전·반전·RGB0.9~1.1 증강을 동일하게 적용했다. 실제 학습은 보존된 스파이크 스크립트로 실행했으며 공용 함수 구현·단위 검사는 별도로 제공한다.

soft_mse는 예측과 Gaussian 표적의 제곱 오차를 soft 전경/배경 질량으로 각각 정규화한다. soft_bce도 같은 질량으로 양성/음성 항을 정규화한다. 기존 focal은 정답 중심 한 픽셀을 양성으로 취급한다. 손실값의 크기는 식이 달라 직접 비교하지 않는다.

|방식|케이스 평균 검출 F1|케이스 평균 재현율|양성 종양 위치 재현율|FP|FN|
|---|---:|---:|---:|---:|---:|
|focal|0.416073|0.465140|0.358156|1535|1136|
|soft_mse|0.379821|0.361391|0.253546|950|1388|
|soft_bce|0.413375|0.415052|0.239362|1035|1283|

각 행은 고정한12임계값×3거리 중 해당 모델의 최고 학습 F1 설정이다. FP·FN은120장 합계, F1·재현율은15케이스 평균이다. 반경6px 안에서 정답과 일대일 대응하며 분할 Dice가 아니다.

진행 기준은 기존 focal보다 학습 F1이0.03이상 높고 양성 종양 위치 재현율이 낮아지지 않는 것이다. 두 대안 모두 실패했다. FP 감소만 보고 개선으로 채택하지 않았다. 120장·한 seed·300step의 학습 적합성 비교이므로 이 손실이 모든 조건에서 나쁘다는 결론도 내릴 수 없다.

## B. 피크 정리 — 기존 모델을 사용하는 별도 비교

이 표는 위300step 모델이 아니라 **696장으로 이미 학습했던 정규화 seed17의 epoch22 진단 체크포인트**를 사용한다. 해당 체크포인트는 이전 validation 결과로 선택됐으므로 그 선택 이력도 보존한다. 이번 평활화 비교 자체는120학습 이미지에서만 수행했다. 두 표의 기준 F1을 서로 직접 비교하면 안 된다.

원영상 RGB 대신 **예측 지도만** float64 Gaussian 필터(reflect,truncate3)로 평활화했다. sigma0은 무처리 대조군이다. 정답 좌표와 매칭 반경6px는 바꾸지 않았다.

|sigma|케이스 평균 검출 F1|양성 종양 위치 재현율|FP|FN|
|---|---:|---:|---:|---:|
|0px|0.498148|0.496454|1365|944|
|1px|0.499409|0.485816|1245|978|
|2px|0.507705|0.468085|1041|1029|
|3px|0.499337|0.544326|1433|915|
|4px|0.508772|0.537234|1221|965|

결과를 보기 전에 무처리보다 F1이0.03이상 상승하고 양성 종양 위치 재현율이 유지될 때만 후속 비교로 진행하기로 고정했다. 최고 F1의 sigma4도 상승폭은0.010624였고 FN은944→965개로 증가했다. sigma3에서는 FN이 줄지만 FP가 늘었다. **선택된 sigma는 없다.** 필터·매칭 허용 반경이나 진행 기준을 사후 완화하지 않았다.

## 검증과 미실행 구분

새35개 단위 검사(손실27,진단 검증8)를 통과했다. 기존 중심 검출25개를 포함한 손실 관련52개 검사도 통과했다. 이는 두 집합을 합산한87개 새 검사가 아니다. 지표 감사에는 공통 peak/matching 기본 함수를 일부 재사용하지만, NMS와 평활화 커널 계산을 별도 구현하고 실제 원영상·주석·체크포인트를 다시 연결했다. 학습300step 자체를 독립 재학습한 것은 아니다.

구현 계획의 본 학습·실제 검출 중심 분류·외부 단계는 선행 기준 미달로 실행하지 않았다. 이미 존재하는 조건부 파이프라인을 성공한 것처럼 실행/완료 처리하거나 새로운 평가 지표를 만들지 않았다. 새 UI는 추가하지 않았고 새 브라우저 검사도 실행하지 않았다. 원본 사용자7개 파일, U106 표시 확인, 이전 실험·데모는 유지했다. 이번 진단·자동 검사·결과 해석을 사용자 수행으로 추가하지 않았다.
