# STEP91 — 추가 학습 전후 검출 화면 (사용자 확인 전)

이번에는 첫 예제만 확인한다. 새 학습이나 코드 실행은 필요하지 않다.

1. [검토 ZIP](../artifacts/handoff/PathologyEdge-CenterRefit-Review-20261114.zip)을 내려받아 압축을 풀고 `index.html`을 연다.
2. A(원래 검출기)와 B(선택/진단 검출기)가 같은 원영상을 보여주는지 확인한다.
3. **후보·정답 표시**를 껐다 켠다. 영상 위 표시만 바뀌고 후보 수·TP·FP·FN은 그대로여야 한다.

작은 화면은 A/B가 세로로 표시된다. B의 진단용 표시는 전체 선택 조건에 미달한 모델임을 뜻한다. 두 모델의 후보가 서로 일대일 대응하는 것은 아니므로 이전 화면의 이동 화살표는 없다.

사용자 확인은 아직 완료 처리하지 않는다. 문제가 있으면 예제 이름·브라우저·안 된 조작·화면 캡처를 보낸다. 이전 U104는 위치 보정 화살표 화면 확인으로 그대로 보존한다.

파일 직접 열기가 제한되면 압축을 푼 폴더에서 아래 명령을 실행하고 `http://127.0.0.1:8000/`을 연다. 이미지와 스크립트는 HTML에 포함되어 별도 외부 자료 다운로드가 필요 없다.

```bash
python -m http.server 8000 --bind 127.0.0.1
```

제공된 Chromium은 `file://` 접근을 정책으로 차단하여 직접 파일 열기 검사는 완료하지 못했다. 대신 위 로컬 HTTP 방식에서 외부 요청 없이 원영상·전환이 동작함을 확인했다.
