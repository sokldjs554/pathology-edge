# STEP85 — 본인 CNN–ViT의 09_6 개선 그림 확인

상태: **사용자 확인 대기(U99)**. STEP84의 09_1 표시 확인과 별도이다. 새 다운로드·코드 작성·학습·추론·테스트 실행은 필요하지 않다.

1. 이미 열어 둔 `CNN–ViT 저장 결과 오류 분석` 페이지에서 위쪽의 **09_6 · 전체 Dice 최대 상승**을 찾는다. 브라우저 찾기(Ctrl+F 또는 Cmd+F)에 이 제목을 입력해도 된다.
2. 전체 비교 그림 아래 **노란 상자의 동일 영역 확대**를 확인한다. 원영상·정답·CNN 오류·ViT 오류·변화 지도를 같은 위치에서 표시한다. 청록은 FP, 분홍은 FN이다.

예상 표시는 전체 이미지 Dice **0.365310→0.651067**, 선택 영역 Dice **0.3673→0.7484**이다. 선택 영역은 `[288,384,416,512)`의128×128px이다. 두 점수는 평가 범위가 다르다. 이 단계에서는 확대 그림이 보이는지만 확인한다.

선정 근거: 사용자 seed20261113의 기존 validation10장 중 전체 Dice(ViT−CNN)가 가장 큰 이미지다. 영역은 정답에 맞게 바뀐 픽셀−틀리게 바뀐 픽셀이 큰 위치를 선택했다. 저장 결과를 읽는 화면이며 새 추론이나 독립 검증이 아니다. 개선 사례에도 악화 픽셀이 있으며 전체 이미지·모든 위치의 우수성을 뜻하지 않는다.

자료는 기존 U97 ZIP의 `artifacts/experiments/user-cnn-vit-errors-20261112/index.html`에 이미 있다. 사용자의 응답 전에는 U99를 완료로 변경하지 않는다. 그림 표시 확인을 수치 독립 재계산·오류 원인 해석·모든 사례 검토로 확대하지 않는다.
