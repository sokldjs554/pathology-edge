상태: **2026-11-09 사용자 설명 검토 완료**. 사용자는 다른 이미지의 변화가 개별 이미지의 감소를 상쇄하면 평균은 상승할 수 있다고 설명했습니다. [설명 원문·수치 확인](../artifacts/learning/step07-review.json). 이번 단계에는 코드 작성이나 추가 실행이 없었습니다.

## 판단할 자료

아래 두 행은 모두 같은 경계 정의를 사용하는 Dice입니다. 높을수록 정답 foreground와의 픽셀 겹침이 큽니다.

| 집계 범위 | 무겹침 | 겹침 |
|---|---:|---:|
| 테스트7장의 경계 Dice 산술평균 | 0.491793 | 0.527261 |
| 개별 이미지 `10_1`의 경계 Dice | 0.682676 | 0.649451 |

두 행의 차이는 집계 범위입니다. 원본은 `artifacts/evaluation.json`의 `methods.*.macro_dice.boundary`와 `methods.*.rows` 중 `id == "10_1"`의 `metrics.boundary.dice`이며, 화면의 `dist/results.json`과도 대조했습니다. 표는 소수6자리 반올림입니다.

`10_1`은 사용자가 앞서 검토를 요청한 첫 예제입니다. 이를 모든 이미지의 대표 사례로 선정한 것은 아닙니다. 전체 테스트는7장·2개 케이스 그룹이며, 이번 자료는 새 실험이나 외부 데이터 평가 결과가 아닙니다.

## 완료한 질문

**테스트 평균 경계 Dice는 올랐는데 `10_1`의 경계 Dice는 낮아졌습니다. 두 결과가 모순되지 않는 이유를2~3문장으로 설명해 주세요.**

사용자 답변을 확인했습니다. 더 엄밀하게는 나머지6장의 **부호를 포함한 점수 변화 합**이 `10_1`의 감소를 상쇄하는지 봅니다. 실제로는3장이 상승하고4장이 하락했으며, 변화 합을7로 나누면 평균 변화와 일치합니다. 이 보충 계산은 Codex 검토입니다.
