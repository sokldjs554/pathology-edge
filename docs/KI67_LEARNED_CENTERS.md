# 학습한 세포 중심 검출: 고정 분류기와 비교

세포 위치를 사람이 제공하지 않고 영상에서 직접 찾는 검출기를 구현하고 실제로 학습·평가했다.
기존 LoG 후보를 줄이는 후처리와 달리, RGB 영상에서 세포 중심 위치 지도를 예측해 새 좌표를 만든다.
기존 분류기 네 개는 그대로 고정하고 **새 좌표에서 다시 분류**했다. 공개 데모 기본 분석은 바꾸지 않았다.

내부407장에서는 세 검출 seed 모두 검출 F1이 상승했고, 12개 검출기·분류기 조합 모두4-class F1이 상승했다.
BCData133장 재평가에서도12개 조합 모두 종양2-class F1이 상승했다.
다만 내부 검출 재현율은0.5783에서0.3770~0.3943으로 하락했고, 양성률 MAE는 일부 조합에서 악화됐다.
특히 BCData의 LR 양성률 MAE는21.11%p에서37.49~40.89%p로 커졌다.
**후보의 정확도와 세포를 놓치는 비율, 양성률 오차가 모두 함께 개선된 것은 아니다.**

이 결과는 이미 살펴본 Patherea407장·BCData133장에 대한 **재평가**다.
새 미노출 외부 검증, 환자 단위 독립성 입증, 임상 Ki-67 검사 또는 WSI 전체 검증이 아니다.
이번 구현·학습·추론·검산은 제공된 개발 환경에서 수행했으며 사용자의 직접 수행에 추가하지 않는다.

## 무엇을 고정했나

- Patherea Breast-P1 v1.1: 224×224 RGB, 중심 좌표와4개 클래스. 학습696장/15케이스,
  검증227장/4케이스, 기존 테스트407장/10케이스. 케이스·픽셀 해시 분리를 재검사했다.
- 7,537개 파라미터의 작은 완전합성곱 encoder/decoder: TinyUNet width4, LeakyReLU0.1,
  출력 bias−2.19, 사전학습 없음. 기존 H&E TinyUNet은 변경하지 않았다.
- 중심 정답은 Gaussian의 최댓값으로 결합: sigma2px, 반경6px, 중심1, 바깥0, 영상 경계에서 자름.
  **핵 분할 마스크·세포 개수 밀도 맵이 아니다.**
- 변형 focal 손실은 정확한 중심(target=1)과 주변/배경을 구분한다.
  음성 가중치 `(1-target)^4`, focal 지수2, 이미지별 중심 수로 정규화한 뒤 배치 평균.
  안정적인 softplus 계산과 극단 logits·빈 정답의 gradient 테스트를 포함한다.
- 세 seed20261117/18/19, 각16epochs, Adam0.001, batch8, CPU threads2.
  train만 회전·반전·RGB채널0.9~1.1배 증강. 분류기 LR+CNN3개는 재학습하지 않았다.
- 검증에서 epoch와 threshold{0.1,0.2,0.3,0.5}×최소 간격{4,6,8} 선택.
  케이스마다 TP/FP/FN을 합쳐 F1을 구한 뒤4케이스 평균을 최대화한다.
  동률이면 재현율→이른epoch→높은threshold→큰간격 순이다.
- 3×3 국소 최대점, 같은 값의 plateau는 중심 가까운 픽셀 하나, 점수 순 거리 억제.
  결과 좌표는 원본 XY 픽셀, 리사이즈 없음. 거리 **6px 이하**로 정답과 일대일 대응한다.

## 수렴 실패와 검증 자료에서 한 수정

첫 ReLU3seed실험의 검증 F1은0.278709/0.275998/0이었다. 마지막 seed는16epochs 모두0이라
정해 둔 동률 규칙에 따라 epoch1이 저장됐다. 실패를 제외하지 않고 초기 weights·전체 history·소스를 보존했다.
train8장+validation8장 진단에서 해당 checkpoint의 최대 점수0.094361은 선택 grid의 최저0.1보다 낮았고,
깊은 층 gradient L1은 약1e−7~1e−6이었다. 같은 weights에서 LeakyReLU0.1로만 바꾸자
약0.06~0.78로 회복됐다. 진단에 optimizer step은 없었다.

이를 근거로 **활성화 함수만 바꾼 별도3seed실험**을 수행했다. seed·epoch수·loss·증강·선택 grid는 유지했다.
이 진단은 한 batch의 gradient 문제를 보여주며 전체 학습 경로의 원인을 완전히 증명하지는 않는다.
두 실험은 모두 같은 검증 자료를 사용한 개발 과정이다. 수정은 테스트·BCData 평가 전에 고정했고,
그 뒤 결과를 보고 다시 조정하지 않았다. 최종 세 seed를 모두 공개한다.

## 재현·검증 자료

`artifacts/experiments/ki67-learned-centers-20261113/`에 source/model SHA, 선택 lock,
초기실패·수정3seed 학습 history, seed별 집계, 내부 좌표, 별도 검산 결과와 화면을 보관한다.
독립 검산은 production evaluator를 사용하지 않고 일대일 대응의 최대 수를 별도 solver로 확인한 뒤
**6,480개 이미지×분류기 조합**(3×4×(407+133))의 TP/FP/FN·양성률·집계를 대조했다.
실제 테스트·브라우저 확인·배포 묶음의 추론 결과는 `verification.json`, `screenshots/browser-check.json`,
`portable-replay.json`에 기록한다. 원본 user7개 파일은 `user-file-preservation.json`으로 보존을 확인한다.

새 모델 하나를 실행할 때는 ZIP 루트에서 기존 Ubuntu Python 환경을 사용한다.
명령은 원영상 한 장만 읽고 정답을 전달하지 않는다. `--output`은 새 경로여야 한다.

```bash
PYTHONPATH=frozen_source python scripts/infer_ki67_centers.py \
  --bundle inference-bundle.json --image examples/first-case.png \
  --detector-seed 20261117 --classifier cnn-20261113 \
  --output my-first-prediction.json
```

패키지 없는 새 Python3.12환경에서는 `python -m pip install -r requirements-inference.txt`가 필요하다.
이는 다운로드·설치를 수행하며 사용자 환경에서의 실행은 아직 확인하지 않았다.
일반 단일RGB패치(한 변4~2048px)만 지원한다. WSI 전체 파일은 지원하지 않는다.

## 남은 한계와 사용자 검토

Patherea의 선택된 주석 영역은 원논문에서 설명하지만 배포 패치에는 원 polygon support가 없다.
주석 없는 픽셀을 학습상 배경으로 다뤘으며 전문가가 확인한 비세포라고 볼 수 없다.
작은 한 데이터셋, 반복 사용한 검증 세트,3seed, native scale, 색상/기관 차이,
검출오류 이후 분류와 양성률의 상쇄 문제가 남는다. 외부 새 환자·기관·임상·전체WSI 검증은 미완료다.
기존 H&E 보정 모델의 외부 악화 결과나 이전 후보 필터 실패를 이 실험으로 덮어쓰지 않는다.

[STEP_80](STEP_80.md)의 첫 사례 후보 수 표시·위치 지도 전환 요청에 사용자가 “응 잘 작동해”라고 응답했다.
해당 요청 범위의 정상 동작 보고를 U94·`artifacts/learning/step80-review.json`에 기록했다.
개별 수치 독립 검산·전체 사례/seed 검토·결과 해석·새 추론/학습/테스트 실행은 확인된 사용자 수행에 포함하지 않는다.
발행 ZIP은 응답 이전의 기록으로 보존한다.

## 재현율과 양성률 오차가 함께 좋아지지 않은 이유

사용자는 U95에서 전체407장의 F1 상승과 재현율 하락을 구분해 해석했다.

근거: `artifacts/learning/step81-result-analysis.json`.

FP가60,143개 줄었지만 TP도1,181개 순감소했다. F1은 `2TP/(2TP+FP+FN)`이므로
이 조합에서도 상승할 수 있다. 이 수치는 기존에 찾던 특정1,181개를 그대로 제거했다는 뜻이 아니다.
새 검출기가 위치를 새로 예측했으므로 어떤 정답을 잃고 새로 찾았는지는 별도 대응 분석이 필요하다.

모델·epoch·점수 기준·최소 간격의 선택 목표는 검증 케이스 평균 위치 F1이었다.
재현율은 동률일 때 비교했으며, 별도의 재현율 하한이나 양성률 MAE 목표는 없었다.
따라서 F1 상승이 재현율 유지 또는 양성률 정확도 상승을 보장하지 않는다.
이전 후보 필터의 재현율 유지 조건을 이번 검출기에도 적용한 것으로 해석하면 안 된다.

양성률은 `양성 종양 예측 수/(양성+음성 종양 예측 수)`다. 같은 분류기 가중치를 사용해도
새 검출 위치에서 읽는 영상/색상 특징과 후보 구성이 달라진다.
검출 누락과 종양/비종양·양성/음성 오분류가 양성·음성 집계를 서로 다르게 바꾸면 비율 오차가 커진다.

실제 내부 `case_0024`, 검출 seed20261117·고정 CNN20261114의 예다.
해당 조합의10케이스 중 양성률 오차 증가가 두 번째로 큰 사례로, 전체 평균을 대표하지 않는다.

| 구분 | 양성 종양 | 음성 종양 | 양성률 |
|---|---:|---:|---:|
| 정답 | 382 | 501 | 43.26% |
| 기존 예측 | 2,640 | 3,476 | 43.17% |
| 새 예측 | 359 | 358 | 50.07% |

기존은 두 종류 모두 약6.9배로 과대 집계했는데 비율만 정답에 가까웠다.
새 예측은 전체 종양 수가6,116→717개로 정답883개에 가까워졌지만
양성·음성의 구성 비율은 더 멀어져 양성률 오차가0.0961→6.8081%p로 증가했다.
같은 사례의4-class F1은0.0877→0.2898로 상승했다.
이는 개별 세포 F1, 전체 개수, 양성률이 서로 다른 목표임을 보여준다.
음성으로 집계된 수가 상대적으로 더 부족해진 것은 확인되지만, 이를 순수한 음성 세포 검출 누락만으로 해석해서는 안 된다.

아직 원인별 기여도까지 확정한 것은 아니다. 점수 기준 미달, 국소 최대점 미생성,
가까운 후보의 거리 억제, 정답에서6px를 벗어난 위치 오차가 각각 FN에 얼마나 기여했는지는 집계하지 않았다.
염색 차이·작은 모델·학습 길이 등이 주원인이라고 단정하지 않는다.
다음 원인 분석은 검증 자료에서 이 단계별 FN과 클래스별 집계 오류를 나누어 보는 방식이 적절하다.
이번 설명을 위해 임계값을 바꾸거나 테스트/BCData에 맞춰 재학습하지 않았다.
