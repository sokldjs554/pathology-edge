# 검출 누락 원인과 재현율 조건 비교

기존 학습 검출기의 재현율 하락을 검증 자료에서 분리하고, 모델 가중치는 고정한 채
점수 기준과 최소 간격을 바꾸는 비교를 수행했다. **누락은 줄었지만 FP가 늘어 F1은
낮아졌다.** 기본 검출기는 교체하지 않고 연구 비교 결과로 제공한다.

## 범위와 선택 순서

- 원인 분석·설정 선택: Patherea 검증227장·4케이스·정답 중심2,802개.
- 고정 모델: detector seeds20261117/18/19, LR 및 CNN seeds20261113/14/15.
- 재학습 없음. 검출기가 실제 RGB에서 중심을 예측하고 고정 분류기가 새 위치를 분류했다.
- 비교 설정은 검증 단계에서 고정한 뒤 기존 테스트407장·10케이스와 BCData133장을 재평가했다.
- 이전 실패를 보고 제안한 탐색적 후속 실험이다. 반복 사용한 검증 자료의 선택 편향과
  재사용 테스트/외부 자료의 노출을 인정하며, 새로운 미노출 외부 검증으로 설명하지 않는다.
- 임상 검증·WSI 전체 정답 기반 검증은 수행하지 않았다.

## 누락이 발생한 단계

원래 설정의 최종 일대일 대응 결과에서 놓친 정답을 다음 순서로 구분했다.
정답 반경6px 내 원시 국소 피크가 없으면 `no_peak`, 피크가 있지만 모두 기준점수
미만이면 `below_threshold`, 점수를 통과한 피크가 모두 거리 억제되면
`distance_suppressed`, 남은 피크가 다른 정답에 대응하면 `assignment_competition`이다.
각 정답은 한 항목에만 속한다. 생물학적 원인을 확정하는 분류는 아니다.

| 검출 seed | 찾은 정답 | 피크 없음 | 점수 미달 | 거리 억제 | 대응 경쟁 |
|---|---:|---:|---:|---:|---:|
|20261117|894|1,158|709|41|0|
|20261118|832|1,122|842|6|0|
|20261119|838|1,133|826|5|0|

첫 seed의 누락1,908개 중 피크 없음60.69%, 점수 미달37.16%, 거리 억제2.15%다.
따라서 거리 억제만 완화해서 모든 누락을 해결할 수 없다. 정답과 피크의 위치 오차,
국소 최대점 생성 실패, 염색·형태·학습 조건 등의 깊은 원인별 기여도는 아직 분리하지 않았다.

첫 seed의 양성 종양은483개 중196개(40.58%), 음성 종양은1,292개 중248개(19.20%)를
찾았다. 음성 종양에서 피크 없음639개와 점수 미달389개가 관찰됐다. **이 수치는
정답 클래스별 위치 검출 재현율이며, 분류까지 맞춘 재현율과 다르다.**

## 재현율 조건을 추가한 선택

검증 재현율 기준: 기존 LoG의 케이스 평균0.479795, 양성 종양 위치0.559006,
음성 종양 위치0.339783 이상을 모두 요구했다. 양성·음성은 전체 검증 주석을 합산한
재현율이며, 케이스 평균과 구분한다. 조건을 만족한 설정 중 케이스 평균 위치 F1을
최대화했다. 동률이면 재현율, 높은 점수 기준, 큰 최소 간격 순이다.

탐색 범위는 실행 전 `0.01,0.02,0.03,0.05,0.075,0.1,0.2,0.3,0.5 × 4,6,8px`로 고정했다.
양성률 MAE나 테스트/외부 결과로 설정·분류기를 선택하지 않았다.

| seed | 27개 중 조건 충족 | 선택 | 판정 |
|---|---:|---|---|
|20261117|3|점수0.03·최소간격4px|비교 진행|
|20261118|0|없음|조건을 완화하지 않음|
|20261119|0|없음|조건을 완화하지 않음|

18/19 seed의 탐색 범위 내 최대 양성 종양 위치 재현율은0.515528/0.494824로
기준0.559006에 못 미쳤다. 첫 seed만 성공했다고 다른 seed에서도 재현됐다고 말할 수 없다.

같은 첫 seed의 검증 결과에서 두 변경을 따로 확인할 수 있다.

| 점수/최소 간격 | 케이스 평균 F1 | 케이스 평균 재현율 |
|---|---:|---:|
|0.10 / 8px (A)|0.341818|0.327809|
|0.10 / 4px (간격만 완화)|0.332983|0.339484|
|0.03 / 8px (점수만 완화)|0.246915|0.506989|
|0.03 / 4px (B)|0.229470|0.538333|

이 범위에서는 점수 기준을 낮춘 변화가 간격만 줄인 변화보다 재현율 증가가 컸다.
이 비교는 같은 검증 자료에서 관찰한 디코딩 효과이며 새 모델 학습 효과가 아니다.

## 기존 테스트407장 재평가

A는 첫 seed의 기존0.1/8px, B는 같은 가중치의0.03/4px다.

| 위치 검출 | A | B |
|---|---:|---:|
|TP|2,531|3,890|
|FP|5,297|30,134|
|FN|3,888|2,529|
|재현율|0.394298|0.606013|
|정밀도|0.323327|0.114331|
|F1|0.355303|0.192370|

순증가로1,359개 정답을 더 찾았지만 FP도24,837개 늘었다. 원래 LoG의 재현율0.578283과
F1 0.098239도 넘지만, 기존 학습 검출기의 F1 0.355303에는 못 미친다.

| 고정 분류기 | 4-class F1 A→B | 케이스 양성률 MAE A→B(%p) |
|---|---:|---:|
|LR|0.218254→0.127568|13.7982→10.3577|
|CNN20261113|0.205718→0.113392|12.1255→11.6097|
|CNN20261114|0.259150→0.133394|13.1085→6.9279|
|CNN20261115|0.203547→0.107915|16.0842→7.3190|

모든 조합의 양성률 계산 가능 케이스는10/10이다. 평균 MAE 감소가 모든 개별 사례의
개선을 뜻하지 않는다. 후보 구성이 달라져 양성·음성 집계 비율이 변했고, 동시에 FP가
증가했다. MAE만 보고 세포 분석 전체의 정확도가 향상됐다고 주장할 수 없다.

앞서 질문한 `case_0024`·CNN20261114도 같은 주의를 보여준다. 정답 양성/음성 종양은
382/501개인데 A는359/358개, B는947/1,320개를 집계했다. 양성률 오차는6.8081→1.4883%p로
줄었지만 B는 종양 수를883개보다 훨씬 많은2,267개로 집계했다. 비율이 가까워진 것과
각 세포·전체 개수가 정확해진 것은 다르다.

## BCData133장 재평가

종양 중심만 주석되어 종양 예측만 평가한다. 클래스별 F1은 양성/음성 종양의 평균이며
내부4-class 지표와 직접 동일시하지 않는다. MAE는 이미지별 양성률 오차의 평균이다.

| 고정 분류기 | 종양2-class F1 A→B | 이미지 양성률 MAE A→B(%p) |
|---|---:|---:|
|LR|0.174637→0.123871|40.8853→37.7901|
|CNN20261113|0.211170→0.184736|56.1354→36.2748|
|CNN20261114|0.320704→0.283286|38.5141→22.1686|
|CNN20261115|0.234982→0.195177|51.2643→41.2217|

모든 조합133/133에서 양성률을 계산했다. 네 분류기 모두 MAE는 줄었지만 세포 F1은
낮아졌다. 외부 데이터에서 전반적인 성능 개선을 입증한 결과가 아니다.

## 재현과 검증

`scripts/run_ki67_recall.py`의 `prepare → validation → internal/external` 순서를 사용했다.
`protocol.json`은 입력·가중치·실행 소스 해시를, `selection-lock.json`은 선택 설정과
검증 피크 자료의 해시를 고정한다. 기존 실행 폴더를 덮어쓰지 않는다.

새 소스의 실행 위치는 저장소 루트다. 원자료와 기존 실험 폴더가 있는 제공된 환경에서는:

```bash
python scripts/run_ki67_recall.py prepare --prior work/learned-centers-leaky-run-20261113 --output work/recall-new-run
python scripts/run_ki67_recall.py validation --output work/recall-new-run
python scripts/run_ki67_recall.py internal --output work/recall-new-run
python scripts/run_ki67_recall.py external --output work/recall-new-run
python scripts/audit_ki67_recall.py --run work/recall-new-run
```

위 경로는 이번 실행 환경의 예이며 모든 사용자 컴퓨터에 존재하는 경로가 아니다.
새 환경에서는 원자료와 선행 실행 폴더의 경로·해시 연결이 먼저 필요하다.
배포 ZIP의 `review.html`은 설치나 새 추론 없이 저장 결과를 확인하는 파일이다.

- 독립 감사: 81개 검증 설정, 정답8,406개 단계 판정, 2,160개 이미지·분류기 조합 일치.
- GitHub CPU CI [fda5695](https://github.com/sokldjs554/pathology-edge/actions/runs/43405269169):
  571 tests passed; 기존 Dice42개·평균6개 및 정적 데모 검사 통과.
- 로컬 전체 검사 초기에는 공간 부족·sparse checkout 누락·C++ 빌드 누락이 있었다.
  불필요한 이번 실행의 pytest 임시 파일만 정리하고 빌드/자료를 복구했다.
  남은2GiB 사전조건은 우회하지 않았으며, 전체 통과 근거는 별도 GitHub CI다.
- Chromium1440/390px, 20개 사례·분류기·폭 조합에서 표시 수치, 오버레이 전환,
  검증/테스트 구분, 가로 잘림 없음 확인. 화면 캡처 포함.
- 사용자 작성7파일 및 이전 실험/ZIP 보존. 이번 코딩·추론·자동 검증은 사용자 직접
  수행 기록에 포함하지 않는다. 사용자 응답 “흥 정상적으로 잘 작동해”로 STEP82의
  첫 사례 표시·놓친 정답 전환 정상 동작을 U96에 기록했다. 독립 검산·다른 사례
  확인·새 실행으로 확대하지 않는다. 발행 ZIP은 응답 이전 상태로 보존한다.

## 남은 한계

고정 모델에서 임계값을 낮추는 것만으로는 누락과 FP를 함께 줄이지 못했다.
다음 연구 과제는 피크가 없는 정답 주변의 위치 오차·학습 신호를 분석하고,
주석 지원 영역을 확인한 뒤 모델 학습 또는 명시적 배경 제거를 검토하는 것이다.
이번 비교 결과를 보고 같은 테스트·BCData에 맞춰 추가 조정하지 않았다.
원시 BCData 영상·개별 좌표는 공개 ZIP에서 제외하며 로컬 감사 자료로 보존한다.
로컬 `external/class-accounting.json.gz`는 전체4클래스 후보를 대응한 원시 집계다.
종양 예측만 필터링한 뒤 대응하는 외부 성능 표와는 대상이 다르므로 그 파일의
matched/missed를 종양 전용 표의 TP/FN과 동일시하지 않는다. 공개 패키지의 클래스
오류 분해는 내부 평가 자료만 포함한다.

영상/주석 출처: [Patherea Breast-P1 v1.1](https://huggingface.co/datasets/ds2268/patherea),
Dejan Štepec et al., [CC BY-NC4.0](https://creativecommons.org/licenses/by-nc/4.0/).
BCData 출처 및 획득 해시는 선행 자동 Ki67 보고서와 동결 입력 기록을 따른다.
