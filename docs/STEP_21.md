# 21단계: NMS 대응과 실제 핵의 정답 구분

상태: **2026-11-09 사용자 해석 확인 완료**. 사용자는 억제 표시만으로 동일한 실제 핵이나 올바른 제거를 확정할 수 없으며, 정답 마스크·전문가 주석으로 위치와 경계를 대조해야 한다고 설명했습니다. [답변·범위](../artifacts/learning/step21-review.json). 아래는 완료한 질문의 참고이며, 다음은 [22단계 실제 WSI의 R1 이동](STEP_22.md)입니다.

## 질문 하나

**화면에 `#74 억제 → #54 유지`가 표시됐다는 사실만으로 “두 후보가 같은 실제 핵이며, 올바르게 중복을 제거했다”고 확정할 수 있을까요? 이유와 추가로 확인할 근거를 한두 문장으로 설명해 주세요.**

필요하면 [2단계 합성 반례](STEP_02.md)와 [3단계 반대 오류](STEP_03.md)를 참고합니다. 이번 질문은 실제 사례가 틀렸다고 가정하는 것이 아니라, 화면에서 확인한 사실의 범위를 판단하는 과제입니다.

## 현재 제공된 근거

두 후보의 패치 출처는27과19이며, 저장 bbox의 IoU는1, 중심 거리는 부동소수점 오차 수준에서0입니다. 둘 다 패치 가장자리에 닿지 않았고, 유지 후보의 평균 예측값이 조금 높습니다. 현재 NMS는 서로 다른 패치 사이에서 bbox IoU0.3 이상 **또는** 중심 거리8px 이하 조건으로 억제 대응을 만듭니다.

자료 위치는 `src/pathology_edge/merge.py::deduplicate`, `dist/app.js::selectPair`와 [저장 후보 대조 기록](../artifacts/learning/step20-preparation.json)입니다. 사용자 설명은 정확하며 해석 완료로 기록했습니다. 사용자가 실제 정답 자료를 열어 이 쌍을 대조한 것으로 기록하지는 않습니다.

## 검토 후 보완

Codex는 붙어 있는 핵을 이진 마스크만으로 구별하기 어려울 수 있으므로 핵별 ID가 있는 인스턴스 주석이나 전문가 검토가 필요할 수 있음을 덧붙였습니다. 이 보완은 사용자가 이미 해당 주석을 검토했다는 뜻이 아닙니다. 같은 위치의 후보라는 알고리즘 근거와 실제 같은 핵이라는 정답 근거를 구분합니다.

Codex는 기존 규칙·화면 안내와 답변을 대조하고 이전 NMS 근거의 입력 해시가 현재 파일과 같음을 확인했습니다. 이번에 새 브라우저 검사·NMS 재실행·모델 추론·핵 단위 정답 검증을 수행하지 않았습니다.
