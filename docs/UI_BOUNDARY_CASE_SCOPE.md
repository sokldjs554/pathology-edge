# 현재 이미지 안에서 개선·악화 경계 비교

기존 두 버튼은 전체 예제의 추천 ID를 열었습니다. 개선은 `11_1-improved`, 악화는 `10_3-worsened`였으므로 이미지까지 바뀌었습니다. 버튼을 현재 이미지 기준으로 바꾸고 선택 이미지 ID를 버튼 위에 표시했습니다.

현재 이미지 `11_1`의 저장 결과는 다음과 같습니다. 점수는 64×64 상자 안의 경계 띠 Dice입니다.

| 버튼 | 이미지 | 상자 중심 (x, y) | A → B Dice |
| --- | --- | --- | --- |
| 좋아진 경계 보기 | 11_1 | (128, 272) | 0.626 → 0.854 |
| 나빠진 경계 보기 | 11_1 | (128, 208) | 0.536 → 0.525 |

**같은 이미지의 서로 다른 위치**를 보여 줍니다. 각 위치에서 양쪽 A/B 영상은 동일 좌표를 가리킵니다. 같은 ROI의 같은 Dice 차이를 동시에 개선과 악화로 분류하는 기능이 아닙니다. 한 상자 안에서 정답 일치로 바뀐 픽셀과 불일치로 바뀐 픽셀이 섞여 있을 수 있으며, 이는 기존 변경 강조와 픽셀 수로 확인합니다.

`10_1`, `10_3`, `11_1`, `11_3`에는 두 방향의 저장 사례가 있습니다. `10_2`, `10_4`에는 개선 사례가 없고 `11_2`에는 악화 사례가 없습니다. 없는 방향의 버튼은 **저장 사례 없음**으로 비활성화하며 다른 이미지로 대신 이동하지 않습니다. 이는 저장 사례 선정 조건에 관한 설명이며 해당 이미지에 개선/악화 픽셀이 전혀 없다는 뜻은 아닙니다.

저장 사례는 정답과 사후 대조하여 64px ROI별 경계 띠의 정답 일치 순증감을 기준으로 선택했고, 최소 정답·변경 픽셀 수와 국소 Dice 방향 조건을 적용했습니다. 선정 규칙·좌표·수치는 [원본 cases.json](../dist/cases.json)에 있습니다. 이번 수정은 원본 사례·이미지·마스크·실험 결과를 바꾸지 않습니다.

다른 이미지는 이미지 선택 목록에서 선택합니다. 기존 **근거 보기 → 다른 경계·좌표 확인 → 전체 이미지의 저장 경계 사례** 목록은 의도적인 다른 이미지 이동을 계속 지원합니다.

## 직접 확인

1. [데모](https://pathology-edge-lab.ykh13571.chatgpt.site/)를 새로고침합니다.
2. 이미지 `TNBC 11_1`에서 두 버튼을 번갈아 누릅니다. 이미지 ID는 유지되고 위 표의 좌표와 점수로 바뀝니다.
3. `TNBC 10_2`를 선택합니다. 개선 버튼에 ‘저장 사례 없음’이 표시되고, 악화 버튼은 같은 `10_2`의 경계를 엽니다.
4. 두 화면의 확대·이동과 상세 도구를 확인합니다. 사용자가 이 수정본을 직접 확인했다고 기록하지 않았습니다.

## 검증
