# BCData 공식 test 402장: 원자료 대조와 고정 IHC 모델 점검

2026-11-12 UTC에 공식 test **402장과 양성·음성 HDF5 804개를 실제 확보하고 대조**했다.
원본 주석 65,432행에서 같은 클래스·같은 좌표의 반복 267행을 명시적으로 정리한
**65,165개 고유 중심**에 기존 모델을 적용했다. Accuracy는 **19.97%**, ROI별 종양 양성률
평균 절대오차는 **44.74 percentage points(pp)**였다. 새로 평가한 392장은 각각 **19.72% / 45.27 pp**다.
이 결과는 해당 외부 원자료에서 고정 모델이 안정적으로 전이되지 않음을 보여준다.

**최초의 엄격한 프로토콜은 주석 점검에서 실패했다.** 아래 결과는 원자료 결함을 확인한 뒤,
새 영상의 예측 전에 처리 규칙을 고정한 진단적 평가다. 원본 주석을 수정 없이 그대로 평가한 벤치마크,
환자 단위 검증, 임상 검증, 전체 WSI Ki67 평가로 해석할 수 없다.

## 실제 확보한 원본과 주석

출처는 [BCData 공식 페이지](https://sites.google.com/view/bcdataset),
[원 논문](https://link.springer.com/chapter/10.1007/978-3-030-59722-1_28),
[공식 ZIP](https://drive.google.com/file/d/16W04QOR1E-G3ifc4061Be4eGpjRYDlkA/view)이다.
ZIP central directory의 test PNG 전부를 사전식 경로 순으로 선택했다.
`images/test/<id>.png`를 `annotations/test/positive/<id>.h5`, `negative/<id>.h5`와 짝지었다.
train/validation이나 853,879,248-byte 전체 ZIP은 다운로드하지 않았다.

1,206개 원본 파일의 총 크기는 **266,720,505 bytes**다. 기존 10장에 해당하는 30개 파일은
다시 검증해 재사용했고, 나머지 1,176개는 HTTP 206 범위 요청으로 254,420,585 bytes를 전송했다.
모든 파일의 ZIP CRC32·크기·SHA-256과 RGB 픽셀 해시를 확인했다.
402장의 파일·픽셀 완전 중복과 기존 Patherea source manifest의 동일 PNG 해시 일치는 없었다.
부분 중복, 유사 영상, 환자 독립성은 이 검사로 판정하지 못한다.

[입력 manifest](../artifacts/experiments/bcdata-full-test-20261112/input-manifest.json),
[입력 점검](../artifacts/experiments/bcdata-full-test-20261112/input-audit.json),
[출처 확인](../artifacts/experiments/bcdata-full-test-20261112/sources.json)에 파일별 근거를 남겼다.
640×640 RGB를 그대로 사용했으며 PNG metadata는 비어 있었다. 검증된 개별 μm/pixel 값은 없으므로
물리 해상도를 맞췄다고 주장하지 않는다.

## 실패한 원래 조건과 예측 전 수정

[최초 프로토콜](../artifacts/experiments/bcdata-full-test-20261112/protocol.json)은
2026-11-12 04:13:57 UTC에 고정됐다. 10장에 대한 이전 결과는 이미 알고 있었고,
나머지 392장의 모델 예측은 아직 없었다. 주석 중복·충돌·범위 오류가 있으면 중단하도록 했다.

[엄격한 입력 점검 결과](../artifacts/experiments/bcdata-full-test-20261112/strict-input-audit.json)는
66개 ROI에서 같은 클래스의 반복 좌표 264곳, 초과 주석 **267행**을 확인했다.
`367/378/379`의 양성 주석은 shape `(0,)`, dtype `float64`인 **빈 배열**이었다.
분수 좌표가 있다는 뜻이 아니다. 비정수·비유한·범위 밖 좌표와 양성/음성 충돌은 모두 0개였다.

새 예측을 시작하지 않은 상태에서 [진단적 수정 프로토콜](../artifacts/experiments/bcdata-full-test-20261112/diagnostic-protocol.json)을
**04:21:08 UTC**에 고정했다. 같은 클래스·같은 좌표는 첫 행만 남기고 원래 순서를 유지했다.
빈 `(0,)` 배열은 좌표를 추가하지 않고 `(0,2)`로 해석했다. 원본은 바꾸지 않았다.
고유 중심과 제외된 반복 행의 대응표를 비공개 파일로 먼저 저장하고 SHA-256을 잠근 뒤 예측했다.
고유 좌표는 고유한 생물학적 세포임을 보증하지 않는다.

모든 402장에 평가 가능한 중심이 있었다. ROI 제외·교체는 없고 예측값으로 포함 여부를 정하지 않았다.
원래 주석 조건을 통과한 336장과 영향받은 66장을 별도로 보고한다.
여기서 “주석 조건 통과”는 영상의 병리학적 품질이나 임상 적합성을 뜻하지 않는다.

기존 모델 SHA-256은 `a0d75efdada6a5a2a077e3144ffc7685430a5130de769d69ccc155d511b48a3a`이며
40개 RGB/HSV/optical-density 특징, 반경 3·7 픽셀, 네 클래스 argmax를 유지했다.
학습·튜닝·확률 보정·리사이즈·염색 정규화를 수행하지 않았다.

## 관측 결과

| 평가 범위 | ROI | 고유 중심 | Accuracy | 종양 두 클래스 평균 F1 | ROI 양성률 MAE |
|---|---:|---:|---:|---:|---:|
| 전체 test | 402 | 65,165 | 19.9678% | 0.318103 | 44.7427 pp |
| 새로 평가 | 392 | 63,789 | 19.7166% | 0.317075 | 45.2652 pp |
| 이전에 평가한 영상 | 10 | 1,376 | 31.6134% | 0.347687 | 24.2603 pp |
| 원래 주석 조건 통과 | 336 | 53,826 | 22.0823% | 0.327390 | 41.1505 pp |
| 반복 좌표/빈 배열 처리 대상 | 66 | 11,339 | 9.9303% | 0.264624 | 63.0300 pp |

이전 10장의 영상별·전체 결과는 기존 공개 결과와 정확히 같았다. 두 분류 방식
(새 영상 여부 / 주석 처리 여부)은 같은 402장을 나눈 것이므로 표의 행들을 더하면 안 된다.

전체 혼동행렬의 행은 제공된 정답, 열은 예측이다.

| 정답 ↓ / 예측 → | 종양 + | 종양 − | 비종양 + | 비종양 − |
|---|---:|---:|---:|---:|
| 종양 + | 11,263 | 3,180 | 4,066 | 3,313 |
| 종양 − | 6,873 | 1,749 | 21,497 | 13,224 |
| 비종양 + | 0 | 0 | 0 | 0 |
| 비종양 − | 0 | 0 | 0 | 0 |

정답은 양성 종양 21,822개, 음성 종양 43,343개다. 정답 종양 중심의 **42,100/65,165개**를
비종양으로 예측했다. 양성 종양 F1은 0.563742, 음성 종양 F1은 0.072464다.
네 클래스 macro-F1 0.159052는 정답 support가 없는 비종양 두 클래스에도 기존 F1=0 규칙을
적용한 값이므로 네 클래스 정답이 있는 Patherea의 macro-F1과 직접 비교할 수 없다.

각 ROI의 정답 비율은 `정답 양성/(정답 양성+정답 음성)`, 예측 비율은
`예측 종양 양성/(예측 종양 양성+예측 종양 음성)`이다. 비종양 예측을 종양으로 재분류하지 않았다.
따라서 세포별 오류뿐 아니라 예측 종양 분모의 변화도 비율에 영향을 준다.
정답 분모 0, 예측 분모 0인 ROI는 각각 **0개**, 비교 가능한 ROI는 **402개**다.

원자료의 비상업 연구 제한과 확인되지 않은 재배포 권리 때문에 공개 산출물에는 RGB/HDF5,
좌표·세포별 정답·예측을 포함하지 않았다. 로컬 원본을 확보한 사용자는
`make_private_review.py`로 원본/정답 중심/예측을 나란히 보는 비공개 HTML을 만들 수 있다.
이번 실행에서도 여섯 극값 사례의 비교 페이지를 만들고 최소·최대 비율 사례의 원본 픽셀을 직접 확인했다.

## 검증 범위

별도 검증 프로그램은 모델 지표 함수를 가져오지 않고, 저장된 예측을 읽어 혼동행렬,
precision/recall/F1, 비율, 모든 하위집단 및 극값을 독립적으로 다시 계산했다.
1,206개 입력의 CRC32·크기·SHA-256, 402개 픽셀 해시, 원래 HDF5에서 고유 중심과 반복 행으로
가는 대응표, 프로토콜·모델·특징 코드·실행 코드의 해시도 다시 확인했다.
빈 배열, 중복, 충돌, 비정수·비유한·범위 밖 좌표 처리의 합성 회귀 검사 4개가 통과했다.

평가한 것은 **제공된 종양 중심에서의 분류**다. 세포 검출 누락·가짜 검출, 비종양 GT의 감도,
침윤암 영역 결정, 슬라이드 샘플링, 전체 WSI 점수, 임상 결과, 병리의사의 독립 눈가림 판독은
포함되지 않았다. 주석 처리 집단 간 차이를 중복 주석의 인과효과로 해석할 수도 없다.
