## 제공된 실행 도구

[`scripts/review_bcdata_case.py`](../scripts/review_bcdata_case.py)는 사용자가 새로 작성할 과제가 아닌 제공 도구다.
기존 코드·학습 환경을 보존하는 새 `work` 폴더와 가상환경에서 실행한다.
추가 라이브러리는 해당 가상환경에만 설치하고 기존 설치 패키지는 읽어서 활용한다.

1. 고정 커밋 `f2713b2`의 기존 입력 manifest·결과·좌표 정리 코드·특징 코드·JSON 모델을 받고 각각 SHA를 대조한다.
2. 사용자 로컬의109 PNG와 양성/음성 HDF5 크기·SHA를 대조한다. 정답 중심 중복 처리 규칙도 기존 것을 그대로 사용한다.
3. 제공된 중심 주변 반경3/7px의 색상 특징40개로 기존 고정 분류기를 **한 장에 실제 실행**한다. 새 학습·튜닝·자동 검출·전체402장 재평가는 아니다.
4. 혼동행렬·양성률·분모가 기존109 결과와 일치해야 비교 그림을 생성한다. 다르면 요약을 남기고 성공 화면 생성을 중단한다.
5. 원래 PNG와 정답/예측 중심을 포함하는 독립 SVG를 로컬에 저장한다. 정답 위치를 모델이 검출한 것으로 표시하지 않는다.

이미 존재하는 결과 폴더는 덮어쓰지 않는다. 다운로드·입력·모델 해시 불일치를 거부한다.
입력 원본을 수정하지 않으며 공개 데이터·배포 UI·기존 실험 결과는 변경하지 않는다.
코드·모델·입력 해시와 실제 실행 환경은 `summary.json`에 남긴다.
