# 후보 통합 + 이진 CNN 제거 실험

고정된 학습 검출기의 느슨한 후보와 LoG 후보를 합친 후, 별도의 작은 RGB CNN으로 후보를 제거하는 비교다. **검출 재현율만 높이거나 양성률 MAE만 낮아지는 것을 전체 성능 개선으로 인정하지 않는다.** 기존 실험·기본 모델·공개 데모는 그대로 유지한다.

## 실제 실행 결과 (2026-11-13)

**세 seed 모두 미충족: 0/3. 1,512개 검증 조합 중 FP·FN 동시 비악화 조건을 만족한 조합 자체가 0개였다.** 따라서 새 모델을 채택하지 않았고, 테스트407장·BCData133장 새 추론도 실행하지 않았다. 기준을 낮춰 다시 고르지 않았다.

아래 C는 각 seed의 **검증 케이스 평균 F1이 가장 높았던 진단용 체크포인트**다. 채택 모델이 아니며, 모든 epoch·임계값·거리 결과는 원본 자료에 남아 있다. FP/FN은 검증227장 합계이고 F1은4개 케이스 평균이다.

| seed | epoch / 임계값 / 거리 | FP A → C | FN A → C | 케이스 평균 F1 A → C |
|---|---|---|---|---|
| 20261117 | 1 / 0.7 / 8px | 1,349 → 4,542 | 1,908 → 1,705 | 0.3418 → 0.2486 |
| 20261118 | 1 / 0.6 / 8px | 1,472 → 4,166 | 1,970 → 1,727 | 0.3133 → 0.2616 |
| 20261119 | 4 / 0.7 / 8px | 1,424 → 4,665 | 1,964 → 1,654 | 0.3185 → 0.2619 |

놓친 정답은 줄었지만 FP 증가가 훨씬 컸다. 이번 학습·후보·설정 범위에서는 동시 개선에 실패했다. 후보 공급이 늘었다는 사실만으로 최종 정확도 향상을 주장할 수 없다. 주석 기반 음성 대용의 한계나 후보 분포 차이가 원인일 수 있으나, 이번 결과만으로 원인을 확정하지 않는다.

학습 소스: `47cc9f0fe33551714b29371fa8412b1b76464328`. 고정 원본·실행 설정·전체 검증 점수·epoch당42조합·seed당504조합의 기록·진단용3모델·선택 잠금·미실행 증거는 [실험 자료](../artifacts/experiments/ki67-union-20261113/)에 있다.

## 고정 설계와 데이터

- [사용자가 승인한 설계](superpowers/specs/2026-11-13-ki67-union-gate-design.md), 구현 계획: [plan](superpowers/plans/2026-11-13-ki67-union-gate.md).
- Patherea train 696장/15케이스, validation 227장/4케이스. 원영상·다섯 종류 주석 파일 SHA와 그룹/픽셀 분리 검사 후 train/validation만 학습 단계에서 읽는다.
- 이미 사용했던 test407/10케이스·BCData133은 새 미노출 평가가 아니다. 세 seed의 선택을 모두 잠근 후 **조건 충족 모델만** 재평가할 수 있다.
- 검출기 seed20261117/18/19와 새 gate seed를 짝지었다. 기존 검출기·LR/CNN 4분류기의 가중치는 고정했다. 순수 gate 초기값만 바꾼 실험이나 검출기 재학습은 아니다.
- 학습 후보는 threshold0.01/distance4px, LoG는 response0.1/distance8px/sigma1.5·2.5·3.5. 서로 다른 출처의 점수를 직접 비교하지 않고 정확히 같은 좌표만 합친다.
- Gate: native32×32 RGB → Conv8/16/32(블록마다3×3두개, LeakyReLU0.1, pooling2) → flatten512 → 2개 logit(19,210파라미터). Adam0.001, batch64,12epoch,CPU2threads.
- 양성은 주석 중심(±3px jitter) 또는6px 이내 일대일 대응한 후보 중심이다. 음성 대용은 모든 주석에서12px 초과 떨어지고 가장자리24px를 제외한 후보, 최대256개/이미지다. 주석 없는 실제 세포가 음성 대용에 들어갈 수 있어 **전문가가 검증한 배경 정답이 아니다.**
- 각 배치는 양성·음성1:1, 각 레이블 안에서 케이스를 균등하게 고른다. 학습에만 회전/반전/RGB배율0.9–1.1을 적용한다. 기존 검출기의 학습 내 후보를 사용한 편향 가능성도 남는다.

## 선택 규칙

12epoch ×14개 임계값 ×3개 거리 = seed당504조합을 검증 자료에서 비교한다. 임계값은0/.05/.1/.2/.3/.4/.5/.6/.7/.8/.9/.95/.99/1, 거리는4/6/8px다.

다음을 모두 만족해야 채택 후보가 된다.

1. 같은 seed 기존 검출기 A보다 FP·FN이 각각 늘지 않으며, 하나 이상은 감소.
2. 기존 LoG의 케이스 평균 재현율0.4797951648, 양성 종양 위치 재현율270/483, 음성 종양 위치 재현율439/1292 이상.
3. 모든 검증 케이스의 재현율이 같은 케이스 A의90% 이상.

조건 충족 조합 중 케이스 평균 F1을 최대화한다. 동률은 재현율, 이른epoch, 높은 임계값, 큰 거리 순이다. 조건 충족 조합이 없으면 해당 seed는 실패다. 진단용 최고 F1 모델은 채택 모델이 아니다. 결과를 보고 규칙을 완화하지 않는다.

## 비교 화면 읽기

- **A:** 기존 고정 학습 검출기.
- **B:** 느슨한 학습 후보 + LoG 후보를 동일 좌표에서만 통합. 후보 공급량 확인용이며 억제 정책이 동일하지 않다.
- **C0:** 새 CNN 점수순 거리 억제, 임계값0.
- **C:** 같은 점수·거리 조건에 선택 임계값 적용. 실패 seed에서는 진단용 모델임을 표시한다.

각 seed에서 이미지별 `(FP+FN) C − A`가 최소/최대인 검증 이미지를 보여준다. 같은224×224좌표, 실제 저장 후보·정답 중심을 겹쳐 표시한다. 표의 FP/FN은227장 합계, F1/재현율은 케이스별 평균이다. 화면 아래 지표는 선택한 단일 이미지 기준이다. 핵 윤곽이나 종양 분류 정확도와 혼동하지 않는다.

## 재현 명령

실행 폴더는 저장소 루트다. 원본 비공개 작업 자료가 있는 환경에서만 학습 명령을 실행할 수 있다. 공개 저장소만 내려받았다고 데이터·이전 가중치가 자동으로 생기는 명령은 아니다. `--prior`에는 기존 학습 검출기 실행 폴더를, `--output`에는 존재하지 않는 새 폴더를 넣는다.

```bash
python -m pytest -q tests/test_ki67_union.py tests/test_ki67_union_experiment.py tests/test_ki67_union_audit.py
python scripts/run_ki67_union.py prepare --prior work/learned-centers-leaky-run-20261113 --output work/union-gate-new
python scripts/run_ki67_union.py fit --output work/union-gate-new
python scripts/run_ki67_union.py internal --output work/union-gate-new
python scripts/run_ki67_union.py external --output work/union-gate-new
python scripts/audit_ki67_union.py --output work/union-gate-new
python scripts/export_ki67_union_review.py --output work/union-gate-new --review work/union-review-new
```

`internal`/`external`은 통과 seed가 없으면 새 영상 추론 없이 미실행 사유만 기록한다. 준비·선택 잠금 파일은 원자료/소스/가중치/저장 후보의 SHA를 확인한다. 감사는 별도 억제·선택 구현으로 모든1512조합의 지표를 재계산하고, 실제 주석과 후보 출처·선택/진단 체크포인트의 점수를 재추론해 대조한다.

## 사용자 확인 상태

U101은 개선 방향 선택, U102는 설계에 따른 구현·실험 실행 승인이다. 이번 구현·학습·감사·브라우저 검사는 사용자 직접 수행 항목이 아니다. 새 결과 화면의 사용자 검토는 답변이 오기 전까지 대기 상태다. 기존 사용자 작성 실습 파일은 수정하지 않는다.
