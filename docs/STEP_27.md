# 27단계: WSI 전체 탐색과 모델 분석 범위 구분

상태: **2026-11-09 사용자 분석 범위 해석 확인 완료**. 전체 탐색과 일부 ROI 예측을 구분하고, 정답 기반 경계 분할 평가는 TNBC7장·2개 그룹에서 수행했으며 WSI 전체 검증은 하지 않았다고 설명했습니다. [답변·범위](../artifacts/learning/step27-review.json). 아래는 완료한 검토의 참고이며, 다음은 [28단계 IHC 실패 사례 표시 확인](STEP_28.md)입니다.

## 확인할 근거

| 항목 | 현재 구현·저장 결과 |
|---|---|
| 확대 탐색할 수 있는 원본 | 46000×32893 전체 슬라이드 |
| 모델을 실행한 영역 | 사전 선택한 R1·R2·R3, 각각1024×1024 |
| 분석한 픽셀 수 | 3,145,728 |
| 원본 파일 픽셀 중 분석 비율 | 0.2079% |
| 이 WSI의 핵 정답 | 없음 |

비율의 분모는 배경을 포함한 원본 파일 전체 픽셀1,513,078,000개입니다. 조직 면적 중 몇 퍼센트를 분석했는지 측정한 값이 아닙니다. 화면 왼쪽 ROI 목록 아래에도 같은 분석 범위가 표시됩니다.

## 질문 하나

**면접에서 “전체 슬라이드를 확대해서 볼 수 있으므로, WSI 전체의 핵 분석과 성능 검증도 완료했다”고 설명해도 될까요? 실제 탐색 범위와 모델 분석·검증 범위를 구분해 한두 문장으로 설명해 주세요.**

## Codex 확인 범위

`dist/wsi.json`의 세 ROI가 원본 범위 안에 있고 서로 겹치지 않는지 확인했습니다. 각 영역의 픽셀 수를 합산하고 원본 파일 크기로 나눠 저장된 `total_pixels`·`slide_fraction`과 화면 반올림 비율이 일치하는지 대조했습니다. 원본 파일이나 조직 면적을 새로 분석한 것은 아닙니다. 새 모델 추론·브라우저 검사·정답 평가도 수행하지 않았습니다.

사용자 설명은 정확하며 해석 완료로 기록했습니다. 이 문서의 수치 대조는 Codex 작업이고, 사용자가 새 성능 평가를 수행한 것으로 기록하지 않습니다. 위 TNBC 평가는 경계 분할 실험에 관한 설명입니다. 별도 데이터·모델의 IHC 분류 평가와 구분하며, 다음 단계에서 IHC 결과를 확인합니다.
