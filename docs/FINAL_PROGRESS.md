## 8. 전달 파일 사용 방법

ZIP의 `START_HERE.txt` → 이 문서 → `COWORK_HANDOFF.md` → `CONTRIBUTIONS.md` 순서로 읽으면 됩니다. `SCREENSHOTS.md`에는 기존 화면과 실제 실패/개선 그림이, `EVIDENCE_DOWNLOADS.md`에는 큰 원본 증거 ZIP의 고정 링크·SHA가 있습니다. `manifest.json`은 포함 파일별 SHA와 출처를 기록합니다.

전체 실행 환경·데이터셋을 복사한 설치 패키지가 아닙니다. 실행은 저장소와 [RUNBOOK](RUNBOOK.md)을 사용합니다. BCData 원영상·HDF5·세포별 좌표와 비공개 검토 HTML은 이 전달 ZIP에 포함하지 않습니다. 연구용 접근 허용만으로 재배포 가능하다고 간주하지 않았습니다. 공개 그림의 라이선스·출처는 ZIP의 `LICENSES_AND_SCOPE.txt`를 따릅니다.

Cowork는 이 자료로 지원 문안을 작성할 수 있지만, 프로젝트 전체 단독 개발·임상 검증·전체 WSI 분석·자동 IHC 검출·논문 재현을 완료했다는 문장을 만들면 안 됩니다. 직접 수행 범위를 남기면서 실패 분석·원자료 대조·재현 근거를 프로젝트의 장점으로 설명합니다.
