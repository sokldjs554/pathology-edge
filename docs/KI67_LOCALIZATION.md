# 후보 점수 정렬 수정과 위치 보정 실험 — 2026-11-14

**정렬 오류는 수정 완료. 성능은 일부 개선됐으나 기존의 모든 재현율·FP/FN 조건을 만족하는 안정성 목표는 아직 미달성이다.** 기본 모델과 공개 서비스는 변경하지 않았다.

## 1. uint8 오류와 기존 결과 보존

`retain_candidates`가 unsigned 점수를 음수로 바꿀 때 정수가 감싸져 낮은 점수가 먼저 처리되는 문제가 있었다. 입력 검사를 마친 점수를 float64로 변환한 뒤 정렬·임계값 비교를 수행하도록 수정했다. float32 임계값 비교의 반올림 문제도 함께 방지한다.

uint8/16/32/64 정렬·근접 후보 억제 및 float32 경계값 회귀를 추가했다. 수정 전 7개 실패를 재현했고 수정 후 통과했다. 기존 float64 후보 선택 681건이 고정 이전 구현과 정확히 일치하며 기존 실험 파일 80개의 SHA256도 유지됐다. frozen_source와 과거 결과는 변경하지 않았다.

## 2. 무엇을 추가했나

이전 gate가 후보를 유지할지만 예측했던 것에서, **실제 검출 후보 주변 RGB와 후보 출처·점수를 사용해 유지 점수와 중심 이동량을 함께 예측**하도록 확장했다. 이전처럼 정답 중심에 놓인 crop을 양성 학습 자료로 추가하지 않는다.

- 기존 3개 검출기는 고정. seed20261117/18/19에 대응하는 새 CNN만 각각12epoch 학습했다.
- train696장/15케이스, validation227장/4케이스를 유지했다. 세포 주석10751/2802개. 같은 자료를 반복 사용한 탐색 실험이다.
- 실제 후보와 가장 가까운 주석의 거리12px 이내를 양성 근방, 그보다 멀고 가장자리24px를 제외한 후보를 음성 대용으로 사용한다. 주석에서 멀다는 사실은 전문가의 비세포 정답이 아니다. 주석이 없는 이미지에서 음성을 만들지 않는다.
- 양성/음성1:1, 케이스와 양성 정답 단위 균형 샘플링. 후보 메타데이터 표준화는 train 후보만으로 계산한다.
- 경계에서 반사 패딩, 중심이 정확한33px 문맥에서 회전/반전한 뒤32px 입력을 만든다. 이동 벡터도 함께 변환한다.
- 연속 이동량은 최대12px. `rint` 반올림·영상 범위 자르기 후 저장 좌표는 최대 약12.71px까지 움직일 수 있다. 실제 저장 정수 좌표로 평가한다.
- 12epoch×14임계값×3거리 = seed당504개, 합계1512개 검증 조합. 기존 선택 조건을 완화하지 않았다.

## 3. 관찰 결과와 남은 조건

아래는 각 seed에서 **전체 검증 케이스 평균 F1이 가장 높은 진단용 설정**이다. FP/FN은227장 합계, F1은4케이스 평균이다. 채택된 모델이나 테스트 결과가 아니다.

| seed | epoch / 임계값 / 거리 | A FP → R FP | A FN → R FN | A F1 → R F1 |
|---|---|---|---|---|
| 20261117 | 4 / 0.8 / 8px | 1,349 → 1,633 | 1,908 → 1,713 | 0.3418 → 0.3802 |
| 20261118 | 9 / 0.7 / 8px | 1,472 → 2,644 | 1,970 → 1,526 | 0.3133 → 0.3748 |
| 20261119 | 9 / 0.7 / 8px | 1,424 → 2,808 | 1,964 → 1,491 | 0.3185 → 0.3709 |

세 seed 모두 최고 F1은 올랐지만 이 설정들의 FP는 증가했다. 같은 체크포인트·점수·설정에서 이동을 끈 S의 F1은 각각0.3364/0.3067/0.3011, 이동을 켠 R은0.3802/0.3748/0.3709였다. 이는 추론 시 이동의 기여를 보여주지만 새 학습법의 모든 변경 원인을 분리한 실험은 아니다.

**FP·FN 동시 비악화만 만족한 조합은 이전0/0/0개에서 이번12/10/5개로 늘었다.** 이 부분의 개선은 실제 관찰됐다. 아래는 해당 조합 중 최고 F1의 **사후 진단용** 설정이다. 원래 선택 규칙을 대체하지 않았다.

| seed | epoch / 임계값 / 거리 | FP A → R | FN A → R | 케이스 평균 재현율 R | 종양+ / 종양− 위치 재현율 R |
|---|---|---|---|---|---|
| 20261117 | 8 / 0.8 / 8px | 1,349 → 1,186 | 1,908 → 1,845 | 0.3506 | 0.3623 / 0.2276 |
| 20261118 | 9 / 0.8 / 8px | 1,472 → 1,263 | 1,970 → 1,835 | 0.3530 | 0.3810 / 0.2531 |
| 20261119 | 9 / 0.8 / 8px | 1,424 → 1,410 | 1,964 → 1,807 | 0.3641 | 0.3209 / 0.2454 |

이 설정들은 각 케이스 A재현율의90% 조건도 통과했으나, 기존 LoG의 케이스 평균 재현율0.4798·종양+0.5590·종양−0.3398 하한에 못 미쳤다. 따라서 **전체 선택 조건 통과는0/3**이고 실제 테스트·BCData 새 추론은 실행하지 않았다. `stability.json`의 test_passes0은 '테스트를 실행해 세 번 실패'라는 뜻이 아니라, 자격 미달로 테스트 성공 증거가 없는 세 seed를 분모3에 유지한 것이다.

학습 단계에서 자료의 모든 주석은 영상 가장자리까지 존재함을 확인했다. 가장자리 FP가 많다는 관찰만으로 '중앙만 주석된 데이터'라고 가정해 평가 영역을 줄이지 않았다. 가장자리 음성 학습 제외, 불완전할 수 있는 배경 대용, 제한된 사례 수 등의 영향은 분리 검증되지 않았다. 이 결과만으로 병리학적 오류 원인을 확정하지 않는다.

## 4. 결과 화면과 검증

[실험 원본](../artifacts/experiments/ki67-localization-20261114/) · [검토 화면](../artifacts/experiments/ki67-localization-20261114/review/index.html) · [확인 순서](STEP_90.md).

A는 기존 검출기, U는 후보 통합, S는 새 점수로 원래 좌표에서 선택, R은 같은 점수로 보정 좌표에서 선택한다. S는 이전 실험의 C0(임계값0)가 아니다. R의 흰 화살표는 살아남은 후보의 원래 좌표→보정 좌표다. 모든 패널은 같은224×224원영상을 사용한다. 6개 사례는 각 seed에서 검증 이미지의 `(FP+FN) R−A` 변화가 최소·최대인 예시다. 전체 평균이나 대표 성능으로 간주하지 않는다.

학습 소스: `f16a726e59279c1ce1e19f764a52c2487087f6a6`. 고정 프로토콜, 학습 손실, 모든 epoch 점수·정수 좌표, 진단용 체크포인트3개, 선택 잠금, 미실행 기록을 보존한다. 검증의 최종 수치는 원본 폴더의 `audit.json`, `verification.json`, `review/browser.json`을 기준으로 한다.

검증 완료: 집중 회귀75개, 저장 Dice42개·평균6개 일치, 독립 감사1512조합·681건 재추론 대조. Chromium1440×1000/390×844에서6개 예제의 동일 영상·수치·원래→보정 좌표 대응, 화살표 전환, 후보 표시, 이전/다음과 가로 넘침을 확인했다. 콘솔 오류0. 학습 소스 f16a726의 깨끗한 CI는643개 검사를 통과했다. 최종 감사·화면 소스54091ef의 [CI](https://github.com/sokldjs554/pathology-edge/actions/runs/43574653698)에서646개 검사와 저장 Dice·기존 데모 검사가 모두 통과했다. 로컬 전체 검사는 디스크 제약 때문에 실행하지 않았다.

[데스크톱](../artifacts/experiments/ki67-localization-20261114/review/desktop.png) · [작은 화면](../artifacts/experiments/ki67-localization-20261114/review/mobile.png) · [FP·FN 조건 세부 표](../artifacts/experiments/ki67-localization-20261114/review/joint-settings.png).

독립 검토에서 실제0적격 실행에 영향을 주는 Critical/Important 항목은 발견하지 않았다. 감사 범위의 한계도 남긴다. 학습 normalizer는 저장 보고와 체크포인트를 비교했으며 train 후보를 전부 독립 재생성해 평균/분산을 다시 구한 것은 아니다. 향후 적격 모델의 holdout 감사는 저장 지표·좌표 재계산 경로이며 원본 GT/영상/모델 전체 재추론 감사가 아니다. 이번에는 해당 경로를 실행하지 않았다.

## 5. 실행 범위와 사용자 확인

이번 구현·학습·자동 감사·브라우저 검사는 사용자가 직접 실행한 작업으로 기록하지 않는다. 이전 U103은 이전 후보 통합 화면의 첫 네 패널 표시 확인까지만 완료다. 이번 새 화면은 사용자 확인 전이다. 사용자 작성7개 파일과 기존 dist는 보존한다.

외부·임상·전체 WSI 검증을 새로 수행하지 않았다. 성능이 좋아 보이는 설정만 선택해 기존 재현율 기준을 숨기거나 반복 노출된 검증 결과를 새로운 일반화 증거로 해석하지 않는다. 다음 연구에는 검출 누락·종양 클래스 재현율 자체를 높이는 학습 자료/표적 설계가 필요하지만 이번 고정 실험에서 그 효과까지 입증한 것은 아니다.

## 재현 명령

저장소 루트에서 다음을 실행한다. 검사 명령은 코드 회귀를 확인한다.

```bash
python -m pytest -q tests/test_ki67_union.py tests/test_ki67_localization.py tests/test_ki67_localization_experiment.py tests/test_ki67_localization_audit.py
```

아래 학습은 이전 검출기 실행 폴더·원본 자료가 연결된 환경에서만 가능하다. 새 output 경로를 사용한다. 공개 자료의 protocol에 담긴 절대경로를 다른 환경에서 자동으로 재작성하지 않는다.

```bash
python scripts/run_ki67_localization.py prepare --prior work/learned-centers-leaky-run-20261113 --output work/new-localization
python scripts/run_ki67_localization.py fit --output work/new-localization
python scripts/run_ki67_localization.py internal --output work/new-localization
python scripts/run_ki67_localization.py external --output work/new-localization
python scripts/audit_ki67_localization.py --output work/new-localization
python scripts/export_ki67_localization_review.py --output work/new-localization --review work/new-localization-review
```

internal/external은 세 seed 선택을 잠근 후 적격 모델이 있을 때만 평가한다. 원자료 경로와 고정 소스가 일치하지 않으면 감사가 실패하도록 설계했다. 새 소스 검증은 frozen 학습 소스와 구분한다.
