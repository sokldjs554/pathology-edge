상태: **2026-11-10 갱신**. 아래는 초기 TNBC 검토용 참고자료입니다. 이후 사용자 이동 정상 보고와 IHC 해석 33단계까지의 검토를 받았습니다. 실제 확인 범위는 [기여 기록](CONTRIBUTIONS.md), 남은 후보는 [검토 현황](NEXT_STEPS.md), 지원 전 권고는 [공고 대조](JOB_MATCH_2026-11-10.md)를 따릅니다. 초기 안내를 현재 미완료 과제로 해석하지 않습니다.
Codex가 설명을 작성했다는 사실만으로 사용자 이해·승인을 완료 처리하지 않습니다.

## 데이터와 분리

자료: `docs/RESEARCH.md`, `artifacts/manifest.json`, `artifacts/analysis.json`.

- 이미지: H&E 512px PNG. 라벨: 모든 핵의 이진 foreground, 0/255.
- Ki-67 양성/음성·종양 여부를 이 라벨에서 알 수 있는가? 없다면 어떤 주장을 하지 않아야 하는가?
- 33/10/7장의 분리에서 폴더 그룹이 겹치지 않는다는 것과 환자 명부를 검증했다는 것은 어떻게 다른가?

- hash 검사로 염색이 바뀐 near-duplicate까지 찾을 수 있는가? 현재 검사는 정확한 바이트 중복만 찾는다.

## 경계 처리와 평가

자료: `src/pathology_edge/patches.py`, `merge.py`, `artifacts/evaluation.json`, `analysis.json`.

- 기준 패치 128px, stride128. 겹침 64px, stride64. 오른쪽/아래 남는 영역은 흰색 padding.
- 픽셀 경로는 확률 가중 합산 후 threshold, 성분 경로는 patch별 이진 연결 성분과 별도 NMS.
  두 결과가 항상 같은 개수여야 할까? 현재는 아니다.
- NMS는 다른 패치 사이에만 적용, 완전한 성분을 먼저 선택한다. 경계 상자 IoU≥0.3 또는 중심 거리≤8px.
  가까운 다른 핵을 잘못 합치거나, 잘린 조각의 중심이 멀어 중복이 남을 수 있다.
- 비교에 쓰는 경계는 두 방식 모두 **기준 방식의 내부 seam 양쪽 8px**이다.
  방식을 바꿀 때 평가할 경계도 바꾸면 왜 비교가 공정하지 않을까?
- 전체 Dice는 조금 좋아졌지만 그룹10은 악화, 그룹11은 개선이다. ‘문제를 해결했다’고 말할 근거가 충분한가?

[이동 오류 수정 기록](PAN_FIX.md#직접-확인할-한-단계) 이후 TNBC 드래그·스크롤과 WSI 이동의 사용자 정상 보고를 받았습니다. 아래는 초기 UI 흐름의 참고표이며 일부 버튼명은 이후 바뀌었습니다. 현재 화면 설명은 [면접용 경계 비교](INTERVIEW_UI.md)와 [WSI·IHC 보고](WSI_REVIEW.md), 실제 사용자 완료 범위는 기여 기록을 따릅니다.

`사용 안내`에는 단축키와 연구 범위가 있습니다. 선택·확대·이동은 브라우저 로컬 동작입니다.
예제 선택은 사전 계산 JSON·PNG를 읽습니다. 실시간 모델 API가 실행된 것으로 설명하지 않습니다.

실패 시 예제ID, 비교모드, 조작 순서, 브라우저/OS, 창 크기, 오류 문구를 보내 주세요.
터미널 테스트는 실행 폴더·명령·전체 오류 출력도 필요합니다. 토큰이나 개인 의료 영상은 필요 없습니다.

## 지표와 화면 연결

`model.pt` → `predictions/<mode>/<id>.npy` → 동일 threshold의 PNG → `dist/assets/*_<mode>.png`.
`objects_<mode>.json`의 좌표와 `eval_<mode>.json`의 지표를 `dist/results.json`으로 내보냅니다.
테스트는 mask·overlay 픽셀 일치와 객체 개수·좌표 범위·평가 숫자·모델 hash를 확인합니다.
브라우저 조작 QA는 다른 검증이며, 정적 파일 테스트가 이를 대신하지 않습니다.

## 면접에서 판단하고 설명할 것

‘경계 주변 지표가 개선되었으나 전체 효과는 작고, 처리 시간이 증가했다’는 제한된 결론이 맞습니다.
소규모 두 그룹·한 seed로 일반화·통계적 유의성·임상적 유효성을 증명하지 않았습니다.
환자 단위 독립 명부, 외부 정확도 검증, 전문가 리뷰, ViT 비교는 미수행입니다. 이후 실제 WSI 탐색·일부 ROI 추론과 별도 IHC 정답 중심 조건의 분류·주석 세포 양성률 비교를 추가했습니다. 이는 TNBC에 Ki-67 라벨을 추가한 것이 아니며, 전체 WSI 정답 검증이나 임상 Ki-67 분석도 아닙니다.

추가 학습이나 NMS 조정은 validation으로 돌아가서 새 실험을 설계해야 합니다. 이번 test 결과를
보며 반복 개선하면 같은 test를 최종 성능 근거로 계속 사용할 수 없습니다.
본인이 쓴 좌표 함수, 본인이 돌린 재현 명령, Codex가 학습·검증한 결과를 구분해서 말합니다.
