# 33단계: IHC 예측 점수와 정확도 구분

상태: **사용자 해석 대기**. [32단계](STEP_32.md)에서 주석 세포 기반 양성률 결과와 전체 WSI·임상 검증을 구분했습니다. 이번에는 첫 실패 사례의 예측 점수 한 항목을 해석합니다. 추가 화면 조작·코드·설치·터미널 실행은 없습니다.

## 저장된 점수와 질문 하나

[첫 실패 사례](https://pathology-edge-lab.ykh13571.chatgpt.site/ihc.html?example=incorrect-01)의 정답은 **Ki67 양성 종양 세포**, 예측은 **Ki67 양성 비종양 세포**입니다. 선택 클래스의 저장 점수는 `0.5091868891451504`이며 화면에서는 **예측 점수 50.9%**로 표시하도록 구현되어 있습니다.

**이 50.9%를 “이 세포의 판정이 맞을 확률이 50.9%라고 검증된 값”으로 설명해도 될까요? 실제로 무엇을 나타내는 수치인지 한두 문장으로 설명해 주세요.**

참고자료는 [IHC 실험 설명](IHC_EXPERIMENT.md)의 확률 보정 항목과 데모 **결과·출처** 패널의 점수 안내입니다. 사용자의 해당 점수 표시·패널 조작 확인은 별도로 받지 않았으며 이번에는 의미 해석만 요청합니다.

## Codex 확인 범위

원본·공개 예제와 해당 위치의 유일한 테스트 행에서 클래스·점수 벡터가 일치합니다. 선택 점수는 네 클래스 점수 중 최댓값이고 저장된 예측 클래스에 해당합니다. `dist/ihc.js`의 백분율 변환·소수 첫째 자리 표시가 50.9%와 연결됩니다.

학습 선택 기록·원본·공개 보고의 확률 보정 여부가 일치하고 화면 안내도 같은 범위를 설명합니다. 기존 저장 점수와 코드·메타데이터만 대조했으며 새 추론·확률 보정·학습·브라우저 검사는 실행하지 않았습니다. 사용자 해석은 답변을 받은 뒤 기록합니다.
