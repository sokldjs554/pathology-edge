# 33단계: IHC 예측 점수와 정확도 구분

상태: **2026-11-10 (Asia/Seoul) 사용자 해석 확인**. 예측 클래스의 모델 점수이며 보정·검증된 정답 확률이나 임상 신뢰도가 아니라는 설명을 받았습니다. 배정한 IHC 해석 질문인 29~33단계의 답변 검토를 마쳤습니다. [확인 범위와 남은 후보](NEXT_STEPS.md)를 구분해 두었으며 새 과제는 배정하지 않았습니다.

## 저장된 점수와 질문 하나

[첫 실패 사례](https://pathology-edge-lab.ykh13571.chatgpt.site/ihc.html?example=incorrect-01)의 정답은 **Ki67 양성 종양 세포**, 예측은 **Ki67 양성 비종양 세포**입니다. 선택 클래스의 저장 점수는 `0.5091868891451504`이며 화면에서는 **예측 점수 50.9%**로 표시하도록 구현되어 있습니다.

**이 50.9%를 “이 세포의 판정이 맞을 확률이 50.9%라고 검증된 값”으로 설명해도 될까요? 실제로 무엇을 나타내는 수치인지 한두 문장으로 설명해 주세요.**

참고자료는 [IHC 실험 설명](IHC_EXPERIMENT.md)의 확률 보정 항목과 데모 **결과·출처** 패널의 점수 안내입니다. 사용자의 해당 점수 표시·패널 조작 확인은 별도로 받지 않았으며 이번에는 의미 해석만 요청합니다.

## 사용자 답변과 확인 범위

> 아니요. 50.9%는 로지스틱 회귀 모델이 예측한 클래스(‘Ki67 양성 비종양 세포’)에 부여한 점수이며, 실제 판정이 맞을 확률로 검증된 값은 아닙니다. 확률 보정이 수행되지 않았으므로 이 수치를 임상적 신뢰도나 정답 확률로 해석해서는 안 됩니다.

저장 모델의 선택 클래스 점수와 확률 보정 기록에 맞는 설명입니다. Codex가 수치·참고자료·질문을 제공했고 사용자가 의미를 해석했습니다. 사용자 확률 보정 실험이나 점수 표시 조작을 확인한 것으로 기록하지 않습니다. [답변 원문과 범위](../artifacts/learning/step33-review.json).

## Codex 확인 범위

원본·공개 예제와 해당 위치의 유일한 테스트 행에서 클래스·점수 벡터가 일치합니다. 선택 점수는 네 클래스 점수 중 최댓값이고 저장된 예측 클래스에 해당합니다. `dist/ihc.js`의 백분율 변환·소수 첫째 자리 표시가 50.9%와 연결됩니다.

학습 선택 기록·원본·공개 보고의 확률 보정 여부가 일치하고 화면 안내도 같은 범위를 설명합니다. 답변 검토 시 준비 기록의 입력 해시 7개가 그대로임을 확인했습니다. 기존 저장 점수와 코드·메타데이터만 대조했으며 새 추론·확률 보정·학습·브라우저 검사는 실행하지 않았습니다.
