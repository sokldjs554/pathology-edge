# 15단계: 두 손가락 스크롤 이동 확인

상태: **사용자 두 손가락 스크롤 확인 대기**. 14단계의 클릭 드래그 질문에 사용자가 “응 잘 이동해”라고 답해 해당 조작은 완료로 기록했습니다. 두 손가락 스크롤까지 확인한 것으로 기록하지 않았습니다.

## 직접 할 조작 하나

같은 `10_1 → 현재 예제 경계` 확대 화면에서 **커서를 영상 안에 두고 트랙패드의 두 손가락을 위아래로 함께 움직여 스크롤**합니다. ⌘/Ctrl 키는 누르지 않습니다. 두 손가락을 벌리는 확대 제스처와 구분합니다.

정상이라면 양쪽 영상이 함께 이동하고 확대 배율은 유지됩니다. 손가락 움직임과 영상 이동 방향의 관계는 macOS의 자연스러운 스크롤 설정에 따라 달라질 수 있습니다.

**양쪽 영상이 함께 이동하는지** 알려 주세요. 이동 대신 확대되거나 웹페이지가 스크롤되거나 한쪽만 움직이면 그 현상과 브라우저 이름을 적어 주세요. 트랙패드가 없으면 미실행이라고 알려 주시면 됩니다.

화면을 닫았다면 [데모](https://pathology-edge-lab.ykh13571.chatgpt.site/)에서 TNBC10_1을 선택하고 **현재 예제 경계**를 누릅니다. 추가 코드나 터미널 실행은 없습니다.

## 확인 범위

기존 `dist/app.js`는 일반 wheel 입력으로 공유 시야 중심을 이동하고, Ctrl/Meta가 눌린 wheel 입력으로 확대합니다. 관련 회귀 검사 정의는 `web-tests/pan.spec.js`에 있습니다. 이번 턴에는 구현·검사 정의를 읽었으며 새 브라우저 테스트를 실행하지 않았습니다. 실제 사용자 트랙패드의 결과는 위 답변을 받은 뒤 기록합니다.
