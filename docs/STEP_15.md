# 15단계: 두 손가락 스크롤 이동 확인

상태: **2026-11-09 사용자 두 손가락 스크롤 보고 확인 완료**. 요청한 조작에 사용자가 “잘 작동해”라고 답했습니다. 14단계의 클릭 드래그와 이번 스크롤을 현재 확인한 화면의 정상 동작 보고로 각각 기록했습니다. [확인 원문·범위](../artifacts/learning/step15-review.json).
아래는 완료한 조작의 참고입니다. 다음은 [16단계 강조 표시 전환](STEP_16.md) 하나입니다.

## 직접 할 조작 하나

같은 `10_1 → 현재 예제 경계` 확대 화면에서 **커서를 영상 안에 두고 트랙패드의 두 손가락을 위아래로 함께 움직여 스크롤**합니다. ⌘/Ctrl 키는 누르지 않습니다. 두 손가락을 벌리는 확대 제스처와 구분합니다.

정상이라면 양쪽 영상이 함께 이동하고 확대 배율은 유지됩니다. 손가락 움직임과 영상 이동 방향의 관계는 macOS의 자연스러운 스크롤 설정에 따라 달라질 수 있습니다.

요청한 조작의 정상 보고를 받았습니다. 이후 이동 대신 확대되거나 웹페이지가 스크롤되거나 한쪽만 움직이면 그 현상과 브라우저 이름을 적어 주세요.

화면을 닫았다면 [데모](https://pathology-edge-lab.ykh13571.chatgpt.site/)에서 TNBC10_1을 선택하고 **현재 예제 경계**를 누릅니다. 추가 코드나 터미널 실행은 없습니다.

## 확인 범위

기존 `dist/app.js`는 일반 wheel 입력으로 공유 시야 중심을 이동하고, Ctrl/Meta가 눌린 wheel 입력으로 확대합니다. 관련 회귀 검사 정의는 `web-tests/pan.spec.js`에 있습니다. 준비 당시 구현·검사 정의를 읽었으며 새 브라우저 테스트를 실행하지 않았습니다. 이후 사용자에게 정상 동작 보고를 받았지만 브라우저·장치 상세, 정확한 배율 유지, 다른 이미지·배율까지 별도로 확인하지는 않았습니다.
