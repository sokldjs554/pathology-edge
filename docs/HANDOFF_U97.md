## 최근 비교를 읽는 기준

재현율 조건 비교는 학습한 중심 seed20261117의 기존 설정 A와 검증 조건을 적용한 B를 비교한다. 재학습은 없었다. Patherea 기존 test407장의 위치 기준 수치는 아래와 같다.

| 위치 검출 지표 | A: 점수 0.1 / 간격 8px | B: 점수 0.03 / 간격 4px |
|---|---:|---:|
| TP | 2,531 | 3,890 |
| FP | 5,297 | 30,134 |
| FN | 3,888 | 2,529 |
| 재현율 | 0.394298 | 0.606013 |
| 정밀도 | 0.323327 | 0.114331 |
| 위치 F1 | 0.355303 | 0.192370 |

4개 고정 분류기 모두 내부·외부 양성률 MAE는 감소했지만, 세포 검출·분류 F1은 모두 하락했다. 양성률 분자·분모의 오차가 상쇄될 수 있으므로 양성률 개선을 세포 분석 전체의 개선이라고 쓰지 않는다. 외부 BCData133장은 반복 사용한 자료이며 새 미노출 검증이 아니다. seed는 초기화뿐 아니라 학습 순서·증강에도 영향을 준다. 이번 결과로 초기화만이 실패 원인이라고 확정하지 않는다.

## 남은 범위와 다음 순서

09_1·09_6 그림 표시 확인은 완료했다. 현재 개인 과제는 [STEP86](STEP_86.md)의 두 사례 FP·FN 해석 한 단계다. 정리·근거 확보를 넘어 성능 연구를 계속한다면 검출 누락과 오검출, 종양 양성/음성 계수, seed별 변동을 함께 개선해야 한다. 후속 학습·선택은 train/validation에서 수행하고, 이미 본 외부 결과는 재평가로 보고해야 한다. **새 연구의 성능 개선은 아직 약속하거나 완료 처리할 수 없다.**

임상 검증과 전체 WSI 모든 핵의 정답 기반 평가는 미실시다. 공개 원본 WSI와 주석 ROI를 확보·평가한 성과를 이 두 검증과 바꾸어 쓰지 않는다. 연구자 협력이 어려운 현재 상황에서 지원 전 필수 과제로 추가하지 않는다.
