# 임상 및 전체 WSI 정답 검증: 현재 수행 범위

사용자는 추가 검증 실시를 요청했다. 공개 외부 핵 주석 데이터의 추론·정답 평가는 실행했지만, 아래 두 항목은 그 결과로 대체할 수 없다. 이 문서는 검증 완료 보고서가 아니라 **현재 확보 자료와 실행 조건을 대조한 기록**이다.

| 구분 | 현재 근거 | 상태 |
|---|---|---|
| 외부 핵 분할 데이터 평가 | MoNuSeg 공식 test의 14개 1000×1000 주석 영역, 고정 TNBC 모델·threshold | 별도 [외부 검증 보고서](EXTERNAL_MONUSEG_VALIDATION.md) |
| 기존 WSI 탐색 | 실제 CMU-1-JP2K-33005.svs의 전체 스캔을 다중 해상도로 탐색 | 구현·사용자 확인 완료 |
| 기존 WSI 모델 분석 | 세 개 1024×1024 ROI의 사전 계산 핵 예측 | ROI에 한해 완료, 핵 정답 없음 |
| WSI 전체 핵 정답 기반 성능 | 같은 원본 슬라이드의 전체 핵 정답 및 검토된 평가 범위 필요 | **미실시: 해당 정답 미확보** |
| 임상 검증 | 의도한 임상 사용, 승인된 코호트, 전문가 기준, 기관 협력 및 사전 연구 계획 필요 | **미실시: 해당 자원·승인·기준 미확보** |

## WSI 정답이 필요한 이유

현재 [원본](../artifacts/wsi/source.json)은 OpenSlide의 CC0 테스트 이미지다. 파일 전체 크기는 46,000×32,893이지만 핵의 전체 정답 마스크가 제공된 근거는 없다. 핵 예측을 슬라이드 전체로 확대 실행하더라도 비교할 정답이 생기지는 않는다.

MoNuSeg·NuCLS 등의 영역/세포 주석은 주석이 있는 범위에서 평가할 수 있다. 주석 없는 바깥 영역을 전부 배경으로 간주하면 실제 핵을 거짓 양성으로 잘못 집계한다. CAMELYON의 종양 영역 정답 또한 핵 전경 분할 정답으로 사용할 수 없다. 공개 후보별 출처와 범위는 [자료 조사](EXTERNAL_WSI_DATA_REVIEW.md)에 기록한다. 공개된 모든 데이터에 전체 핵 정답이 없다고 단정하지 않는다.

실제 전체 WSI 검증을 시작하려면 다음 자료가 서로 연결되어야 한다.

1. 원본 WSI ID·SHA·level0 치수·MPP와 사용할 모델/threshold의 동결 기록.
2. 같은 파일의 level0 좌표계에 정렬된 전문가 핵 주석. 전체 평가 영역, 검토되지 않은 영역, 제외 사유를 별도 마스크로 기록.
3. 평가 영역에 모든 핵이 주석됐는지 확인한 근거. 일부만 표본 주석했다면 결과의 이름과 분모는 그 표본/ROI로 제한.
4. 환자·기관 단위 분리와 중복 점검, 관심 조직/염색·스캐너 범위.
5. 전체 추론의 유효 픽셀 커버리지, 타일 누락·겹침·배경 제외·좌표 검증 후, 환자별/슬라이드별 성능과 실패 사례를 산출.

## 임상 검증을 실행하기 전 필요한 결정

연구용 핵 전경 Dice와 진료에서의 유용성은 다른 평가 대상이다. 먼저 목적을 핵 분할 검토 보조로 할지, 종양세포 Ki67 양성률 정량으로 할지 정해야 한다. 현재 H&E 모델은 Ki67 모델이 아니고, IHC 기준선은 제공된 정답 중심점에서 분류하므로 세포 자동 검출을 포함한 임상 Ki67 도구로 사용할 수 없다.

- 협력기관이 허용한 비식별 자료·연구 목적과 접근 조건, 적용되는 IRB 심의/면제 여부를 해당 기관에서 확인한다. 환자 원자료를 공개 저장소에 올리지 않는다.
- 대상 환자·슬라이드 포함/제외 기준, 분리 단위, 독립 기관·시간 코호트, 필요한 표본 수를 임상 전문가·통계 담당자와 정한다. 지금 임의의 표본 수나 임상 허용 오차를 만들어 넣지 않는다.
- 모델 결과와 독립적으로 전문가 기준을 만들고, 복수 평가자 불일치와 판정 절차를 남긴다. 핵 분할 지표와 임상 과업 지표를 각각 사전 지정한다.
- 분석 버전·threshold를 고정하고 제외 사례·결측·실패를 모두 기록한다. 임상 현장 평가라면 실제 사용자·업무 흐름·오류의 영향도 별도로 평가한다.

이 범위 구분은 [DECIDE-AI 원문](https://pmc.ncbi.nlm.nih.gov/articles/PMC9116198/)의 초기 실제 임상 평가와 in-silico 평가의 구분을 참고했다. 지침을 읽고 계획을 작성한 사실을 임상 연구 승인이나 수행으로 기록하지 않는다.

현재 사용자에게 임상 자료·전문가 기준·병원 협력 경로 보유 여부를 질문한 상태다. 제공되기 전까지 임상 검증은 진행 완료로 표시하지 않는다. 외부 데이터에서 보정 모듈의 성능이 낮아진 결과도 검증 범위를 넓힐 때 검토해야 할 실제 실패 근거로 보존한다.
