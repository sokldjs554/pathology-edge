2026-11-13 KST 후속: NuCLS SP.3의153개 원자료와 GDC WSI5개 전체 스트림(약5.08GB, MD5 5/5일치)을 확보·대조했다. RGB/mask 치수가 일치하는15개 시야·4케이스를 실제 평가했고 Dice는0.637160→0.625636이었다. 치수가1px 다른36쌍은 추론 전에 보류했다. [완료 범위·실패 사례·재현 근거](NUCLS_SP3_EVALUATION.md). 아래의 전체 WSI·임상 미실시 상태는 유지한다.

사용자는 공개 WSI와 핵 주석을 활용하는 방향을 제안했고, 임상 연구자 협력은 현재 어렵다고 밝혔다. 따라서 다음 보완은 **동일한 원본 WSI와 연결된 수작업 핵 주석 ROI의 연구 평가**에 집중한다. 임상 검증은 미실시 상태로 명시하고 향후 협력 과제로 둔다. 사용자의 연구자 섭외나 임상 자료 확보를 현재 포트폴리오의 필수 완료 조건으로 요구하지 않는다. 전체 WSI 핵 정답 기반 평가는 아래 표와 같이 미실시이며, ROI 평가로 대체해 완료 처리하지 않는다.

AIDPATH의 공개 안내에서 일부 Ki67 hotspot XML과 기준 양성률을 확인했으나, 현재 데이터 접근에는 회원 가입·관리자 확인이 필요하다. 실제 파일의 확보·대응 관계·전문가 기준의 완전성은 확인하지 못했다. 후보로 기록하되 사용자에게 가입이나 기관 연락을 요구하지 않았다. [공개 데이터 표 추가 대조](PUBLIC_DATA_UPLOAD_REVIEW.md#공개-데이터-확보-가능성-표-추가-대조).

## WSI 정답이 필요한 이유

현재 [원본](../artifacts/wsi/source.json)은 OpenSlide의 CC0 테스트 이미지다. 파일 전체 크기는 46,000×32,893이지만 핵의 전체 정답 마스크가 제공된 근거는 없다. 핵 예측을 슬라이드 전체로 확대 실행하더라도 비교할 정답이 생기지는 않는다.

MoNuSeg·NuCLS 등의 영역/세포 주석은 주석이 있는 범위에서 평가할 수 있다. 주석 없는 바깥 영역을 전부 배경으로 간주하면 실제 핵을 거짓 양성으로 잘못 집계한다. CAMELYON의 종양 영역 정답 또한 핵 전경 분할 정답으로 사용할 수 없다. 공개 후보별 출처와 범위는 [자료 조사](EXTERNAL_WSI_DATA_REVIEW.md)에 기록한다. 공개된 모든 데이터에 전체 핵 정답이 없다고 단정하지 않는다.

실제 전체 WSI 검증을 시작하려면 다음 자료가 서로 연결되어야 한다.

1. 원본 WSI ID·SHA·level0 치수·MPP와 사용할 모델/threshold의 동결 기록.
2. 같은 파일의 level0 좌표계에 정렬된 전문가 핵 주석. 전체 평가 영역, 검토되지 않은 영역, 제외 사유를 별도 마스크로 기록.
3. 평가 영역에 모든 핵이 주석됐는지 확인한 근거. 일부만 표본 주석했다면 결과의 이름과 분모는 그 표본/ROI로 제한.
4. 환자·기관 단위 분리와 중복 점검, 관심 조직/염색·스캐너 범위.
5. 전체 추론의 유효 픽셀 커버리지, 타일 누락·겹침·배경 제외·좌표 검증 후, 환자별/슬라이드별 성능과 실패 사례를 산출.

## 임상 검증을 실행하기 전 필요한 결정

연구용 핵 전경 Dice와 진료에서의 유용성은 다른 평가 대상이다. 먼저 목적을 핵 분할 검토 보조로 할지, 종양세포 Ki67 양성률 정량으로 할지 정해야 한다. 현재 H&E 모델은 Ki67 모델이 아니고, IHC 기준선은 제공된 정답 중심점에서 분류하므로 세포 자동 검출을 포함한 임상 Ki67 도구로 사용할 수 없다.

- 협력기관이 허용한 비식별 자료·연구 목적과 접근 조건, 적용되는 IRB 심의/면제 여부를 해당 기관에서 확인한다. 환자 원자료를 공개 저장소에 올리지 않는다.
- 대상 환자·슬라이드 포함/제외 기준, 분리 단위, 독립 기관·시간 코호트, 필요한 표본 수를 임상 전문가·통계 담당자와 정한다. 지금 임의의 표본 수나 임상 허용 오차를 만들어 넣지 않는다.
- 모델 결과와 독립적으로 전문가 기준을 만들고, 복수 평가자 불일치와 판정 절차를 남긴다. 핵 분할 지표와 임상 과업 지표를 각각 사전 지정한다.
- 분석 버전·threshold를 고정하고 제외 사례·결측·실패를 모두 기록한다. 임상 현장 평가라면 실제 사용자·업무 흐름·오류의 영향도 별도로 평가한다.

이 범위 구분은 [DECIDE-AI 원문](https://pmc.ncbi.nlm.nih.gov/articles/PMC9116198/)의 초기 실제 임상 평가와 in-silico 평가의 구분을 참고했다. 지침을 읽고 계획을 작성한 사실을 임상 연구 승인이나 수행으로 기록하지 않는다.

사용자가 제공한 `PathologyEdge_WSI_자료조사.zip`에는 후보 조사·체크리스트·전달문 Markdown 3개만 있고 원본 WSI, 임상 코호트, 전문가 기준은 없었다. 이후 사용자는 **“현재 보유 자료는 업로드한 조사 문서뿐”**이라고 확인했다. 별도 원자료 경로를 기다리는 상태로 기록하지 않는다. 이 조사 단서를 따라 공개 원자료를 추가 확보해 PanopTILs WSI 연결 ROI 평가와 BCData 외부 분류를 실행했다. 두 작업 모두 한정된 연구 평가이며 요청한 두 검증을 대체하지 않는다.

PanopTILs의 평가 가능 픽셀 평균 Dice는 0.479080→0.435576으로 세 사례 모두 낮아졌고, BCData의 제공 종양 중심 분류 accuracy는31.61%, ROI별 양성률 MAE는24.26%p였다. 이 실패 근거를 보존한다. **전체 WSI의 검토된 핵 정답 범위, 독립 임상 검체·전문가 판독 기준과 협력 경로는 여전히 미확보**다. 두 검증은 현재 자료로 실행할 수 없어 미실시로 유지한다. 향후 해당 원자료와 연구 협력 조건을 확보한 뒤 대응 관계와 평가 계획부터 확인한다. 현재 공개 자료의 부분 영역 평가를 전체 WSI·임상 검증으로 확대해 기록하지 않는다.

후속 요청에 따라 원본 바이트·CSV·mask를 직접 대조하고 새 사례를 평가했다. 위 이전3ROI는 CSV/mask 일치 영역 재평가에서0.481569→0.437627이었다. **새 GDC 원본2case**의 유효 윤곽 영역은0.654638→0.654510, 별도 배경 대조1case도 보존했다. BCData는10장 표본에서 공식test402장으로 확대하고 원주석 중복을 공개한 뒤 진단적으로 평가했다. 이는 새로 완료한 자료 연결·연구 평가이며, 전체 파일을 읽어 해시를 확인했다는 사실을 전체 슬라이드 추론·정답 평가로 바꾸지 않는다.
