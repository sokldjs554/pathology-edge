# 정규화 검출기와 자동 Ki-67 후속 실험

주 모델의 검증 채택 조건 통과는 **0/3 seed**다. 적격 모델이 없어 기존 테스트의 검출 안정성, 자동 분류·양성률, 새 외부 자료의 성능 평가는 **실행하지 않았다**. 세 seed를 모두 추적하며 기존 배포 모델은 유지한다.

적격 모델이 없어 이번 새 모델의 테스트407장·BCData133장·DeepLIIF597장 추론은 실행하지 않았다. 0/3은 테스트 세 번을 실행해 실패했다는 뜻이 아니다. 1번 성능 안정성은 미달이며, 2·3번의 연결 코드와 검사까지 준비했지만 새 모델의 개선을 입증하지 못했다.

## 원인 조사와 고정 설계

학습 자료 4장·84개 정답 중심만 사용한300step 진단에서, 정규화 없는 width4/16의 F1은0.1502/0.5890, GroupNorm이 있는 width4/16은0.9299/1.0000이었다. 이 비교에서는 초기 convolution 가중치를 맞췄다. 이는 소수 학습 표본을 맞추는 능력의 차이이며 검증·외부 성능이나 정규화만의 인과 효과를 입증하지 않는다. 학습 전체의 Gaussian 표적을 다시 해독한10750/10751개 중심과64개 회전·반전 좌표 검사를 확인했다.

- 새 주 모델은 결과를 보기 전에 GroupNorm width16으로 고정했다. GroupNorm width4는 별도 비교군이며 주 모델을 대신 선택하지 않는다.
- 두 새 모델 모두 처음부터24epoch, seed20261117/18/19, Adam0.001, batch8로 학습했다. train696장/15케이스, validation227장/4케이스를 유지했다.
- A는 기존 width4/7537파라미터/16epoch 모델이다. 새 모델과는 구조·정규화·학습 기간이 함께 다르므로 단일 요인의 효과로 해석하지 않는다.
- Gaussian sigma2/radius6, center focal loss, 회전·반전·RGB 배율 증강을 유지했다. 임계값12개×거리3개×24epoch×6모델, 총5184개 설정을 저장했다.
- 채택 기준: A보다 FP·FN 각각 악화 없음(하나는 감소), 케이스 평균 재현율≥0.479795, 양성 종양 위치 재현율≥270/483, 음성 종양 위치 재현율≥439/1292, 모든 케이스 재현율≥A의90%. 결과를 보고 기준을 완화하지 않았다.
- 모든6모델 선택을 잠근 뒤 적격 주 모델에만 후속 평가를 허용한다. classifier 선택도 validation에서만 하고 테스트·외부 전에 잠근다.

## 자동 Ki-67 전체 흐름

기존 LR와 CNN3개 분류기는 재학습하지 않는다. 실제 검출된 새 중심에서 RGB 영상을 읽어 네 세포 클래스를 예측한다. 정답 중심을 추론 입력으로 제공하지 않는다. A의 비교 분류기는 detector seed17/18/19에 CNNseed13/14/15를 미리 대응했다. B는 validation에서 전체4케이스의 계산 가능한 분모를 유지하면서4클래스 end-to-end macro-F1이 상승하고 케이스 양성률 MAE가 악화하지 않는 분류기를 선택한다. 해당 분류기가 없으면 기존 대응 분류기를 유지하고 목표 미달로 기록한다. 모든 동일 분류기 A/B 비교도 남겨 검출기와 분류기 변경 효과를 구분한다.

이번에는 적격 검출기가 없어 새 중심에서의 후속 분류·양성률 비교도 실행하지 않았다. 구현·합성 검사 통과와 실제 모델 성능 입증은 구분한다.

## 새 외부 자료와 해석 범위

[DeepLIIF 공식 testing 자료](https://zenodo.org/records/4751737), Ghahremani et al., [논문](https://doi.org/10.1038/s42256-022-00471-x), CC BY4.0을 조사했다. 원본 testing ZIP의598개PNG 중 형식 확인에 사용한1장을 사전에 제외하고 나머지597개 이름을 고정했다. 형식 예제의49개 중심/양음성 라벨은 독립 OpenCV 추출과 일치했다. 실제 추론이 없을 때 이49개 대조를 모델 성능 평가로 기록하지 않는다.

첫512px 타일이 IHC, 마지막512px 타일이 제공된 분할 정답이다. 초록 경계는 중심 추출에서 제외하고 빨강/파랑 내부의8연결 성분에서 좌표와 양성·음성을 추출한다. 면적4px 이하 제외, 경계에 걸친 성분과 혼합 성분의 수를 기록한다. 동률·예상 밖 색상/크기·잘못된 HTTP 범위·CRC·중복 영상은 조용히 제외하지 않고 평가를 중단한다. 전체ZIP MD5를 검증한 것은 아니며 개별 압축 항목의CRC·SHA256을 확인하는 방식이다.

외부 양성률은 **전체 주석 세포의 양성 비율**이며 종양세포 전용 Ki-67 지수가 아니다. 종양/비종양 예측을 모두 포함해 양성·음성으로 묶는다. 분할 마스크에서 유도한 중심이지 원래 전문가 점 주석이나 공식 DeepLIIF 평가 프로토콜의 재현이 아니다. 주 매칭 반경6px, 보조12px는 사전에 고정했다. 물리적 MPP와 환자·슬라이드 독립성은 확인되지 않았으며 동일 이미지 해시 검사만으로 부분 겹침이나 동일 환자를 배제할 수 없다.

양성률 MAE는 GT와 A가 모두 계산 가능한 동일 이미지 집합에서 A/B를 비교한다. B가 이 중 한 이미지라도 분모를 잃으면 해당 조건은 실패이며 그 이미지를 평균에서 빼지 않는다. 전체·A·B·공통 유효 이미지ID와 B의 추가 계산 가능 이미지를 따로 기록한다. 빈 비교 집합은 성공이 아니다. 검출·분류 지표는 전체597장에 적용한다.

이번 새 모델의 DeepLIIF 추론은 **0장**이다. 미채택 모델의 외부 개선을 주장하지 않으며, 자료 연결·형식 검증과 모델 성능 검증을 구분한다.

BCData133장은 이미 사용한 자료의 재평가이며 새 외부 검증이 아니다. 폐·방광 IHC 결과는 H&E 보정 모듈의 MoNuSeg/NuCLS 음성 결과를 해결하거나 유방암 종양세포 분석의 임상 정확도를 입증하지 않는다. 임상 검증과 전체WSI 정답 기반 검증은 이번 범위에 포함되지 않는다.

## 재현 경계

저장소 루트의 준비된 Python 환경에서 `python -m pytest -q tests/test_ki67_normalized.py tests/test_ki67_normalized_pipeline.py tests/test_ki67_deepliif.py tests/test_audit_ki67_normalized.py`로 새 코드 검사를 실행한다. 전체 검사 명령은 `python -m pytest -q`다. 이는 학습 실행 명령이 아니다.

새 학습은 `scripts/run_ki67_normalized.py`의 prepare→width4/16×seed3 worker→seal 순서다. 그 뒤 `scripts/run_ki67_normalized_pipeline.py`의 select→internal→external을 실행한다. 새 외부 자료는 `scripts/run_ki67_deepliif.py`와 별도 감사 스크립트를 사용한다. 각 명령의 `--help`에서 필수 경로를 확인한다. 기존 원자료와 이전 모델·실행 폴더가 필요하고 출력은 새 폴더여야 한다. 공개 ZIP만으로 원자료가 모두 설치되지는 않는다.

원본 실행의 절대경로나 소스가 바뀌면 해시 검사가 실패한다. 과거 기록의 해시를 덮어쓰지 말고 고정 소스·원본 입력을 연결하거나 별도 새 실행으로 기록한다. BCData 원영상·HDF5·개별 외부 세포 좌표는 공개 ZIP에서 제외하고 집계·해시 증거만 제공한다.
