# 자동 Ki-67 외부 전이 평가 사전 규약

2026-11-13, Asia/Seoul. 현재 학습 중인 모델의 결과를 보기 전에 범위와 평가 규칙을 고정했다. 실제 완료 여부와 수치는 `AUTO_KI67_EXPERIMENT.md` 및 실행 산출물로 확인한다.

## 데이터와 독립성

- [BCData 공식 안내](https://sites.google.com/view/bcdataset)의 validation 133장 전체를 선택했다. 공식 train 803장 / validation 133장 / test 402장 중 **기존 프로젝트에서 평가했던 test 402장을 재사용하지 않는다**.
- 여기서 validation은 BCData 배포본의 이름이다. 이번 프로젝트에서는 **학습·설정 선택에 사용하지 않는 외부 평가 집합**으로 사용한다.
- 공식 페이지는 positive/negative **tumor cells**의 HDF5 중심 좌표를 명시한다. 종양 외 세포의 네 클래스 정답은 없다.
- 원본 640×640 RGB를 변형 없이 사용한다. MPP와 환자·슬라이드 대응표를 확보하지 못했으므로 물리적 해상도 일치나 환자 단위 독립성을 주장하지 않는다.
- Patherea 1,330장, 기존 BCData test 402장과 전체 영상 픽셀 해시를 대조하고 외부 집합 내부 중복도 검사한다. 전체 영상 해시는 부분 크롭 중복이나 같은 환자의 다른 영상을 배제하지 못한다.
- [Patherea 논문](https://arxiv.org/html/2412.16425v2)은 BCData가 현미경 카메라 영상임을 설명한다. WSI 전체 분석으로 표현하지 않는다.

## 모델 및 평가

1. Patherea train 15케이스로 학습하고 validation 4케이스에서 선택한 검출 설정·모델 3개를 고정한다. 기존 색상 통계 로지스틱 회귀와 같은 검출 위치를 사용한다.
2. BCData에서 모델 학습, threshold 조정, seed 선택, 좋은 사례만 선택하는 작업을 하지 않는다.
3. 입력은 RGB 영상뿐이다. 검출 이후 예측 클래스 0·1(종양)만 모아 정답 종양 중심점과 대조한다. 예측 비종양 세포를 정답 비종양 세포로 간주하지 않는다.
4. 클래스와 무관하게 반경 6 **원본 픽셀** 안에서 최대 대응 수를 먼저 구하고, 같은 대응 수 중 거리 합을 최소화한다. 일대일 대응이며, 클래스 오분류는 해당 클래스의 FP·FN에 반영한다.
5. 종양 검출 precision/recall/F1, 양성·음성 종양 두 클래스의 end-to-end macro-F1, 이미지별 양성률 MAE(%p), 유효 분모 이미지 수, 세포 수 오차를 모두 공개한다. 비종양 민감도나 4-class 전체 정확도는 계산하지 않는다.
6. 동일 클래스의 완전히 같은 좌표는 한 점으로 정규화하고 제거 수를 기록한다. 서로 다른 클래스가 같은 좌표에 있거나, 범위 밖·소수·비유한 좌표면 실행을 중단한다. 모델 결과에 따라 데이터를 제외하지 않는다.
7. 종양 세포 예측 수가 0이면 양성률은 `null`이다. 오차 평균에서 제외된 수를 반드시 표시한다.

이 평가는 제공된 종양 주석에 대한 이미지 단위 벤치마크다. 미주석 세포의 존재·주석 완전성을 독립적으로 전문가가 재검수하지 않았으며, 임상 정확도·환자 수준 일반화·공식 논문 수치 재현으로 해석하지 않는다. IHC 비교 결과는 기존 H&E 보정 모듈의 MoNuSeg/NuCLS 성능 하락을 뒤집는 근거가 아니다.

## 사용과 배포

원본 논문의 비상업 연구 용도 범위를 따른다. 원영상·HDF5·개별 세포 좌표는 공개 산출물에 재배포하지 않는다. 공개 묶음에는 출처, 선택 목록, CRC·SHA, 모델과 코드, 집계 결과 및 재실행 방법만 넣는다. byte-range 응답의 크기·ZIP 헤더·CRC를 검사하며, 전체 ZIP을 받았거나 전체 ZIP SHA를 검증했다고 기록하지 않는다.
