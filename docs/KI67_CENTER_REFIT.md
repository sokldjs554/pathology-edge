# 검출기 추가 학습 — 고정 3seed 후속 실험

검증 선택 조건 통과는 **0/3**이며, 적격 모델이 없어 **테스트·외부 새 추론은 실행하지 않았다.** 모델 구조와 기존 선택 기준을 유지하고 각 모델을 24epoch 추가 학습했다. 이 수치는 새로운 외부·임상·전체 WSI 검증을 뜻하지 않는다. 기존 배포 모델은 유지한다.

## 왜 이 실험을 했나

기존3검출기 모두 최고 검증 F1이 학습 마지막16번째 epoch에서 나왔고 손실이 감소 중이었다. 기존 모델의 학습 자료 case-F1도0.3879/0.3692/0.3594로 낮았다. 후보를 더 모으고 제거하는 후처리만 조정하기 전에, 같은 검출기의 학습 여지를 시험했다. 이 관찰은 추가 학습의 성공 보장이 아니며 다른 원인을 배제하지 않는다.

## 고정 조건과 변경 범위

- 기존 CenterDetector width4/7537파라미터와 세 초기 가중치를 유지. seed20261117/18/19를 짝지었다.
- train696장/15케이스,validation227장/4케이스. Gaussian sigma2·center focal loss·회전/반전/RGB augmentation은 유지했다.
- 기존16epoch 가중치에서 **새 Adam(.001)**,batch8,2threads로24epoch 추가 학습. 기존 optimizer/RNG가 없어 연속40epoch 학습을 재현한 것은 아니다. 마지막 optimizer·torch/NumPy RNG 상태도 보관했다.
- 임계값(.01,.02,.03,.05,.075,.1,.15,.2,.3,.5,.7,.9),거리4/6/8px를 고정했다. 원래4개 임계값보다 범위가 넓어졌으므로 추가 학습만의 효과라고 단정하지 않는다.
- **epoch0**에서 새 범위로 기존 가중치를 평가한 대조를 남겼으며 채택 대상에서는 제외했다. 총2700조합 중108개는epoch0 대조,2592개는추가 학습 조합이다.
- 기존 A설정의 epoch0 case-F1/recall이 이전 실험과 일치하는지 학습 전에 확인했다. 테스트·외부 자료는 세 seed 선택을 모두 잠근 뒤 적격 모델에만 허용했다.

## 검증 결과

이번 B는 세 seed 모두 최고 검증 F1의 **진단용 모델**이며, 채택 모델이 아니다. FP/FN은227장 합계, F1/재현율은4케이스 평균이다. 모든 결과를 포함하고 가장 좋은 seed만 선택하지 않았다.

선택 조건은 A대비 FP·FN 각각 악화 없음(하나는 감소), 기존 LoG의 케이스 평균 재현율0.4798·종양+0.5590·종양−0.3398 이상, 모든 케이스 재현율이 A의90% 이상이다. 점수/조건을 보고 사후 완화하지 않았다. 전체 F1이 높아졌다는 이유만으로 이 조건의 실패를 숨기지 않는다. `failure-analysis.json`은 사후 원인 검토이며 선택 규칙을 대체하지 않는다.

**적격 모델이 없어 테스트407장·BCData133장 새 추론은 실행하지 않았다.** test_passes0/3은 테스트를 세 번 실행해 실패했다는 뜻이 아니라, 자격 미달인 세 seed를 성공 증거의 분모에 유지한 것이다. 추가 학습만으로 모든 재현율·FP/FN 조건을 해결했다고 말할 수 없다.

## 남은 실패 원인

최고 F1 모델은 세 seed 모두 FN을 줄였지만 FP가 증가했다. FP·FN만 함께 줄어든 설정도 2/48/40개 존재했으나, 전체 선택 조건은 모두 미충족이었다. 각 seed의 동시 감소 설정 중 최고 F1 설정에서도 케이스 평균 재현율은 0.3536/0.3604/0.3625로 하한 0.4798보다 낮았고 두 종양 클래스 재현율 하한도 미달했다. 단순히 더 엄격한 점수 기준을 쓰는 것만으로 해결되지 않는 검출 수와 오류의 절충이 남는다.

사후 학습 자료 진단에서 원래 A의 임계값·거리를 유지한 B의 학습 자료 case-F1은 0.4000/0.4172/0.4234였다. 추가 학습 후에도 학습 자료 자체의 검출 정확도가 높지 않다는 관찰이다. 이것만으로 원인이 작은 모델의 표현력인지, 중심 표적이나 데이터·주석의 문제인지 확정할 수는 없다. 이후에는 이 원인을 분리하는 새로운 가설과 고정 평가 계획이 필요하며, 이번 결과를 보고 같은 검증 자료의 임계값을 계속 조절해 성공으로 보고하지 않는다.

## 코드·실행 증거

학습 소스 `d28c8127675cf92e08aa46698eb3e4908518a2f1`. 전체 원본은 [실험 자료](../artifacts/experiments/ki67-center-refit-20261114/)에 보존한다. 프로토콜·입력·소스·선택·점수/좌표·가중치 해시를 잠갔다. 각 epoch의 원 피크와 점수·영상별 offset, 모든 선택 조합,3개 진단 가중치와 최종 재개 상태를 기록했다. 새 모델을 선택한 seed만 채택 가중치가 별도로 존재한다.

- 독립 감사: **2700조합**, 원래·선택/진단 체크포인트의 검증 영상 **1362건** 재추론 일치.
- 테스트/외부 A/B 파이프라인 재추론 대조 **0건**. 외부 정답은 앞서 원주석과 대조한 해시 고정 canonical points를 기준으로 하며 이번에 HDF5 주석 감사를 다시 했다는 뜻은 아니다.
- 코드53a6c08의 [깨끗한 CI](https://github.com/sokldjs554/pathology-edge/actions/runs/43578532938)에서668개 검사,저장 Dice42개·평균6개와기존 데모 검사를 통과했다. 로컬 전체 검사에는 디스크 공간 제약이 있어 통과로 기록하지 않는다. 최종 게시본 검사는 verification.json과CI로 구분한다.
- 최종 상태와 사용자 수행 범위는 `verification.json`·`review/browser.json`을 기준으로 한다. 이전 U104는 이전 위치 보정 화살표 전환·표시 수치 유지 확인까지만 완료다. 이번 학습·검산·새 화면은 사용자 직접 수행으로 추가하지 않는다.

## 실제 결과 화면

[확인 순서](STEP_91.md). A는 원래 검출기·원래 설정, B는 새 선택/진단 모델이다. 두 화면은 같은224×224 원영상을 사용한다. 후보 중심은 핵 윤곽이 아니다. 두 검출기가 독립적으로 중심을 예측하므로 후보 간 이동 화살표는 없다.

각 seed에서 `(FP+FN) B−A`가 최소·최대인 검증 이미지를 선택한6개 예시다. 전체 성능의 대표 표본이 아니다. epoch0 대조 표와 진단용 표시를 함께 확인한다. 이번 자료는 저장 결과 열람이며 화면에서 새 추론하지 않는다.

Chromium에서 6개 예제의 실제 저장 수치·동일 원영상·표시 전환·이전/다음 이동·epoch0 대조 표를 확인했다. 데스크톱 1440px와 작은 화면 390px에서 조작을 확인했고 본문 가로 넘침은 없었다. 작은 화면의 넓은 표는 표 내부를 가로로 스크롤한다. [데스크톱 캡처](../artifacts/experiments/ki67-center-refit-20261114/review/desktop.png) · [작은 화면 캡처](../artifacts/experiments/ki67-center-refit-20261114/review/mobile.png). 이 검사는 사용자 직접 확인과 구분한다. 외부 자원 요청 없는 로컬 HTTP 열기도 통과했다. 관리형 Chromium이 `file://`을 차단하므로 직접 파일 열기 검사는 미완료이며, STEP91에 로컬 HTTP 대안을 안내한다.

## 한계와 재현 범위

반복 사용한 검증4케이스에서 설정과 epoch를 선택했다. 독립적인 새 기관·환자·슬라이드 검증이 아니다. 공개 점 주석은 모든 비주석 위치를 전문가가 비세포로 판정한 자료와 다르다. 제한된 모델 표현력·표적·염색 차이·주석 불확실성의 영향을 이번 한 실험으로 분리하지 않는다. 동일 구조라도 임계값과 검출 후보 수가 달라져 전체 파이프라인 시간도 달라질 수 있으며, 기록한 학습·검증·저장 시간은 추론 속도 벤치마크가 아니다.

저장소 루트에서 코드 회귀를 확인한다.

```bash
python -m pytest -q tests/test_ki67_center_refit.py tests/test_ki67_center_refit_audit.py tests/test_ki67_centers.py
```

다음은 기존 원자료·이전 실행 폴더가 연결된 환경의 명령이다. 공개 ZIP만으로 모든 데이터가 설치되는 명령은 아니다. 출력은 존재하지 않는 새 폴더를 사용한다.

```bash
python scripts/run_ki67_center_refit.py prepare --prior work/learned-centers-leaky-run-20261113 --output work/new-refit
python scripts/run_ki67_center_refit.py fit --output work/new-refit
python scripts/run_ki67_center_refit.py internal --output work/new-refit
python scripts/run_ki67_center_refit.py external --output work/new-refit
python scripts/audit_ki67_center_refit.py --output work/new-refit
python scripts/export_ki67_center_refit_review.py --output work/new-refit --review work/new-refit-review
```

원본 protocol의 절대경로나 소스가 바뀌면 해시 감사가 실패한다. 과거 실행을 재현하려면 해당 frozen source와 원본 입력을 연결해야 하며 해시를 임의로 덮어쓰지 않는다. BCData 원영상·HDF5·개별 외부 세포 좌표는 기존 배포 범위에 따라 공개 ZIP에서 제외한다.
