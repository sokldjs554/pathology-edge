# 16단계: 달라진 픽셀 강조 끄기·켜기

상태: **사용자 강조 표시 전환 확인 대기**. 15단계에서 사용자가 두 손가락 스크롤이 잘 작동한다고 답했습니다. 현재 확인한10_1 확대 화면에서는 클릭 드래그와 두 손가락 스크롤 모두 사용자 정상 보고를 받았습니다.

## 직접 할 조작 하나

같은 화면에서 **현재 예제 경계**를 눌러 영역을 다시 맞춘 뒤, 오른쪽 **선택 경계**의 **달라진 픽셀 강조** 체크를 껐다가 다시 켭니다. 상단의 ‘분할’ 체크와 구분합니다.

예상 결과는 선명한 **분홍·청록 변경 픽셀 표시**가 사라졌다가 다시 나타나는 것입니다. 원래 조직 영상의 분홍색이나 기존 분할 오버레이 색까지 모두 없어지는 것은 아닙니다. 흰 영역 상자와 선택 경계 Dice0.546→0.433은 유지됩니다.

**변경 픽셀 강조가 꺼졌다가 다시 나타나는지** 알려 주세요. 토글이 안 보이면 상단 **결과 패널**을 열고 ‘선택 경계’ 부분을 확인합니다. 이번에는 추가 예제나 다른 기능까지 검사할 필요가 없습니다.

이 표시는 같은 경계 영역에서 A→B로 예측이 바뀐 픽셀 중 청록은 정답과 일치하게, 분홍은 불일치하게 바뀐 부분입니다. 새 추론을 실행하는 기능이 아닙니다.

## Codex 확인 범위

`dist/review-ui.js`의 체크 상태에 따른 강조 레이어 그리기와 `web-tests/review.spec.js`의 기존 픽셀 검사 정의를 확인했습니다. 이번 턴에는 새 브라우저 검사를 실행하지 않았으며, 사용자 토글 결과는 위 답변을 받은 뒤 기록합니다.
