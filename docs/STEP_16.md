# 16단계: 달라진 픽셀 강조 끄기·켜기

상태: **2026-11-09 사용자 강조 표시 전환 확인 완료**. 강조를 껐다 켰을 때 분홍·청록 표시가 사라졌다가 다시 나타나는 동작까지 확인했는지 재확인했고, 사용자가 “응 정확히 확인했어”라고 답했습니다. [확인 원문·범위](../artifacts/learning/step16-review.json).

사용자는 ‘선택 경계’ 위치를 찾는 데 안내를 받았습니다. 처음 안내에서 빠졌던 **이미지 탭**과 **현재 예제 경계 버튼**의 위치를 아래에 보완했습니다. 스스로 위치를 찾았다고 기록하지 않습니다. 아래는 완료한 조작의 참고이며, 다음은 [17단계 좋아진 경계 확인](STEP_17.md) 하나입니다.

## 직접 할 조작 하나

같은 `10_1` 화면에서 영상 위 도구 모음 오른쪽의 **현재 예제 경계**를 누릅니다. 이 버튼은 오른쪽 결과 패널 안에 있지 않습니다. 이어 오른쪽 **검토 결과 → 이미지 탭**을 엽니다. ‘이미지’는 `이미지 | 선택 후보 | 실험` 중 맨 왼쪽 탭입니다.

`TNBC 10_1` 소개 아래, **평가 영역 위**에 나타난 **선택 경계**에서 **달라진 픽셀 강조** 체크를 껐다가 다시 켭니다. 상단의 ‘분할’ 체크와 구분합니다.

예상 결과는 선명한 **분홍·청록 변경 픽셀 표시**가 사라졌다가 다시 나타나는 것입니다. 원래 조직 영상의 분홍색이나 기존 분할 오버레이 색까지 모두 없어지는 것은 아닙니다. 흰 영역 상자와 선택 경계 Dice0.546→0.433은 유지됩니다.

변경 픽셀 강조가 꺼졌다가 다시 나타난다는 사용자 확인을 받았습니다. 패널이 닫혔다면 상단 **결과 패널**을 엽니다. 이미지 탭에 ‘평가 영역’만 보이면 **현재 예제 경계**를 다시 눌러 사례를 활성화합니다.

이 표시는 같은 경계 영역에서 A→B로 예측이 바뀐 픽셀 중 청록은 정답과 일치하게, 분홍은 불일치하게 바뀐 부분입니다. 새 추론을 실행하는 기능이 아닙니다.

## Codex 확인 범위

`dist/review-ui.js`의 체크 상태에 따른 강조 레이어 그리기와 `web-tests/review.spec.js`의 기존 픽셀 검사 정의를 준비 당시 확인했습니다. 이번에는 사용자 확인을 기록하고 `dist/index.html`의 탭·섹션 위치에 맞춰 안내를 보완했습니다. 새 브라우저 검사를 실행하지 않았습니다. 점수·흰 상자의 유지, 색의 의미 해석, 다른 예제 동작까지 사용자가 확인한 것으로 확대하지 않습니다.
