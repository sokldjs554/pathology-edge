# 23단계: WSI R1의 차이가 큰 경계 열기

상태: **사용자 화면 확인 대기**. 22단계에서 R1 이동과 양쪽 같은 조직 위치의 사용자 보고를 받았습니다. 이번에는 저장된 경계 사례 하나를 엽니다. 새 코드·설치·추론은 없습니다.

## 직접 할 조작 하나

현재 R1 화면의 영상 위 도구 모음에서 **차이가 큰 경계**를 누릅니다. 화면을 닫았다면 [실제 WSI 탐색](https://pathology-edge-lab.ykh13571.chatgpt.site/wsi.html)에서 왼쪽 **저장된 분석 ROI → R1**을 먼저 선택합니다.

양쪽 영상이 동일 경계 위치로 이동·확대되고 흰 상자가 나타나야 합니다. 오른쪽 **결과·출처 → 선택한 경계의 예측 차이**에는 **B 추가347px · B 제거123px · 경계띠 내 변화413px**가 표시됩니다. 패널이 닫혀 있다면 상단 **결과·출처**를 누르고 패널 안을 아래로 스크롤합니다.

**양쪽 흰 상자가 같은 위치를 가리키고, B 추가347px·제거123px가 보이는지** 알려 주세요. 다르게 보이면 선택 ROI와 실제 표시 수치를 보내 주세요. 다른 ROI나 후보 추적까지 한꺼번에 확인할 필요는 없습니다.

## 수치와 색의 범위

A는 무겹침, B는 겹침 방식입니다. 선택된64×64 상자 전체에서 A의 배경 예측이 B의 핵 예측으로 바뀐 픽셀이347개, 반대로 핵 예측에서 배경 예측으로 바뀐 픽셀이123개입니다. 총470개 변화 중 고정 경계 띠에 속하는 변화는413개입니다.413은347+123과 같은 범위를 세는 값이 아닙니다.

주황은 B에서 추가된 핵 예측, 파랑은 B에서 사라진 핵 예측입니다. 이 WSI에는 핵 정답이 없으므로 색은 정답 여부나 개선·악화를 뜻하지 않습니다. 앞서 TNBC에서 본 정답 대조 강조와 구분합니다.

사례는 `R1-boundary-1`, 원본 level-0 좌표는 `[6496, 21232, 6560, 21296]`, 중심은 `(6528, 21264)`입니다. ROI 내 좌표는 `[608, 624, 672, 688]`입니다. 경계 변화 수를 기준으로 사후 선택한 영역이며 정확도가 가장 좋아진 곳이라는 의미는 아닙니다.

## Codex 확인 범위

저장된 R1의 두 이진 마스크에서 추가·제거·경계띠 변화 수를 재계산하고 사례 JSON과 대조했습니다. 차이 PNG의 해시와 알파가0보다 큰 픽셀이 두 마스크의 XOR 영역과 일치하는지, ROI→원본 좌표가 맞는지도 확인했습니다. `jumpDifference`의 표시·시야 연결과 기존 WSI 테스트 정의를 읽었습니다. 이번에 새 브라우저 검사·모델 추론·정확도 측정은 실행하지 않았습니다.
