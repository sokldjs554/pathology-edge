| 데이터 분리 감사 확장 | exact hash와 환자/슬라이드/near-duplicate 검사의 차이 이해 | 추가 구현은 이후 후보. 현재는 배정하지 않음 |

후속 과제를 실제 배정할 때만 파일·함수, 입력/출력 계약, 제공 코드와 직접 작성 범위,
예제·테스트를 새 문서로 제공합니다. 이미 Codex가 작성한 코드를 사용자 기여로 소급하지 않습니다.

Codex는 사용자 좌표 함수와 무관한 데이터 조사, 원래 PNG 좌표계의 모델 학습·평가,
C++ 처리, 결과 시각화, 배포를 진행했습니다. 사용자 함수가 미완료라는 이유로 이 작업을 막지 않았습니다.
사용자 함수 검토와 WSI 원본 확보는 완료했습니다. 기존 native ROI 경로에 일반 배율 어댑터를 연결하는 작업은 별도로 남아 있으며 이번 검토에서 변경하지 않았습니다.
