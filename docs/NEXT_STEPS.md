# 한 단계씩 진행하는 작업 분리

**[STEP_01.md](STEP_01.md)의 코드·12개 테스트 실행 보고·좌표계 설명 확인을 마쳤습니다.**
2단계 반례 해석도 확인했습니다. 현재 활성 작업은 [STEP_02.md](STEP_02.md)의 테스트 함수 하나를 직접 작성·실행하는 것입니다.
병합 정책 변경과 나머지 후보는 이 코드와 실행 결과를 검토한 뒤 배정합니다.

| 순서 후보 | 직접 해 보면 유익한 이유 | 지금의 상태 |
|---|---|---|
| 좌표 변환 | 모델·패치·원본 좌표의 단위를 명확히 이해 | 사용자 코드·12개 테스트 실행 보고·좌표계 설명 확인 완료 |
| 경계 중복 판정의 반례 작성 | 서로 다른 핵의 잘못된 병합과 같은 핵의 중복 잔존을 구별 | 2단계: 합성 반례 해석 완료, 사용자 테스트 본문 작성·실행 대기. NMS와 fixture는 Codex 제공 |
| 작은 배열로 지표 독립 계산 | Dice와 객체 F1의 단위·분모가 다름을 이해 | 현재 metrics는 Codex 구현. 이후 독립 검산 후보 |
| 데이터 분리 감사 확장 | exact hash와 환자/슬라이드/near-duplicate 검사의 차이 이해 | 현재 group/hash 검사는 Codex 구현. 이후 감사 확장 후보 |

후속 과제를 실제 배정할 때만 파일·함수, 입력/출력 계약, 제공 코드와 직접 작성 범위,
예제·테스트를 새 문서로 제공합니다. 이미 Codex가 작성한 코드를 사용자 기여로 소급하지 않습니다.

Codex는 사용자 좌표 함수와 무관한 데이터 조사, 원래 PNG 좌표계의 모델 학습·평가,
C++ 처리, 결과 시각화, 배포를 진행했습니다. 사용자 함수가 미완료라는 이유로 이 작업을 막지 않았습니다.
사용자 함수 검토와 WSI 원본 확보는 완료했습니다. 기존 native ROI 경로에 일반 배율 어댑터를 연결하는 작업은 별도로 남아 있으며 이번 검토에서 변경하지 않았습니다.
