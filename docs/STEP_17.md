# 17단계: 좋아진 경계 사례 열기

상태: **사용자 확인 대기**. 16단계의 강조 표시 끄기·켜기는 사용자 확인을 받았습니다. 이번에는 실제 개선 사례 하나를 엽니다. 코드 작성·설치·터미널 실행은 없습니다.

## 직접 할 조작 하나

[데모](https://pathology-edge-lab.ykh13571.chatgpt.site/)의 영상 위 목적 설명 바로 아래에 있는 **좋아진 경계 보기**를 누릅니다. ‘현재 예제 경계’와 다른 버튼입니다.

예상 결과는 `TNBC 11_1`로 바뀌고 양쪽 영상이 같은 흰 상자 영역으로 이동·확대되는 것입니다. 오른쪽 **검토 결과 → 이미지 탭 → 선택 경계**에서 **국소 경계 Dice 0.626 → 0.854**가 표시됩니다. 패널이 닫혔다면 상단 **결과 패널**을 연 뒤, `이미지 | 선택 후보 | 실험` 중 맨 왼쪽을 선택합니다.

**11_1로 바뀌었는지, 국소 점수가 얼마인지, 양쪽이 같은 위치를 보여 주는지** 알려 주세요. 다르게 보이면 화면의 이미지 번호와 점수를 그대로 보내면 됩니다. 다른 버튼까지 한꺼번에 확인할 필요는 없습니다.

## 점수의 범위와 근거

A는 무겹침, B는 겹침 처리 후 병합입니다. 이 점수는 원본 PNG의 `x 96–160, y 240–304`(끝 좌표 제외)인 64×64 상자와 고정 경계 띠가 겹치는 1,792개 픽셀 기준입니다. 이미지 전체 점수나 7장 평균과 구분합니다.

Codex가 저장된 예측·정답 PNG를 읽어 Dice `0.626153846… → 0.853860881…`, 정답 일치로 변경된 268px와 불일치로 변경된 11px, 강조 좌표를 다시 대조했습니다. 이는 다음 화면의 예상값이며 아직 사용자 확인 결과는 아닙니다. 새 추론이나 이번 단계의 브라우저 검사는 실행하지 않았습니다.

이 사례는 테스트 정답을 사용해 사후 선택한 예시입니다. 이미지별 개선 후보 중 순개선 픽셀 수가 큰 영역을 고르고, 추천 사례에는 해당 이미지의 전체·경계 Dice 방향도 같은 조건을 적용합니다. 이 사례 하나가 평균 성능이나 일반적인 개선을 증명하지 않습니다.
