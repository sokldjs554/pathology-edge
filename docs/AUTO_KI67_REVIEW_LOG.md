# 최종 독립 검토 및 판단

범위: `ff486a3..8406de8`, 읽기 전용 독립 검토. Critical 0, Important 1, Minor 0.

중요 발견: NaN CNN 파라미터 또는 overflow 출력이 `argmax`로 유효 클래스처럼 바뀔 수 있었다. 현재 소스는 비유한 가중치(빈 후보 포함)와 잘못된 확률 출력을 거부한다. 네 회귀 테스트의 RED→GREEN 및 관련50개 테스트 통과를 확인했다. 독립 검토자는 실제 체크포인트가 모두 유한하고 source/input/model SHA가 맞으며, 내부1,628+외부532 재집계가 일치함을 다시 확인했다. 역사적 실험 snapshot과 결과는 보존한다.

검토자가 코드 결함으로 판단하지 않은 항목: 낮은 검출 정확도, 외부 CNN 성능 저하, 임상 자료 부재. 공개한 연구 결과와 한계로 유지한다. 해당 결과를 성공처럼 표현한다면 보고 오류가 되므로 비교표와 결론에 실패를 명시했다.

구현 중 판단과 영향:

- 디스크 여유가 적어 기존 환경과 sparse worktree를 사용하고 다운로드 캐시만 정리했다. 전체 테스트는 GitHub의 새 환경에서 실행했다. 이 때문에 현재 로컬 전체 체크아웃 실행까지 검증한 것은 아니다.
- 먼저 전통 검출기+기존 분류기를 연결하고 같은 위치에서 CNN 세 seed를 비교했다. 위치 찾기와 분류의 영향을 분리하지만, 학습 기반 검출기 개선 실험은 포함하지 않는다.
- BCData 공식 validation133을 외부 이미지 수준 평가에 사용했다. 환자/슬라이드 ID와 MPP를 확인하지 못해 환자 독립성·물리적 해상도 일치를 주장할 수 없다. 비종양 정답이 없어 종양 두 클래스만 평가했다.
- 과다 검출 및 외부 악화 결과를 모두 남기고 사전 규약 뒤에 테스트를 이용한 재튜닝을 하지 않았다. 초기 자동 기준선은 실용적 검사 정확도에 미치지 못한다.
- 관리형 Chromium의 file:// 정책 때문에 localhost HTTP로 독립 HTML을 검사했다. 사용자의 브라우저·파일 정책은 본인 응답 전에는 확인 완료가 아니다.

독립 코드 검토 당시 이번 자동 분석의 사용자 검토는 대기 상태였고 기록은 U86까지였다. 이후 첫 사례 화면·모델 전환 요청에 “확인했어”라는 응답을 받아 U87을 추가했다. 그 다음 내부 양성률 오차와 macro-F1의 서로 다른 변화에 대한 올바른 해석을 U88로, 제공된 첫 사례 대응 수에서 FP104·FN4를 계산한 답변을 U89로 추가했다. U90에는 분류기 교체와 검출 후보 제거를 구분한 구조 해석을 기록했다. U91에는 결과를 보고 기준을 조정한 외부 자료의 재평가와 미노출 검증을 구분한 원칙 해석을 추가했다. 사용자 직접 구현·실행·독립 수치 재계산·전체 사례나 외부 결과 검토 완료로 확대하지 않는다. 기존 데모를 자동 분석이 가능한 것처럼 바꾸거나 배포하지 않았다.
