## 실제 사용자 결과

**validation10장·2케이스 그룹, seed20261116**의 SmallViT와 작성한153파라미터 보정 head를 비교했습니다. 두 모델 모두 무겹침128px 추론으로 평가합니다. 이는 기존 공개 데모의 test7장 겹침/무겹침 비교와 다른 실험입니다.

|---|---:|---:|---:|
| 전체 Dice | 0.570565 | 0.590386 | +0.019820 |
| 128px 패치 경계 Dice | 0.558802 | 0.559040 | +0.000238 |

차이는 반올림 전 값으로 계산합니다. 기준은epoch12, 보정은epoch14를 선택했고 threshold는 둘 다0.35입니다. 파이프라인 시간은 약27.50% 증가했습니다. CPU 파이프라인은 RGB 패치 추출·조직 검사·forward·확률 결합·후보 추출을 포함하며, 무겹침 조건이어서NMS는 포함하지 않습니다. 모델 로딩·디스크 입출력·정답 평가를 제외하고, 예열 후 이미지별3회 중앙값을 구한 뒤 검증10장의 중앙값을 집계합니다. 시간과 전체 worker RSS는 참고 관찰값이며 통제된 속도나 보정 모듈 단독 메모리 측정이 아닙니다.

## 남는 한계

한 paired seed에서 이미 사용한 validation10장·2그룹으로 epoch/threshold를 선택했습니다. 독립 test·외부 데이터·임상 검증, WSI 전체의 정답 기반 검증을 뜻하지 않습니다. 보정 head는 각128px 입력 타일 안에서 동작하며 별도 타일 사이를 직접 연결하지 않습니다.

사용자 EPYC7763 Codespaces 실행과 개발 참고 EPYC9V74 실행은 구분합니다. 같은seed를 서로 다른 환경에서 실행한 결과를 추가 독립 seed로 세지 않습니다. CNN–ViT의3개 seed 비교는 별도 실험이며 이번 보정 head를3개 seed로 검증했다는 뜻이 아닙니다. 사용자 직접 화면 검토와 면접 문장 작성 완료도 새로 기록하지 않습니다.
